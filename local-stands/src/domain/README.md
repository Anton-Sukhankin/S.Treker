# Доменная логика стенда

Здесь находятся чистые правила состояния локального стенда. `task-card-state.js` хранит черновые и сохраненные значения общей Lego-формы. `document-creation-options.js` отбирает доступные и опубликованные варианты, выполняет текстовый поиск и формирует локальный результат создания без DOM. UI-разделы не дублируют эти правила.

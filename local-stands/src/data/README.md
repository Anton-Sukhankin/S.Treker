# Данные стенда

Здесь хранятся mock-данные локального стенда. `task-card-mock.js` содержит задачу и данные общего блока Lego-формы. `documents-workspace-mock.js` содержит пакеты, типы, атрибуты, файлы и representative-варианты создания документа. Эти данные не переносятся в корневой `src/data` до отдельной миграции блока.

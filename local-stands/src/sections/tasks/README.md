# Раздел `Задачи`

Здесь реализованы стендовая демонстрационная строка с кнопкой `Открыть карточку`, правый drawer карточки задачи и размещение первого шага общей Lego-формы. Демонстрационная строка не мигрируется как продуктовый список; действующий список задач основного S-Tracker не копируется и не импортируется. Остальные шаги формы и завершение задачи относятся к следующим волнам.

При изменении реализации использовать:

- паспорт раздела: `docs/sections/tasks/README.md`;
- источники: `references/evidence/tasks/README.md`;
- компонент: `docs/components/task-card-drawer/`;
- сквозной путь: `docs/user-flows/complete-document-form-in-task.md`.

Если подтвержденное правило отсутствует в `task-card-drawer/01/02/03`, код по этому правилу не создается до обновления спецификации.

# Раздел `Шаблоны документов`

Здесь будут реализованы каталог шаблонов выбранного типа и начальная настройка до создания черновика. Полный редактор после черновика добавляется только после отдельной спецификации.

До начала реализации использовать:

- паспорт раздела: `docs/sections/document-templates/README.md`;
- источники: `references/evidence/document-templates/README.md`;
- компонент: `docs/components/document-templates-workspace/`;
- сквозной путь: `docs/user-flows/create-document-template-draft.md`.

Материалы после создания черновика остаются исследовательским контекстом, пока не появится отдельная подтвержденная спецификация.

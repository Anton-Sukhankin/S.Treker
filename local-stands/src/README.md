# Код локального стенда

Здесь находится общий runtime многостраничного локального стенда. Разделы запускаются через собственные HTML-страницы, но не копируют общие модули.

| Папка | Ответственность |
|---|---|
| `entries/` | Независимые точки запуска каталога, `Задач`, `Документов` и `Шаблонов документов`. |
| `shell/` | Каталог прототипов и общая оболочка отдельной страницы раздела. |
| `sections/tasks/` | Стендовая точка входа и карточка задачи в drawer; не содержит список задач основного S-Tracker. |
| `sections/documents/` | Пакетный раздел документов и его локальные состояния. |
| `sections/document-templates/` | Каталог и настройка шаблонов. |
| `shared/lego-document-form/` | Общая форма, используемая двумя разделами. |
| `data/` | Mock-данные и схемы только этого стенда. |
| `domain/` | Чистые правила шагов, валидации, версий и применимости. |
| `styles/` | Стили только стенда. |

Код не импортирует feature-, domain- и data-модули основного S-Tracker. Общие UI-контролы импортируются через `@s-tracker/ui`; стенд не создает собственные реализации компонентов, зарегистрированных в основном `src/ui/components/registry.js`. Продуктовая логика документных сценариев сначала проверяется здесь, а затем переносится по миграционному шлюзу.

HTML-точки входа находятся в корне `local-stands/`: `index.html`, `tasks/index.html`, `documents/index.html` и `document-templates/index.html`. Рабочие интерфейсы открываются через Vite. Для запуска можно дважды нажать `start-local-stands.cmd` или выполнить `npm.cmd run start`. При прямом открытии HTML по `file://` страница перенаправляет на уже запущенный стенд либо показывает инструкцию запуска вместо пустого экрана.

# Оболочка стенда

Здесь находятся каталог локальных прототипов и общая оболочка отдельной страницы раздела. Каталог и навигация header открывают `Задачи`, `Документы` и `Шаблоны документов` как независимые HTML-страницы; активный раздел получает `aria-current="page"`. Оболочка также показывает ссылку возврата в каталог. Этот код не изменяет корневой хедер основного S-Tracker.

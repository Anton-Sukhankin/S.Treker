# Локальные прототипы S-Tracker

Стенд содержит независимые страницы прототипов разделов `Задачи`, `Документы` и `Шаблоны документов`.

## Запуск

Для открытия конкретного раздела дважды нажать соответствующий файл:

- `tasks/open.cmd` — раздел `Задачи`;
- `documents/open.cmd` — раздел `Документы`;
- `document-templates/open.cmd` — раздел `Шаблоны документов`.

Launcher проверяет локальный сервер на порту `4175`. Если стенд еще не запущен, общий `open-local-stand.cmd` запускает Vite, ожидает готовности и затем открывает выбранный раздел в браузере. Уже запущенный сервер переиспользуется.

Для открытия общего каталога прототипов дважды нажать `start-local-stands.cmd`. Команда запустит Vite и откроет `http://127.0.0.1:4175/`.

Альтернативный запуск из терминала в папке `local-stands/`:

```powershell
npm.cmd run start
```

Исходные `index.html` используют общие ES-модули и UI-компоненты, поэтому рабочий интерфейс обслуживает Vite. При прямом открытии HTML по `file://` страница больше не остается пустой: она перенаправляет на уже работающий стенд или показывает инструкцию запуска.

## Страницы

- `/` — каталог локальных прототипов;
- `/tasks/` — рабочий первый срез карточки задачи;
- `/documents/` — рабочий первый срез раздела: пакеты, таблица, пагинация и карточка документа;
- `/document-templates/` — отдельная точка входа раздела, пока без реализованного продуктового интерфейса.

## Варианты дизайна MagicPath

Рабочие исходники вариантов карточки задачи находятся в `magicpath/task-card/`. Они предназначены для визуального выбора и не подключены к Vite-runtime локального стенда. Перенос выбранного варианта в `src/` выполняется отдельной задачей после утверждения.

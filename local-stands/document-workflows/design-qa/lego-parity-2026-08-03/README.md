| Приоритет | Расхождение до исправления | Исправленный результат |
|---|---|---|
| P1 | Полноширинные поля ограничивались шириной базового поля и визуально занимали одну левую колонку. | `Предмет договора`, описания, адрес и загрузка файла занимают предписанную ширину; двухколоночные строки совпадают с референсом. |
| P1 | Фон прокручиваемой формы был серым, хотя в MagicPath серой является только поверхность полей. | Рабочая область формы белая; поверхность полей остаётся светлой. |
| P1 | Между строкой НДС и бюджетными полями был третий лишний разделитель. | Строка НДС имеет только верхний и нижний разделители; бюджетная секция начинается без дополнительной линии. |
| P1 | Левая и правая границы контента смещались относительно карточек при видимой вертикальной полосе прокрутки. | Контент и строка карточек имеют одинаковые границы с погрешностью менее одного CSS-пикселя. |
| P1 | Этап `Сроки и формат` сжимал адрес и загрузку файла до одной колонки; тексты загрузки не совпадали с MagicPath. | Адрес и загрузка занимают полную ширину; тексты и подсказка повторяют выбранную ревизию. |

| P2 | Повторно открытый подтверждённый этап выглядел только завершённым и терял активный синий контур. | Активное состояние имеет приоритет, а маркер подтверждения сохраняется. |
| P2 | Placeholder обязательного справочника нельзя было выбрать повторно для очистки значения. | Пустой пункт остаётся доступным; очистка возвращает серый placeholder и штатную валидацию. |
| P2 | Карточки и поля переходили к узкой компоновке позже, чем в MagicPath. | До ширины планшета карточки переносятся без горизонтального скролла, а поля переходят в одну колонку. |
| P2 | Секция сводки не имела имени региона для assistive technology; описание toggle не было связано с переключателем. | Блоки сводки получили именованные регионы, toggle — программные label и description; клик по тексту переключает значение. |

## Намеренные отличия интеграции

- Глобальный header локального стенда остаётся над drawer: он принадлежит разделу `Документы`, а не Lego-форме.
- Header самостоятельной формы содержит `Вернуться к выбору` и закрытие drawer; публичный MagicPath-preview показывает компонент вне сценария каталога и этих действий не содержит.
- Сводка сохраняет документ в текущий пакет локального стенда, поэтому CTA и пояснение используют термин `пакет`, а не обещают реальное ECM-сохранение.
- Баннер `Made with MagicPath` относится к публичному preview и не переносится в продуктовый интерфейс.

# Референсы локального стенда

## Текущее состояние

Транскрипция и двенадцать полноэкранных изображений сохранены в `raw/` под стабильными идентификаторами. Видео остается во внешней рабочей папке; его имя, размер и SHA-256 зафиксированы в `context-register.md` и `raw/video/README.md`.

Паспорта разделов и выборки доказательств ссылаются на идентификаторы, а не на абсолютный путь пользовательского компьютера.

## Правила добавления

| Вид материала | Локальное размещение | Роль |
|---|---|---|
| Исходное видео | Внешний оригинал, метаданные в `references/raw/video/README.md` | Проверка последовательности и контекста; не экспортируется с компонентом. |
| Транскрипция | `references/raw/transcripts/` | Поиск решений и формулировок; не является спецификацией. |
| Полноэкранный снимок | `references/raw/screenshots/<owner>/` | Сырье для подготовки эталона; имя содержит стабильный ID и короткое описание состояния. |
| Обрезанный эталон | `docs/components/<component>/assets/` | Экспортируемый визуальный контракт конкретного состояния. |

Большие исходные видеофайлы добавляются в стенд только после отдельного решения о хранении бинарных материалов в репозитории.

## Структура доказательств

| Путь | Содержание |
|---|---|
| `context-register.md` | Единственный каталог исходных файлов, интервалов и затронутых разделов. |
| `visual-assets.md` | Связь подготовленных компонентных PNG с исходниками, evidence и параметрами обрезки. |
| `evidence/README.md` | Индекс диапазонов evidence по разделам и компонентам-владельцам. |
| `traceability-matrix.md` | Сквозная связь источников, evidence, спецификаций и runtime-планов. |
| `raw/README.md` | Правила будущего размещения оригиналов без объявления их спецификациями. |
| `evidence/tasks/README.md` | Выборка фактов, замечаний и гипотез для раздела `Задачи`. |
| `evidence/documents/README.md` | Выборка для раздела `Документы`. |
| `evidence/document-templates/README.md` | Выборка для раздела `Шаблоны документов`. |
| `evidence/shared/README.md` | Общая Lego-форма, используемая несколькими разделами. |

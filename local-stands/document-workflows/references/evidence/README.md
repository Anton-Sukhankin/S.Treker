# Каталог evidence

Evidence — это проверяемая связь исходного материала с наблюдением и маршрутом в документацию. Evidence не является самостоятельным продуктовым требованием: подтвержденное правило должно находиться в компонентном `01/02/03`.

| Раздел | Диапазон ID | Файл | Компоненты-владельцы |
|---|---|---|---|
| `Задачи` | `TASK-E-001`–`TASK-E-005` | `tasks/README.md` | `task-card-drawer`, встроенный `lego-document-form` |
| `Документы` | `DOC-E-001`–`DOC-E-006` | `documents/README.md` | `documents-workspace`, самостоятельный `lego-document-form` |
| `Шаблоны документов` | `TPL-E-001`–`TPL-E-005` | `document-templates/README.md` | `document-templates-workspace` |
| Общая форма | `LEGO-E-001`–`LEGO-E-006` | `shared/README.md` | `lego-document-form` |

Каждая карточка содержит источники и синхронизацию, классификацию, проверяемое наблюдение и маршрут в спецификацию или flow. Замечание, наблюдавшийся дефект, гипотеза и открытый вопрос не переводятся в подтвержденное правило автоматически.

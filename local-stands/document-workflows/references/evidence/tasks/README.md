## 3. Подтвержденные правила для спецификаций

- Верхний контекст карточки и рабочая область являются разными зонами; Lego-форма не владеет метаданными и действиями задачи.
- Подтвержденный прогресс формы сохраняется после закрытия и повторного открытия карточки.
- В утвержденном локальном варианте одно контекстное действие в footer подтверждает этапы 1–4, а на пятом меняет label на `Завершить задачу`; это явное решение `DEC-USER-005`, заменяющее раннюю гипотезу о двух наборах действий.
- Завершенность шага не сбрасывается переходом на другой шаг.
- Неприменимая печатная ветка не создает экран превью.

## 4. Замечания и наблюдавшиеся дефекты

| Связь | Наблюдение | Требование для прототипа |
|---|---|---|
| `TASK-E-002` | Завершенный шаг терял визуальную завершенность после возврата назад. | Состояние завершенности вычисляется из подтвержденных валидных данных, а не из текущей позиции пользователя. |
| `TASK-E-003` | Два набора закрепленных действий выглядели дублирующими. | Решено в `DEC-USER-005`: один footer содержит icon-only сохранение и одно контекстное primary-действие. |
| `TASK-E-003` | Завершение формы было доступно до последнего применимого шага. | Действие недоступно, пока не подтверждены все применимые обязательные шаги. |
| `TASK-E-003` | Заявка без печатной формы проходила лишнее превью. | После сводки форма сразу возвращает результат карточке задачи. |

## 5. Гипотезы, не являющиеся требованиями

| Основание | Гипотеза | Нерешенный вопрос |
|---|---|---|
| Реплики `00:10:25–00:10:56` | Автоматически переходить к следующему шагу после заполнения текущего. | Нужен ли явный момент подтверждения шага. |
| Реплики `00:12:12–00:13:08` | Собрать действия формы и задачи в одной верхней закрепленной области. | Закрыто `DEC-USER-005`: действия находятся в едином нижнем footer. |
| `TASK-E-004` | Использовать один универсальный набор процессных кнопок. | Какие действия и информационные элементы назначает конкретный процесс. |

Прототип не выполняет автопереход. Компоновка действий утверждена `DEC-USER-005`; остальные гипотезы не становятся требованиями.

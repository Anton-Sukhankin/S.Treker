# Выборка доказательств: общая Lego-форма

## 1. Причина выделения

Lego-форма используется самостоятельно в разделе `Документы` и как дочерняя рабочая область карточки задачи. Evidence формы регистрируются здесь один раз, чтобы два контекста запуска не создавали разные правила шагов, полей, подтверждения и печатной ветки.

## 3. Подтвержденные правила для спецификаций

- Состав шагов и полей приходит от выбранного Lego-шаблона; форма не придумывает постоянный набор.
- Обязательность, значения по умолчанию, зависимые значения и условная видимость являются правилами поля.
- Сохраненное состояние шага не зависит от текущей позиции пользователя.
- Сводка и печатная форма читают один набор подтвержденных значений.
- Верификация существует только при применимой печатной форме.
- Завершение формы возвращает результат владельцу контекста, но не завершает задачу автоматически.

## 4. Замечания и наблюдавшиеся дефекты

| Связь | Наблюдение | Требование для прототипа |
|---|---|---|
| `LEGO-E-005` | Завершенность шагов могла сбрасываться навигацией. | Завершенный шаг остается завершенным, пока его сохраненные данные валидны. |
| `LEGO-E-006` | Значение по умолчанию требовало пользовательского клика. | Уже валидное значение участвует в проверке без дополнительного взаимодействия. |
| `LEGO-E-006` | Завершение становилось доступно до последнего применимого шага. | Действие недоступно до подтверждения всех применимых обязательных шагов. |
| `LEGO-E-003` | Редактирование подстановки могло расходиться с атрибутом. | В первой версии верификация работает только для чтения, пока двусторонняя синхронизация не специфицирована. |

| Основание | Гипотеза или вопрос | Статус |
|---|---|---|
| Реплики `00:10:25–00:10:56` | Автоматически переходить к следующему шагу после заполнения. | Не является требованием. |
| Реплики `00:07:57–00:09:05` | Использовать одну или три колонки сводки. | Основной режим не выбран. |
| Реплики `00:12:12–00:13:08` | Перенести действия встроенной формы к верхней границе карточки. | Компоновка не утверждена. |
| Реплики `00:06:27–00:07:56` | Разрешить ручное редактирование отдельных подстановок. | Скрыто из первой версии до отдельного решения. |

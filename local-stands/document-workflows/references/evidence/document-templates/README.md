# Выборка доказательств: раздел «Шаблоны документов»

## 1. Граница выборки

Встреча подтверждает каталог шаблонов и начальную настройку до создания черновика. Загрузка файла шаблона, разметка, условия и полный редактор после черновика названы отдельной задачей и не входят в текущую спецификацию.

## 3. Подтвержденные правила для спецификаций

- Выбранный тип документа определяет каталог шаблонов и доступную корзину атрибутов.
- Опубликованная версия и черновик являются разными состояниями одной строки шаблона.
- Изменение схемы типа может перевести шаблон в состояние, требующее исправления, с перечнем проблемных полей.
- Обязательные атрибуты включаются в будущий черновик и не снимаются массовым действием.
- Текущий путь заканчивается созданием именованного черновика с зафиксированным набором атрибутов.

## 4. Замечания и наблюдавшиеся дефекты

| Связь | Наблюдение | Требование для прототипа |
|---|---|---|
| `TPL-E-003` | После копирования результат не был однозначно виден в каталоге. | Успех добавляет или обновляет одну определенную строку; неуспех оставляет каталог без изменений и показывает конкретную ошибку. |
| `TPL-E-003` | Сообщение об ошибке было техническим или слишком общим. | Сообщение называет проблемное поле или шаг и действие для исправления; техническая информация не показывается пользователю. |
| `TPL-E-004` | История не объясняла автора и содержание изменения. | Детальный состав записи истории остается открытым до подтверждения источником; текущая версия не придумывает его. |

## 5. Гипотезы, не являющиеся требованиями

| Основание | Гипотеза | Что требуется для решения |
|---|---|---|
| Реплики `00:02:48–00:03:38` | Автоматически переносить существующие шаблоны с минимальным участием пользователя. | Источник шаблонов, качество преобразования, объем проверки и интерфейс ошибок. |
| Демонстрация `00:15:00–00:19:33` | Использовать универсальное копирование между типами документов. | Правила совместимости схем и ожидаемый результат строки. |
| `TPL-E-005` | Реализовать весь редактор после создания черновика в текущем блоке. | Отдельная встреча и самостоятельная компонентная спецификация. |

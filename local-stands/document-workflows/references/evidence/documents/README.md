# Выборка доказательств: раздел «Документы»

## 1. Граница выборки

Выборка описывает пакетный раздел документов, детальную карточку, файлы, прямое редактирование полной схемы атрибутов и точку входа в создание документа. Действующая вкладка `Поиск` основного S-Tracker не относится к этому набору и не используется как реализация раздела.

## 3. Подтвержденные правила для спецификаций

- Тип документа задает полную схему атрибутов, которую показывает прямое редактирование.
- Выбор пакета определяет список документов и место сохранения нового документа.
- Детальная карточка сохраняет доступ к атрибутам и файлам одного документа.
- Просмотр выбранного файла не скрывает соседний список файлов.
- Создание документа начинается с явного выбора стандартной формы или опубликованного Lego-шаблона.

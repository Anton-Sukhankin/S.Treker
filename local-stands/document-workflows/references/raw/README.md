# Оригиналы источников

## Состав

| Путь | Содержание | Статус |
|---|---|---|
| `transcripts/SRC-TRANSCRIPT-001.txt` | Неизмененная локальная копия транскрипции встречи. | SHA-256 совпадает с внешним оригиналом. |
| `screenshots/documents/` | Пять неизмененных полноэкранных изображений раздела `Документы`. | ID, первоначальное имя и SHA-256 каждого файла зафиксированы в `../context-register.md`. |
| `screenshots/tasks/` | Два неизмененных полноэкранных изображения карточки задачи и встроенной формы. | ID, первоначальное имя и SHA-256 каждого файла зафиксированы в `../context-register.md`. |
| `screenshots/document-templates/` | Два неизмененных полноэкранных изображения раздела `Шаблоны документов`. | ID, первоначальное имя и SHA-256 каждого файла зафиксированы в `../context-register.md`. |
| `screenshots/shared/lego-document-form/` | Три неизмененных полноэкранных изображения общей Lego-формы. | ID, первоначальное имя и SHA-256 каждого файла зафиксированы в `../context-register.md`. |
| `video/README.md` | Метаданные внешнего оригинала видео. | Само видео не копируется в стенд. |

Файлы в `raw/` не являются спецификациями и не передаются как единственный контекст реализации. Факты и спорные выводы находятся в `../evidence/`, а готовые визуальные эталоны — в `../../docs/components/<component>/assets/`.

Имя PNG состоит из стабильного ID и короткого смыслового slug: `<ID>-<screen-state>.png`. Папка обозначает основного владельца интерфейса; повторное использование в другом разделе оформляется ссылкой на тот же ID без копирования файла.

Исходный файл не редактируется после регистрации. Перемещение или уточнение имени не меняет ID и контрольную сумму. При замене содержимого создается новый идентификатор и новая запись контрольной суммы.

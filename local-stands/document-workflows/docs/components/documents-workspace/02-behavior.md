# Рабочая область документов: поведение

> Статус: пути списка, детальной карточки и локального создания документа реализованы в нативном локальном стенде `/documents/`; перенос в основной S-Tracker еще не выполнялся.

## 1. Основной пользовательский путь просмотра документа

1. Пользователь выбирает пакет в дереве.
2. Таблица показывает документы выбранного пакета.
3. Пользователь нажимает наименование документа в строке таблицы.
4. Drawer открывается справа и перекрывает правую часть колонки `Наименование`; оставшаяся видимой область наименований доступна.
5. Пользователь может нажать другое наименование, не закрывая drawer; header, атрибуты, файлы и footer заменяются данными выбранного документа.
6. Пользователь открывает файл или переходит к редактированию атрибутов.
7. После закрытия дополнительного слоя пользователь возвращается в тот же drawer, а после закрытия drawer — к тому же пакету и списку.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Выбирает пакет | Раздел открыт | Узел получает активное состояние; путь и таблица относятся к выбранному пакету. |
| 2 | Нажимает наименование документа | Таблица содержит документ | Drawer выезжает справа налево поверх правых колонок и правой части колонки `Наименование`; header, атрибуты, файлы и footer относятся к выбранному документу, а чекбокс и видимая левая область наименования остаются доступными. |
| 3 | Нажимает другое наименование документа | Drawer открыт | Drawer остается открыт; его header, атрибуты, файлы, версия и footer показывают новый документ, а индикация активной строки переходит к выбранному наименованию. |
| 4 | Выбирает файл | В drawer есть файлы | Открывается просмотр выбранного файла; строка файла активна. |
| 5 | Закрывает просмотр | Просмотр открыт | Снова виден drawer с тем же выбранным документом. |
| 6 | Нажимает `Закрыть`, кнопку закрытия в header или клавишу `Esc` | Drawer открыт | Drawer закрывается; видны прежний пакет, положение дерева, страница и вся таблица списка. |

## 3. Масштабирование детальной карточки

| Действие | Исходное состояние | Результат |
|---|---|---|
| Наводит указатель на левую границу drawer | Карточка открыта | Граница и индикатор получают синее активное состояние, курсор показывает возможность горизонтального изменения размера. |
| Зажимает основную кнопку мыши и перемещает границу влево | Карточка открыта | Drawer расширяется вправо от сохраненной правой привязки; расположение блоков `Атрибуты` и `Файлы` не меняется. |
| Зажимает основную кнопку мыши и перемещает границу вправо | Карточка открыта | Drawer сужается; доступная часть таблицы увеличивается, расположение блоков карточки не меняется. |
| Дважды нажимает левую границу | Ширина изменена | Drawer возвращается к базовой ширине, допустимой для текущей ширины окна. |
| Фокусирует границу и нажимает `ArrowLeft` или `ArrowRight` | Карточка открыта | `ArrowLeft` расширяет drawer, `ArrowRight` сужает; с `Shift` применяется увеличенный шаг. |
| Фокусирует границу и нажимает `Home` | Ширина изменена | Drawer возвращается к базовой ширине. |

## 4. Меню `Действия`

| Действие | Исходное состояние | Результат |
|---|---|---|
| Нажимает `Действия` | Drawer документа открыт | Под кнопкой открывается меню с иконками, одиннадцатью действиями и разделителями между пятью смысловыми группами. |
| Выбирает пункт меню | Меню открыто | Меню закрывается; прототип показывает уведомление с результатом выбранного действия. |
| Нажимает вне меню | Меню открыто | Меню закрывается; drawer и выбранный документ не меняются. |
| Нажимает `Esc` | Меню открыто | Закрывается меню, фокус возвращается на кнопку `Действия`; drawer остается открыт. |

## 5. Редактирование атрибутов

| Действие | Исходное состояние | Результат |
|---|---|---|
| Открывает редактирование | Есть право изменения выбранной версии | Открывается форма по полной схеме атрибутов типа документа. |
| Включает `Скрыть необязательные поля` | Видны обязательные и необязательные поля | Необязательные поля скрываются; значения не удаляются. |
| Меняет значение | Поле доступно для редактирования | Поле показывает новое черновое значение; карточка под слоем не обновляется до сохранения. |
| Нажимает `Отмена` | Есть или нет черновых изменений | Слой закрывается; сохраненные значения документа не меняются. |
| Нажимает `Сохранить` | Все обязательные значения валидны | Слой закрывается; карточка показывает новые значения и обновленное последнее изменение. |
| Нажимает `Сохранить` | Есть ошибка | Слой остается открыт; проблемные поля получают конкретное сообщение. |

## 6. Выбор способа создания

| Действие | Исходное состояние | Результат |
|---|---|---|
| Нажимает `Создать новый документ` | Выбран пакет и действие доступно | Карточка документа и меню списка закрываются; снизу раскрывается модальный picker, workspace остается виден под затемнением. |
| Выбирает стандартную ECM-форму | Вариант доступен | Каталог сменяется стандартной формой внутри нижнего drawer; Lego-компонент не запускается. |
| Выбирает опубликованный Lego-шаблон | Вариант доступен | Каталог и его header скрыты; тот же drawer показывает самостоятельный `lego-document-form`. |
| Нажимает `Вернуться к выбору` | Форма открыта | Каталог возвращается с прежним запросом; документ не создается. |
| Закрывает drawer | Документ еще не сохранен | Пользователь возвращается к прежнему пакету и списку без новой строки. |
| Сохраняет ECM-форму | Наименование заполнено | Drawer закрывается; таблица текущего пакета и счётчик содержат новую локальную строку. |
| Сохраняет Lego-документ | Открыта сводка после пяти валидных этапов | Drawer закрывается; таблица текущего пакета и счётчик содержат новую локальную строку выбранного Lego-варианта. |

Поиск, строки, пустой результат и действия picker описаны в `../new-document-type-picker/02-behavior.md`.

## 7. Работа с файлами

| Действие | Исходное состояние | Результат |
|---|---|---|
| Выбирает поддерживаемый файл | Файл доступен для просмотра | Открывается встроенный просмотр. |
| Выбирает другую страницу | Документ многостраничный | Основная область показывает выбранную страницу; ее миниатюра активна. |
| Меняет масштаб | Просмотр открыт | Документ показывает новый масштаб; карточка документа не меняется. |
| Нажимает скачивание | Файл доступен | Начинается получение выбранного файла; остальные слои остаются открыты. |

## 8. Короткие внешние результаты

| Действие | Получатель | Видимый результат |
|---|---|---|
| Выбор Lego-шаблона | `lego-document-form` | В нижнем drawer показана самостоятельная пошаговая форма. |
| Сохранение созданного документа | Рабочая область документов | Новый документ появляется в целевом пакете и может быть открыт. |
| Публикация шаблона | Список вариантов создания | Применимый опубликованный шаблон доступен для выбора. |

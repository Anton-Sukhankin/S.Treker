# Рабочая область документов: структура

> Статус: реализовано в нативном локальном стенде `/documents/` по MagicPath revisions `434701870192275456`, `434991671604826112` и визуальной корректировке `434987194554413057`; перенос в основной S-Tracker еще не выполнялся. Не является действующей таблицей документного поиска `documents-list`.

## 1. Граница функционального блока

`Рабочая область документов` — самостоятельный раздел для навигации по пакетам и работы с документами выбранного пакета. Она включает состояния списка, детальной карточки и ее дополнительных слоев. Пошаговое создание по Lego-шаблону передается общему компоненту `lego-document-form`.

| Объект | Тип связи | Правило |
|---|---|---|
| Дерево пакетов | Входит | Выбирает текущий пакет и задает набор документов справа. |
| Таблица документов пакета | Входит | Показывает документы текущего пакета и открывает детальную карточку. |
| Детальная карточка документа | Входит, правый drawer поверх списка | Показывает заголовок, версию, действия, атрибуты и файлы одного документа; таблица остается источником переключения между документами. |
| Просмотр файла | Входит, дополнительный слой | Показывает выбранный файл поверх карточки с сохранением панели файлов. |
| Редактирование атрибутов | Входит, дополнительный слой | Показывает редактируемую схему атрибутов выбранного документа. |
| Выбор способа создания | Дочерний нижний drawer | Показывает стандартные ECM-формы и опубликованные Lego-шаблоны; полная спецификация находится в `../new-document-type-picker/`. |
| `lego-document-form` | Дочерний общий компонент | Открывается после выбора Lego-варианта создания в самостоятельном режиме. |
| Документный поиск | Не входит | Действующая вкладка `Поиск` имеет отдельные компоненты и состояние. |

## 3. Пространственный контракт базового состояния

| Зона | Расположение | Соседняя область | Условие видимости | Состав | Что не входит |
|---|---|---|---|---|---|
| Левая панель | Слева под навигацией раздела | Основная область справа | Раздел открыт | Поиск пакета, дерево папок, `Создать пакет` | Таблица документов и карточка документа. |
| Контекст пакета | Сверху основной области | Панель действий ниже | Выбран пакет | Путь или хлебные крошки текущего пакета | Поля документа. |
| Панель списка | Под контекстом пакета | Таблица ниже | Выбран пакет | Фильтры, сортировка, настройки, вложенные документы, обновление, права доступа, `Добавить в пакет`, `Создать новый документ` | Действия конкретного документа. |
| Таблица | Под панелью списка | Пагинация или размер страницы ниже | Выбран пакет | Чекбокс, колонки, строки, меню строки | Детальная карточка и ее файлы. |

## 4. Пространственный контракт дополнительных слоев

| Слой | Привязка | Состав | Что остается видно | Что недоступно под слоем |
|---|---|---|---|---|
| Детальная карточка | Drawer выезжает от правой границы рабочей области справа налево, располагается поверх правой части таблицы и не сдвигает таблицу или панель пакетов; при ширине фрейма 1600 px базовая ширина drawer составляет 1060 px, а пользователь может изменять ее левой границей | Изменяемая левая граница; закрепленный header с наименованием и панелью инструментов; центральная область с блоком `Атрибуты` и панелью `Файлы` шириной 350 px, разделенными промежутком 12 px; закрепленный footer содержит только действия карточки | Левая панель пакетов, чекбоксы строк и доступная часть колонки `Наименование` остаются видимыми; при изменении ширины drawer внутреннее расположение блоков `Атрибуты` и `Файлы` не меняется | Drawer перекрывает правые колонки и правую часть колонки `Наименование`; закрытие возвращает доступ ко всей таблице. |
| Просмотр файла | Поверх центральной части карточки | Заголовок файла, документ, инструменты просмотра, миниатюры страниц | Панель файлов карточки справа | Атрибуты карточки под просмотром. |
| Редактирование атрибутов | Полноширинный слой поверх карточки | Заголовок, переключатель необязательных полей, сетка полей, `Отмена`, `Сохранить` | Контекст выбранного документа через значения формы | Действия карточки под слоем. |
| Выбор способа создания | Модальный drawer раскрывается от нижней границы viewport вверх, занимает всю доступную ширину и не сдвигает workspace | Заголовок, пояснение, поиск, счётчик, подсказка Lego-сценария, список вариантов, `Выбрать` для ECM, `Открыть этапы` для Lego, закрытие | Верхний контекст раздела под затемнением | Дерево пакетов, таблица и toolbar недоступны до закрытия. |
| Форма создания | Заменяет каталог внутри того же нижнего drawer после выбора варианта | ECM-вариант показывает стандартные поля под header каталога; Lego-вариант занимает drawer собственными header, этапами, контентом и footer | Затемнённый контекст раздела | Каталог вариантов до возврата. |

## 5. Атрибутивный состав списка

| Колонка | Содержание | Правило |
|---|---|---|
| Выбор | Чекбокс документа | Выбирает документ только для доступных массовых действий текущего пакета. |
| Наименование | Отображаемое имя документа | Основная точка открытия drawer; открытый drawer перекрывает правую часть колонки, но видимая левая область строки остается доступной для выбора другого документа. |
| Номер | Номер документа | Показывает сохраненное значение или нейтральное отсутствие. |
| Тип документа | Наименование типа | Определяет схему атрибутов документа. |
| Дата документа | Дата | Формат единый для раздела. |
| Версия | Номер текущей версии | Совпадает с версией в заголовке детальной карточки. |
| Последнее изменение | Дата последнего изменения | Обновляется после сохранения документа. |
| Меню строки | Действия одного документа | Состав действий зависит от прав и состояния. |

## 6. Состав детальной карточки

| Зона | Элементы | Правило состава |
|---|---|---|
| Заголовок | Наименование документа, закрытие | Наименование относится к открытой версии документа; отдельный description `Карточка документа` отсутствует. |
| Изменяемая граница | Левая граница drawer с индикатором масштабирования | Граница находится поверх края карточки, не образует отдельную контентную колонку и не меняет взаимное расположение header, атрибутов, файлов и footer. |
| Панель инструментов header | Открытие в отдельном окне, раскрываемый список версий, меню `Действия`, `Копировать ссылку` | Выбрана ровно одна версия; доступность действий зависит от прав и состояния этой версии. |
| Меню `Действия` | Группа контекста договора: `Демо Контрактс 12-11-2025`; группа навигации: `Показать в архиве`, `Пакеты документа`, `Связи документа`; группа изменения: `Редактировать`, `Изменить тип`; группа создания и выгрузки: `Создать копию`, `Создать версию`, `Скачать атрибутивный состав`, `Скачать файлы`; отдельная группа `Пометить на удаление` | Каждая строка содержит иконку и текст; группы разделены горизонтальными линиями. |
| Атрибуты | Заголовок `Атрибуты`, счетчик и пары `название — значение` в двух колонках | Состав определяется типом документа; description `Сведения о документе` отсутствует. |
| Файлы | Заголовок `Файлы`, счетчик, имя, тип файла, размер и отдельное действие скачивания | Панель имеет ширину 350 px на фрейме 1600 px; description версии и нижнее пояснение о последующем просмотре отсутствуют. |
| Footer | `Закрыть`, `Редактировать атрибуты` | Footer остается видимым при прокрутке атрибутов и файлов; левая статусная зона с индикатором, версией и последним изменением отсутствует. |

Показанный референс содержит, в частности: тип документа, наименование, номер, дату, плановую дату договора, вид документа, тип договора, организацию, автора, контрагента, доверенности подписантов и их даты, прочие условия, расчетные счета, бизнес-ключ Трекера, GUID мастер-системы, признак блокировки и другие поля схемы. Этот пример не является универсальным фиксированным набором для всех типов документов.

## 7. Состав редактирования атрибутов

| Группа | Примеры из референса | Тип отображения |
|---|---|---|
| Основные идентификаторы | Наименование, номер, дата, GUID мастер-системы, мастер-система | Текст, дата или недоступное системное значение согласно схеме. |
| Справочники | Организация, вид документа, тип договора, контрагент, расчетные счета, проект, БЮ, специализации | Выбор значения из соответствующего справочника. |
| Участники и доверенности | Автор, представитель организации, номера и даты доверенностей | Выбор пользователя, текст или дата согласно атрибуту. |
| Договорные данные | Плановая дата, предмет договора, прочие условия, вид договора, признак типового договора | Поле соответствующего типа из схемы. |
| Служебные данные | Бизнес-ключ Трекера, статус, блокировка | Отображение или редактирование определяется правами и схемой. |

## 8. Состав выбора способа создания

Полная структура каталога, его пространственный контракт и визуальные эталоны находятся в `../new-document-type-picker/01-structure.md`. Рабочая область владеет только точкой открытия, текущим пакетом, взаимным исключением с карточкой документа и возвращением созданной строки в таблицу.

## 9. Точки будущей DS-binding привязки

| Зона | Тип UI-элемента | Продуктовое правило | Будущее имя DS-компонента |
|---|---|---|---|
| Дерево пакетов | Tree navigation | Выбранный узел задает текущий пакет. | Заполняется после утверждения DS-карты. |
| Таблица | Table | Показывает документы выбранного пакета. | Заполняется после утверждения DS-карты. |
| Детальная карточка | Right-side drawer | Перекрывает правые колонки и правую часть колонки `Наименование`, но оставляет доступными чекбокс и видимую левую область наименований; выбор другого наименования заменяет документ внутри того же drawer. | Заполняется после утверждения DS-карты. |
| Просмотр файла | Document viewer | Показывает выбранный файл и страницы. | Заполняется после утверждения DS-карты. |
| Редактирование атрибутов | Form layer | Строится по схеме типа документа. | Заполняется после утверждения DS-карты. |
| Выбор создания | Modal bottom drawer | Показывает применимые стандартные формы и опубликованные шаблоны поверх workspace без его сдвига. | Заполняется после утверждения DS-карты. |

## 10. Внешние связи

| Компонент | Тип связи | Результат |
|---|---|---|
| `lego-document-form` | Дочерний получатель | После выбора Lego-шаблона получает тип, шаблон и самостоятельный контекст запуска. |
| `new-document-type-picker` | Дочерний drawer | Получает текущий пакет и передает выбранный вариант форме создания. |
| `document-templates-workspace` | Источник опубликованных шаблонов | Опубликованный применимый шаблон появляется среди вариантов создания. |
| Действующий документный поиск | Отдельная область системы | Может позднее открыть тот же документ, но не разделяет состояние пакетов и списка этого компонента. |

# Рабочая область документов: данные, состояния и правила

> Статус: данные и состояния списка, детальной карточки и локального создания реализованы в нативном локальном стенде `/documents/`; перенос в основной S-Tracker еще не выполнялся.

## 1. Владельцы состояния

| Область | Состояние | Правило видимого результата |
|---|---|---|
| Дерево пакетов | Выбранный пакет, раскрытые узлы, строка поиска | Таблица и путь относятся к выбранному пакету. |
| Таблица | Набор документов, сортировка, выбор строк, размер страницы | Показывает только состояние текущего пакета. |
| Детальная карточка | Открытый документ, выбранная версия и текущая ширина drawer | Header, атрибуты, файлы и footer относятся к одному документу; выбор другого наименования в таблице заменяет документ без закрытия drawer и без сброса выбранной ширины. |
| Просмотр файла | Выбранный файл, страница и масштаб | Не изменяет выбранную версию документа. |
| Редактирование | Черновые значения атрибутов | До сохранения не меняет карточку и таблицу. |
| Выбор создания | Открытие drawer, запрос и выбранный вариант | Не создает документ до перехода в соответствующую форму и ее сохранения; полный контракт находится в `../new-document-type-picker/03-data-states-rules.md`. |
| Локальный результат создания | Созданные в текущей сессии документы | После сохранения добавляет документ в выбранный пакет и пересчитывает таблицу; перезагрузка очищает этот результат. |
| `lego-document-form` | Черновик нового документа | Возвращает сохраненный документ или отмененный сценарий. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода |
|---|---|---|---|
| Пакет не выбран | Раздел открыт без текущего пакета | Таблица не показывает документы; действие создания недоступно, если пакет обязателен. | Выбор пакета. |
| Пакет выбран | Выбран доступный узел | Показаны путь, панель и документы пакета. | Выбор другого пакета. |
| Пустой пакет | В выбранном пакете нет документов | Таблица показывает пустое состояние, а не фиктивную строку документа. | Создание или добавление документа. |
| Карточка открыта | Нажато наименование документа в строке таблицы | Справа виден drawer с header, атрибутами, файлами и footer выбранной версии; drawer перекрывает правую часть колонки `Наименование`, но чекбоксы и видимая левая область наименований доступны, а строка открытого документа имеет активную индикацию. | Выбор другого видимого наименования заменяет документ внутри drawer; закрытие drawer возвращает всю ширину прежней странице списка без сброса пакета. |
| Ширина карточки изменена | Пользователь переместил левую границу или применил клавиатурное изменение размера | Drawer сохраняет правую привязку, а левая граница занимает новое допустимое положение; блоки `Атрибуты` и `Файлы` остаются в прежнем взаимном расположении. | Двойное нажатие или `Home` возвращает базовую ширину; изменение ширины окна ограничивает сохраненное значение новым допустимым диапазоном. |
| Меню действий открыто | В drawer нажата кнопка `Действия` | Под кнопкой видны одиннадцать пунктов с иконками, объединенные разделителями в пять групп. | Выбор пункта, нажатие вне меню или `Esc` закрывает меню; при `Esc` drawer остается открыт. |
| Файл открыт | Выбран файл с поддерживаемым просмотром | Видны документ, страницы и инструменты просмотра. | Закрытие просмотра или выбор другого файла. |
| Редактирование | Пользователь открыл доступное действие | Видна форма полной схемы атрибутов. | Сохранение или отмена. |
| Выбор создания | Нажато `Создать новый документ` | Снизу открыт модальный picker; workspace виден под затемнением и недоступен. | Переход к форме или закрытие. |
| ECM-форма создания | Нажато `Выбрать` у ECM-варианта | Каталог скрыт; header каталога и стандартные поля видны внутри нижнего drawer. | Возврат к каталогу, закрытие или сохранение. |
| Lego-форма создания | Нажато `Открыть этапы` у Lego-варианта | Каталог и его header скрыты; самостоятельные этапы Lego занимают нижний drawer. | Возврат к каталогу, закрытие или переход к сводке. |
| Lego-сводка | Подтверждён пятый этап | В drawer видны блоки заполненных значений и финальные действия. | Возврат к редактированию, закрытие или сохранение документа. |
| Документ создан локально | Форма успешно сохранена | Drawer закрыт; таблица текущего пакета содержит новую строку, счетчик и пагинация пересчитаны. | Перезагрузка страницы или дальнейшие действия пользователя. |

## 3. Правила схемы и данных

| Данные | Источник | Правило |
|---|---|---|
| Полная схема атрибутов | Тип документа | Детальная карточка и прямое редактирование не придумывают и не удаляют атрибуты типа. |
| Значение атрибута | Выбранная версия документа | Карточка показывает сохраненное значение именно этой версии. |
| Техническое поле | Схема и права | Может быть показано только для чтения; наличие на референсе не означает обязательное ручное редактирование. |
| Справочник | Конфигурация атрибута | Поле показывает выбранную сущность и использует соответствующий набор вариантов. |
| Файлы | Выбранная версия | Список относится к текущей версии; имя и формат отображаются отдельно от действия скачивания. |
| Варианты создания | Стандартные ECM-формы и опубликованные применимые Lego-шаблоны | Черновые, сломанные или неприменимые шаблоны не предлагаются. |

## 4. Правила видимости и доступности

| Элемент | Условие | Видимый результат |
|---|---|---|
| `Создать новый документ` | Есть право создания и выбран допустимый контекст | Кнопка доступна. |
| `Создать новый документ` | Нет права или отсутствует обязательный контекст | Кнопка недоступна или не показана согласно политике раздела. |
| Редактирование атрибутов | Версия доступна для изменения | Действие доступно. |
| Редактирование атрибутов | Версия недоступна для изменения | Атрибуты остаются только для чтения. |
| Необязательное поле | Переключатель скрытия включен | Поле скрыто без изменения значения. |
| Просмотр файла | Формат поддерживается | Файл открывается встроенно. |
| Просмотр файла | Формат не поддерживается | Доступно скачивание; пустой просмотр не открывается. |
| Колонка `Наименование` | Drawer документа открыт | Drawer перекрывает правую часть колонки; оставшаяся слева видимая область каждого наименования доступна для открытия, а выбранное наименование получает активную индикацию. |
| Правые колонки таблицы | Drawer документа открыт | Правые колонки и правая часть колонки `Наименование` находятся под drawer и недоступны; закрытие drawer снова показывает всю ширину таблицы. |
| Левая граница drawer | Карточка открыта | Граница доступна мышью и клавиатурой; при наведении, фокусе и перетаскивании показывает синее активное состояние. |

Ширина drawer по умолчанию составляет 1060 px на широком рабочем фрейме. Базовая нижняя граница — 840 px. Верхняя граница оставляет слева 440 px рабочей области для панели пакетов и доступной части таблицы. Если окно уже этого пространственного контракта, допустимый диапазон уменьшается вместе с окном, а блоки карточки не переставляются из-за самого действия масштабирования.

## 5. Контракты взаимодействия

| Связанный компонент | Роль | Условие | Результат в рабочей области | Результат в связанном компоненте |
|---|---|---|---|---|
| `document-templates-workspace` | Источник опубликованных шаблонов | Шаблон опубликован и применим к типу | Вариант появляется в выборе создания. | Каталог сохраняет собственные версии и состояние. |
| `new-document-type-picker` | Получатель пакета и источник выбранного варианта | Нажата доступная кнопка создания | Workspace сохраняет пакет и блокирует действия под drawer. | Picker показывает применимые варианты и передает выбранную строку форме. |
| `lego-document-form` | Получатель контекста и источник результата | Выбран Lego-шаблон | Раздел оставляет список видимым под затемнением и сохраняет пакет для возврата. | Форма получает тип, шаблон, пакет и самостоятельный режим. |
| `lego-document-form` | Источник нового документа | Сценарий успешно сохранен | Документ появляется в таблице целевого пакета. | Форма завершает самостоятельный сценарий. |
| Действующий документный поиск | Независимая область | Позднее открывается тот же документ | Данные документа могут совпадать, но UI-состояние поиска не переносится в пакетный раздел. | Поиск сохраняет свои фильтры и таблицу. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Документный поиск | Компонент не меняет фильтры, выдачу, массовые действия и настройки колонок действующей вкладки `Поиск`. |
| Шаблоны | Компонент не создает и не публикует Lego-шаблоны. |
| Lego-форма | Компонент не определяет шаги, зависимости, обязательность и печатную ветку. |
| Схема документа | Интерфейс строится по типу документа и не фиксирует показанный набор атрибутов как универсальный. |
| Несохраненные изменения | Закрытие редактирования без сохранения не изменяет документ. |
| Постоянное хранение | Созданная в локальном стенде строка существует только до перезагрузки и не выдается за backend-результат. |

# Lego-форма документа: поведение

## 1. Основной пользовательский путь самостоятельного режима

1. Пользователь открывает Lego-вариант из каталога нового документа и видит этап `Потребность`.
2. Пользователь заполняет обязательные параметры этапа и нажимает `Подтвердить и продолжить`.
3. Подтверждённая карточка получает состояние `Этап подтверждён`, а следующий этап становится активным.
4. Пользователь последовательно подтверждает этапы `Контрагент`, `Стоимость и бюджет` и `Условия оплаты`.
5. На этапе `Сроки и формат` пользователь нажимает `Завершить заполнение`.
6. Экран формы сменяется сводкой пяти этапов; пользователь проверяет значения.
7. Пользователь нажимает `Сохранить документ`; drawer закрывается, а новая строка появляется в текущем пакете.

## 2. Навигация по этапам

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает карточку подтверждённого этапа | Есть минимум один подтверждённый этап | Выбранный этап становится активным; его значения остаются заполненными. |
| Нажимает первую доступную незавершённую карточку | Карточка не заблокирована | Выбранный этап становится активным; контент прокручивается к началу. |
| Пытается открыть будущий этап | Карточка показывает `Будет доступен позже` | Активный этап и значения не меняются. |
| Изменяет значение подтверждённого этапа | Выбран ранее подтверждённый этап | Этот этап и все последующие теряют подтверждённость; пользователь должен подтвердить последовательность повторно. |

## 3. Подтверждение и ошибки

| Действие пользователя | Условие | Итог интерфейса |
|---|---|---|
| Нажимает primary-действие | Все обязательные поля активного этапа заполнены | Значения сохраняются, карточка подтверждается, активируется следующий этап или сводка. |
| Нажимает primary-действие | Есть пустое обязательное поле | Этап остаётся активным; поле получает сообщение об ошибке и фокус. |
| Меняет поле с показанной ошибкой | Новое значение введено или выбрано | Сообщение этого поля снимается; остальные ошибки остаются до исправления или повторной проверки. |

Автоматического перехода после последнего ввода или выбора нет.

## 4. Зависимые поля

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Выключает `Контрагент уже определён` | Переключатель включён | `Контрагент (справочник)` и `Контактное лицо` скрыты; обязательность контрагента снята. |
| Включает `Контрагент уже определён` | Переключатель выключен | Поля контрагента и контактного лица снова видны; справочник контрагента обязателен. |
| Включает `Сумма включает НДС` | Переключатель выключен | Появляется обязательная `Ставка НДС`. |
| Выключает `Сумма включает НДС` | Переключатель включён | `Ставка НДС` скрыта и не участвует в валидации; сохранённое значение ставки остаётся в черновике. |
| Выбирает `Предоплата` или `Аванс и окончательный расчёт` | Открыт этап `Условия оплаты` | Вместо `Отсрочка платежа` показан обязательный `Размер аванса`. |
| Выбирает другую схему оплаты | Видим `Размер аванса` | Поле аванса скрыто; показана необязательная `Отсрочка платежа`. |
| Возвращает справочник к пустому пункту `Выберите…` | Ранее было выбрано значение | Выбранное значение очищено; `Select` снова показывает серый placeholder, а обязательное поле не проходит следующее подтверждение этапа. |
| Выбирает файл | Открыт этап `Сроки и формат` | В блоке `Техническое задание` имя выбранного файла заменяет текст `Выберите файл или перетащите его сюда`; пояснение меняется на `Нажмите, чтобы заменить файл`. |

## 5. Сводка

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает `Завершить заполнение` | Пятый этап валиден | Форма скрыта; показана сводка с пятью блоками и заполненными значениями. |
| Нажимает `Вернуться к редактированию` | Открыта сводка | Открывается этап `Сроки и формат`; значения и подтверждённость этапов сохранены. |
| Нажимает `Верифицировать` | Открыта сводка | Появляется уведомление `Документ отправлен на верификацию`; сводка остаётся открытой. |
| Нажимает `Скачать` | Открыта сводка | Появляется уведомление `Печатная форма подготовлена к скачиванию`; сводка остаётся открытой. |
| Нажимает `Сохранить документ` | Открыта сводка самостоятельного режима | Drawer закрывается; таблица документов получает новую строку выбранного Lego-варианта. |

## 6. Возврат и закрытие самостоятельного режима

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает `Вернуться к выбору` | Открыт экран этапов | Каталог вариантов показан с прежним поисковым запросом; документ не создан. |
| Нажимает кнопку закрытия | Открыта форма или сводка | Drawer закрыт; новая строка документа отсутствует. |

## 7. Встроенный режим

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает icon-only `Сохранить` в footer карточки задачи | Есть черновые изменения | Значения фиксируются как сохранённый черновик; активный этап не подтверждается; показан toast. |
| Нажимает `Подтвердить шаг` | Активен этап 1–4 и он валиден | Этап подтверждён; следующий этап активен. |
| Нажимает `Завершить задачу` | Активен валидный этап `Сроки и формат` | Все пять этапов подтверждены; показан toast завершения; самостоятельная сводка не открывается. |
| Сворачивает аккордеон формы | Форма раскрыта | Карточки и активные поля скрыты; значения и активный этап не меняются. |

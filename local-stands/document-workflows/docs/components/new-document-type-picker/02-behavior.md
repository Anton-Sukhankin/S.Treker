# Выбор типа нового документа: поведение

> Статус: реализовано в нативном локальном стенде `/documents/`.

## 1. Основной пользовательский путь

1. Пользователь выбирает пакет и нажимает `Создать новый документ`.
2. Нижний drawer показывает доступные стандартные ECM-формы и опубликованные Lego-шаблоны.
3. Пользователь при необходимости вводит запрос и проверяет счетчик найденных вариантов.
4. Пользователь нажимает `Выбрать` у ECM-строки или `Открыть этапы` у Lego-строки.
5. Каталог скрывается и показывает соответствующую форму с сохранённым пакетом и выбранным вариантом; у Lego-варианта header каталога скрыт, а header Lego-формы виден в той же верхней зоне drawer.
6. После сохранения drawer закрывается, а новая строка появляется в таблице того же пакета.

## 2. Открытие и закрытие

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает `Создать новый документ` | Создание доступно, picker закрыт | Меню списка и карточка документа закрыты; снизу раскрывается picker, а фокус переходит в поиск. |
| Нажимает кнопку закрытия | Picker открыт | Picker закрыт; пакет и табличное состояние сохранены; фокус возвращен к кнопке создания. |
| Нажимает `Escape` | Picker является верхним открытым слоем | Закрывается только picker; нижележащие области не выполняют второе действие закрытия. |
| Нажимает на затемнение | Picker открыт | Результат равен закрытию кнопкой в header. |

## 3. Поиск

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Вводит текст | Каталог открыт | Строки отбираются по имени варианта, отображаемому источнику и типу документа; `Найдено: N` равно числу видимых строк. |
| Вводит `ECM` | Есть доступные ECM-варианты | Видны строки со значением `Стандартная ECM-форма`. |
| Вводит `Lego` | Есть опубликованные Lego-варианты | Видны строки со значением `Lego-шаблон`. |
| Нажимает очистку или `Сбросить поиск` | Запрос непустой | Запрос очищен, возвращен полный доступный список, фокус остается в поиске. |
| Вводит запрос без совпадений | Нет подходящих вариантов | Счетчик равен нулю; на месте строк показаны `Ничего не найдено`, пояснение и `Сбросить поиск`. |

## 4. Выбор варианта

| Действие пользователя | Условие | Итог интерфейса |
|---|---|---|
| Нажимает строку | Вариант доступен | Строка получает выбранное состояние; форма еще не открывается. |
| Нажимает `Выбрать` | Доступен ECM-вариант | Каталог скрывается; стандартная форма получает пакет, источник, тип документа и идентификатор варианта. |
| Нажимает `Открыть этапы` | Доступен Lego-вариант | Каталог и его header скрываются; самостоятельная Lego-форма получает пакет, тип документа, идентификатор и версию шаблона. |
| Нажимает `Enter` или `Space` на строке | Фокус находится на строке | ECM-строка открывает стандартную форму; Lego-строка открывает этапы. |
| Дважды нажимает строку | Вариант доступен | ECM-строка открывает стандартную форму; Lego-строка открывает этапы. |
| Выбирает ECM-вариант | Источник равен `Стандартная ECM-форма` | Открывается стандартная форма; Lego-шаги не показываются. |
| Выбирает Lego-вариант | Источник равен `Lego-шаблон`; строка показывает действие `Открыть этапы` | Каталог и его header скрыты; тот же drawer целиком показывает самостоятельный `lego-document-form` с собственными header, этапами и footer. |

## 5. Переход к созданию

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Нажимает `Вернуться к выбору` | ECM-форма или экран этапов Lego открыт | Возвращается каталог и прежний поисковый запрос; header каталога снова виден; документ не создается. |
| Нажимает `Вернуться к редактированию` | Открыта сводка Lego | Сводка скрыта; открыт пятый этап с сохранёнными значениями. |
| Сохраняет форму с наименованием | Форма открыта | Создается локальная строка с пакетом, наименованием, номером, типом, датой и версией `1`; счетчик и пагинация пересчитаны. |
| Пытается сохранить без наименования | Поле наименования пусто | Форма остается открытой; у поля показана ошибка и фокус переведен в это поле. |
| Закрывает форму без сохранения | Форма открыта | Drawer закрывается; новая строка отсутствует, пакет не меняется. |

Локальный стенд демонстрирует клиентский результат без backend-запроса и постоянного хранения после перезагрузки страницы.

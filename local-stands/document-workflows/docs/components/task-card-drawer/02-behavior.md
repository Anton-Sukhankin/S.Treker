# Карточка задачи в drawer: поведение

## 1. Открытие и закрытие

| Действие | Исходное состояние | Видимый результат |
|---|---|---|
| `Открыть карточку` | Drawer закрыт | Drawer и overlay показаны, фокус передан карточке |
| Крестик, overlay или `Escape` | Нет несохранённых изменений | Drawer закрыт, фокус возвращён точке входа |
| Крестик, overlay или `Escape` | Есть несохранённые изменения | Открывается подтверждение `Остаться` / `Выйти без сохранения` |
| `Остаться` | Открыто подтверждение | Modal закрыт, значения сохранены в черновике интерфейса |
| `Выйти без сохранения` | Открыто подтверждение | Изменения после последнего сохранения отброшены, drawer закрыт |

## 2. Изменение ширины

Пользователь зажимает левую границу и перемещает её. Синяя линия видна при hover, keyboard focus и drag. Значение округляется до целых пикселей и ограничивается диапазоном `520–1100 px` и шириной viewport. При фокусе `ArrowLeft` расширяет drawer на `20 px`, `ArrowRight` сужает на `20 px`.

## 3. Аккордеоны

Нажатие на строку title `О задаче` или формы переключает только соответствующий контент. Стрелка меняет направление, `aria-expanded` соответствует видимому состоянию. Icon-only действия истории и комментариев не переключают аккордеон.

## 4. История и комментарии

| Действие | Результат |
|---|---|
| История | Основные аккордеоны скрыты; под неизменным header показан список из пяти событий |
| Комментарии | Основные аккордеоны скрыты; показан список из четырнадцати комментариев |
| Возврат | Восстанавливается основной режим без сброса формы |

При пустом наборе показывается соответствующая заглушка. История и комментарии не изменяют активный этап и введённые значения.

## 5. Footer

`Сохранить` фиксирует текущие значения как черновик и показывает toast. Primary-кнопка недоступна, пока подтверждённые обязательные поля активного этапа не заполнены. На этапах 1–4 она называется `Подтвердить шаг`; на этапе 5 — `Завершить задачу`.

После подтверждения этап получает завершённое состояние и активируется следующий этап. Последнее подтверждение завершает демонстрационную задачу и показывает toast. Автоматического перехода без явного нажатия нет.

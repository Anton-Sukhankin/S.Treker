# Рабочая область шаблонов документов: поведение

> Статус: целевая спецификация; компонент еще не реализован ни в локальном стенде, ни в основном S-Tracker.

## 1. Основной пользовательский путь первой волны

1. Пользователь выбирает тип документа.
2. Каталог показывает шаблоны этого типа и их актуальные состояния.
3. Пользователь нажимает `Создать новый шаблон`.
4. Начальная настройка показывает полную схему атрибутов типа; обязательные атрибуты уже выбраны.
5. Пользователь выбирает дополнительные атрибуты, вводит имя и создает черновик.
6. Интерфейс подтверждает создание черновика. Продолжение в полном редакторе не входит в этот путь.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Выбирает тип | Раздел открыт | Тип активен; видны его шаблоны и счетчик. |
| 2 | Нажимает `Создать новый шаблон` | Тип выбран | Открывается начальная настройка для этого типа. |
| 3 | Ищет атрибут | Корзина загружена | Видны карточки, соответствующие имени или token; счетчик выбора не меняется. |
| 4 | Выбирает необязательный атрибут | Карточка доступна | Карточка выбрана; счетчик увеличен. |
| 5 | Вводит имя черновика | Имя пусто | Поле показывает введенное имя. |
| 6 | Нажимает `Создать черновик` | Имя валидно, обязательные атрибуты включены | Создан черновик с фиксированным набором атрибутов; интерфейс показывает подтверждение и дальнейшее действие только при наличии отдельной спецификации. |

## 3. Работа с существующим шаблоном

| Действие | Исходное состояние | Результат |
|---|---|---|
| Нажимает `Продолжить` | Есть черновик без блокирующей несовместимости | Открывается следующий доступный этап настройки этого черновика. |
| Нажимает `Исправить` | Состояние `Нужно исправить` | Открывается настройка с видимой диагностикой несовместимых атрибутов. |
| Раскрывает `Что нужно исправить` | Есть диагностика | Видны конкретные отсутствующие или измененные атрибуты. |
| Раскрывает `История` | История доступна | Открывается список событий шаблона; обязательный состав одной записи не утвержден материалами встречи. |
| Нажимает `Копировать` | Шаблон доступен для копирования | Создается отдельный черновик-копия или открывается форма имени копии; точный вариант должен быть утвержден до реализации. |

Действие `Копировать` включено как подтвержденная точка входа, но его единственный видимый итог на встрече не был определен. До решения оно не реализуется как автоматическое создание без подтверждения.

## 4. Массовые действия корзины

| Действие | Исходное состояние | Результат |
|---|---|---|
| Нажимает `Выбрать все` | Есть видимые доступные необязательные атрибуты | Все такие карточки выбраны; обязательные остаются выбранными. |
| Нажимает `Снять выбор` | Есть выбранные необязательные атрибуты | С них снят выбор; обязательные остаются выбранными. |
| Включает `Показать скрытые` | Есть скрытые схемой атрибуты | Они добавляются в видимый набор с явным признаком скрытого атрибута. |
| Пытается снять обязательный атрибут | Карточка обязательна | Выбор не меняется; карточка сообщает, что атрибут обязателен. |

## 5. Ошибки

| Ситуация | Результат |
|---|---|
| Имя черновика пусто или невалидно | Черновик не создается; поле получает конкретное сообщение. |
| Схема типа не загрузилась | Корзина показывает ошибку загрузки и действие повторения; пустая схема не считается корректным результатом. |
| Создание черновика не удалось | Пользователь остается в настройке; выбранные атрибуты и имя сохраняются. |
| Шаблон несовместим с новой схемой | Каталог показывает `Нужно исправить` и конкретную диагностику. |

## 6. Ограничение первой волны

После успешного создания черновика спецификация не описывает загрузку файла, настройку шагов, логику подстановок и публикацию. Эти действия не должны быть сымитированы без отдельного комплекта требований.

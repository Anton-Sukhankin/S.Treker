# Рабочая область шаблонов документов: данные, состояния и правила

> Статус: целевая спецификация; компонент еще не реализован ни в локальном стенде, ни в основном S-Tracker.

## 1. Владельцы состояния

| Область | Состояние | Правило видимого результата |
|---|---|---|
| Дерево типов | Выбранный тип и поиск | Каталог и корзина относятся к одному типу. |
| Каталог | Версии, состояние, диагностика и история шаблона | Каждая строка показывает один логический шаблон с опубликованной и черновой версиями. |
| Корзина | Полная схема, видимый набор, выбранные атрибуты | Поиск не снимает выбор со скрытых результатом поиска карточек. |
| Черновик | Имя и зафиксированный набор атрибутов | После создания набор не меняется без явного редактирования черновика. |
| Публикация | Готовность полного шаблона | В первой волне остается недоступной, потому что последующие настройки не специфицированы. |

## 2. Состояния шаблона в каталоге

| Состояние | Условие | Видимый результат | Основное действие |
|---|---|---|---|
| Только опубликован | Есть опубликованная версия, черновика нет, схема совместима | Показана опубликованная версия и нейтральное отсутствие черновика. | Создать изменение или копировать по отдельному решению. |
| Есть черновик | Есть незавершенная версия | Показаны опубликованная версия при наличии, номер черновика и владелец. | `Продолжить`. |
| Нужно исправить | Актуальная схема типа несовместима с версией шаблона | Показаны состояние и количество конкретных проблем. | `Исправить`. |
| Не опубликован | Есть черновик, опубликованной версии нет | Публикация показана как отсутствующая; черновик доступен для продолжения. | `Продолжить`. |
| Ошибка действия | Последнее действие не завершилось | Строка сохраняет прежнее подтвержденное состояние и показывает понятную ошибку. | Повторить допустимое действие. |

## 3. Правила атрибутов

| Правило | Условие | Видимый результат |
|---|---|---|
| Полная схема | Выбран тип документа | Корзина содержит все доступные атрибуты этого типа. |
| Обязательный атрибут | В схеме установлен признак обязательности | Карточка выбрана и недоступна для снятия выбора. |
| Необязательный атрибут | Атрибут доступен для пользовательского выбора | Пользователь может включить или исключить его из будущего шаблона. |
| Скрытый атрибут | В схеме установлен соответствующий признак | По умолчанию не виден; показывается после включения `Показать скрытые`. |
| Ссылочный атрибут | Тип `reference` | Карточка показывает источник справочника. |
| Счетчик | Загружена схема | Показывает `выбрано N из M`, где `M` — полный доступный набор, а `N` включает обязательные атрибуты. |

## 4. Правила версий и диагностики

| Данные | Источник | Правило |
|---|---|---|
| Опубликованная версия | Последний успешный выпуск | Не заменяется черновиком до публикации. |
| Черновая версия | Последнее незавершенное изменение | Имеет номер и владельца, если они доступны. |
| Дата изменения | Последнее подтвержденное изменение шаблона | Не меняется после неуспешного действия. |
| Диагностика | Сравнение используемых атрибутов с актуальной схемой | Перечисляет конкретные поля и причины, а не только общий статус. |
| История | Подтвержденные события шаблона | Сохраняет последовательность событий; обязательные поля события остаются открытым решением. |

## 5. Контракты взаимодействия

| Связанный компонент | Роль | Условие | Результат в шаблонах | Результат в связанном компоненте |
|---|---|---|---|---|
| `documents-workspace` | Получатель опубликованной версии | Шаблон опубликован, совместим и применим к типу | Каталог показывает опубликованную версию. | Шаблон появляется в выборе создания документа. |
| `lego-document-form` | Будущий получатель конфигурации | Полный редактор сохранит шаги и правила | Каталог получит новую версию после публикации. | Форма сможет строиться по опубликованной конфигурации. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Тип документа | Рабочая область не создает полную схему атрибутов и не меняет признак обязательности. |
| Полный редактор | Первая волна не описывает загрузку файла, разметку, шаги, зависимости, печатную форму и выпуск. |
| Публикация | Не становится доступной только из-за создания черновика. |
| Копирование | До решения о подтверждении и именовании копии действие не создает молча новый шаблон. |
| Документы | Каталог не создает документ и не управляет пакетами документов. |

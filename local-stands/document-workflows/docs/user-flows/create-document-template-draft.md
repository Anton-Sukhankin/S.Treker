# Flow: создание черновика Lego-шаблона

> Статус: целевой flow; еще не реализован ни в локальном стенде, ни в основном S-Tracker.

## Зачем нужен сценарий

Пользователь создает начальный черновик Lego-шаблона на основе схемы выбранного типа документа. Финальный результат первой волны: черновик существует и содержит обязательные и выбранные дополнительные атрибуты.

## Граница flow

| Граница | Значение |
|---|---|
| Начальное состояние | Открыт каталог шаблонов и выбран тип документа. |
| Конечный результат | Создан именованный черновик с зафиксированным набором атрибутов. |
| Не входит | Загрузка файла шаблона, разметка шагов, условия, подстановки, печатная форма и публикация. |

## Участники интерфейса

| Участник | Роль | Источник деталей |
|---|---|---|
| Каталог шаблонов | Точка входа и получатель нового черновика. | `docs/components/document-templates-workspace/` |
| Корзина атрибутов | Выбор подмножества полной схемы. | `docs/components/document-templates-workspace/01-structure.md`, `03-data-states-rules.md` |

## Основной сценарий

| Шаг | Действие или событие | Компонент-источник | Передаваемый результат | Компонент-получатель | Видимый итог |
|---:|---|---|---|---|---|
| 1 | Пользователь выбирает тип документа. | Дерево типов | Идентификатор типа. | Каталог | Видны шаблоны этого типа. |
| 2 | Пользователь нажимает `Создать новый шаблон`. | Каталог | Тип и полная схема атрибутов. | Начальная настройка | Корзина загружена; обязательные атрибуты выбраны. |
| 3 | Пользователь выбирает дополнительные атрибуты. | Корзина | Выбранный набор. | Счетчик и будущий черновик | Карточки и счетчик показывают актуальный выбор. |
| 4 | Пользователь вводит имя и создает черновик. | Начальная настройка | Имя, тип, выбранные атрибуты. | Каталог шаблонов | Создана строка с состоянием `Есть черновик` и доступным продолжением после появления отдельной спецификации. |

## Изменения состояния

| Состояние | Владелец | Когда меняется | Видимый результат |
|---|---|---|---|
| Выбранный тип | Дерево типов | Пользователь выбирает тип | Каталог и корзина используют одну схему. |
| Набор атрибутов | Корзина | Пользователь меняет необязательный выбор | Счетчик обновляется; обязательные остаются включены. |
| Черновик | Каталог шаблонов | Создание успешно | Видны номер черновика, владелец и состояние. |

## Evidence сценария

`TPL-E-001` подтверждает каталог и состояния строк; `TPL-E-002` подтверждает корзину и обязательные атрибуты; `TPL-E-003`–`TPL-E-005` фиксируют дефекты и границу полного редактора.

## Ветки

| Ситуация | Условие | Видимый результат |
|---|---|---|
| Пользователь снимает весь выбор | Есть обязательные атрибуты | Необязательные сняты; обязательные остаются выбранными. |
| Имя невалидно | Нажато создание | Черновик не создается; поле имени показывает причину. |
| Создание неуспешно | Получена ошибка | Выбор и имя сохраняются; доступно повторение. |

# Пользовательские пути локального стенда

| Файл | Сценарий |
|---|---|
| `create-document-from-documents-workspace.md` | Создание локального документа по ECM-форме или Lego-шаблону из выбранного пакета. |
| `complete-document-form-in-task.md` | Заполнение общей Lego-формы внутри карточки задачи. |
| `create-document-template-draft.md` | Создание черновика шаблона по схеме типа документа. |

Flow хранит только межкомпонентную последовательность. Структура, локальные действия и устойчивые правила остаются в `docs/components/<component>/` этого стенда.

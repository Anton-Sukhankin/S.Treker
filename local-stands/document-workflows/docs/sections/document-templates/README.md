# Паспорт раздела «Шаблоны документов»

## 1. Граница раздела

Раздел охватывает каталог шаблонов выбранного типа документа, версии, состояния, диагностику, историю, корзину атрибутов и создание черновика. Полный редактор после создания черновика в текущую границу не входит.

## 2. Карта реализации

| Блок | Компонент или документ | Статус перед кодом |
|---|---|---|
| Каталог и состояния шаблонов | `docs/components/document-templates-workspace/` | Целевая спецификация подготовлена. |
| Корзина атрибутов | `docs/components/document-templates-workspace/` | Начальная настройка подготовлена. |
| Создание черновика | `docs/user-flows/create-document-template-draft.md` | Путь ограничен подтвержденной частью встречи. |
| Полный редактор шаблона | Будущий отдельный блок после уточнения | Не специфицирован и не реализуется. |

## 3. Источники контекста

| Источник | Подтверждаемая область | Локальная выборка |
|---|---|---|
| `TPL-E-001` | Каталог, версии, состояния, диагностика и действия | `references/evidence/document-templates/README.md` |
| `TPL-E-002` | Корзина атрибутов и создание черновика | `references/evidence/document-templates/README.md` |
| `TPL-E-003`, `TPL-E-004` | Дефекты копирования, сообщений и неполный состав истории | `references/evidence/document-templates/README.md` |
| `TPL-E-005` | Граница полного редактора после черновика | `references/evidence/document-templates/README.md` |

Полные имена файлов, типы материалов и статус хранения находятся в `references/context-register.md`.

## 4. Задачи без излишней декомпозиции

Каталог и начальная настройка остаются зонами одного `document-templates-workspace`. Полный редактор не получает папку до появления подтвержденной границы, пользовательского пути и визуальных состояний.

## 5. Открытые решения

- Полный путь настройки шаблона после создания черновика не показан.
- Точный результат копирования и обновления каталога требует уточнения.
- Автоматический перенос существующих шаблонов остается гипотезой.

## 6. Готовность

Документационный контур и два визуальных эталона подтверждены до создания черновика. Реализация каталога и начальной настройки запланирована после раздела `Документы`; полный редактор остается за границей.

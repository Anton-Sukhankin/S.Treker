# Паспорта разделов локального стенда

Каждая дочерняя папка соответствует одному верхнеуровневому разделу стенда. Паспорт раздела связывает задачи реализации с компонентными спецификациями, пользовательскими путями и зарегистрированными источниками.

| Раздел | Паспорт | Компонент-владелец |
|---|---|---|
| `Задачи` | `tasks/README.md` | `docs/components/task-card-drawer/` |
| `Документы` | `documents/README.md` | `docs/components/documents-workspace/` |
| `Шаблоны документов` | `document-templates/README.md` | `docs/components/document-templates-workspace/` |

Паспорт не дублирует требования `01/02/03`. Если правило необходимо для генерации интерфейса, оно должно находиться в комплекте компонента. Сквозное правило через несколько компонентов дополнительно фиксируется в `docs/user-flows/`.

Отдельная папка задачи создается только тогда, когда задача образует самостоятельный компонент. Иначе задача остается строкой карты реализации в паспорте раздела.

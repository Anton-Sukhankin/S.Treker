# Паспорт раздела «Задачи»

## 1. Граница

Раздел локального стенда содержит одну демонстрационную строку и нативную карточку mock-задачи в правом drawer. Таблица, фильтры, домены и очереди основной вкладки S-Tracker не воспроизводятся.

## 2. Реализация

| Блок | Спецификация | Статус |
|---|---|---|
| Точка входа и drawer | `docs/components/task-card-drawer/` | Реализовано |
| Пять этапов формы | `docs/components/lego-document-form/` | Реализованы поля, зависимые состояния, валидация, черновик и последовательное подтверждение |
| Сквозной путь | `docs/user-flows/complete-document-form-in-task.md` | Реализован на mock-данных |
| История и комментарии | `docs/components/task-card-drawer/` | 5 и 14 позиций, inline takeover |
| Изменяемая ширина | `docs/components/task-card-drawer/` | `520–1100 px`, база `740 px` |

Полный реестр материалов расположен в `references/context-register.md`; разделённые доказательства — в `references/evidence/tasks/README.md` и `references/evidence/shared/README.md`.

## 4. Текущие ограничения

- Завершение задачи и сохранение черновика работают на локальном состоянии без backend.
- Самостоятельная сводка не открывается внутри карточки задачи.
- Интеграция в основной S-Tracker выполняется отдельной задачей после приёмки локального стенда.

## 5. Запуск

Рабочая точка входа: `local-stands/tasks/index.html` через локальный Vite-сервер. Runtime находится только в `local-stands/src`; документы — только в `local-stands/document-workflows`.

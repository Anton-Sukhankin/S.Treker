# Исследовательский контекст

`meeting-findings.md` хранит источники, последовательность встречи, подтвержденные решения, замечания, гипотезы и открытые вопросы.

Стабильные идентификаторы исходных файлов и временных интервалов находятся в `references/context-register.md`. Разделенные по функциональным областям факты находятся в `references/evidence/`; исследовательский документ не создает второй каталог источников.

Материалы этой папки не являются экспортируемой спецификацией интерфейса. Подтвержденное решение переносится в соответствующий комплект `docs/components/<component>/01/02/03` и только после этого используется при реализации.

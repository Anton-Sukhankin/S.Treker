# Миграционный шлюз в основной S-Tracker

Пошаговый план переноса рабочей области документов из MagicPath в нативный runtime локального стенда: [`documents-workspace-migration-plan.md`](documents-workspace-migration-plan.md).

Завершенный план инкремента выбора типа нового документа как нижнего drawer: [`new-document-type-picker-drawer-migration-plan.md`](new-document-type-picker-drawer-migration-plan.md).

Выполненный план объединения самостоятельного Lego-сценария с локальным стендом `Документы`: [`lego-to-documents-workspace-migration-plan.md`](lego-to-documents-workspace-migration-plan.md).

## 1. Главный принцип

Стенд не является runtime-частью основного S-Tracker. Перенос выполняется только отдельной задачей и только для одного завершенного функционального блока.

## 2. Условия готовности блока

| Проверка | Требуемый результат |
|---|---|
| Спецификация | Комплект `01/02/03` отражает фактическое поведение стенда и прошел аудит. |
| Пользовательский путь | Основной путь и применимые ветки проверены в стенде. |
| Код | Нет импорта feature-, domain- и data-runtime основного S-Tracker; общие UI-компоненты получены через `@s-tracker/ui`, второй реализации общей Lego-логики и базовых контролов нет. |
| Данные | Mock-данные отделены от правил; определена будущая точка подключения к данным S-Tracker. |
| Стили | Стили ограничены областью компонента и не меняют соседние разделы. |
| Регрессия | Определены проверки действующих сценариев основного прототипа, которые нельзя сломать. |
| Визуальные эталоны | Готовые состояния находятся в папке компонента и совпадают со спецификацией. |

## 3. Правило переноса

1. Выбрать один готовый блок.
2. Сопоставить локальные файлы стенда с будущими файлами основного проекта.
3. Перенести код и документацию одной согласованной операцией, без сохранения второй активной копии.
4. Подключить блок к основному runtime только после переноса его данных и контрактов.
5. Выполнить сборку и регрессионные проверки S-Tracker.
6. После успешной проверки удалить мигрированный активный код из стенда или оставить только явно архивный исследовательский материал по отдельному решению.

## 4. Запрет преждевременной интеграции

До выполнения условий запрещено добавлять ссылки на целевые компоненты стенда в каталоги действующей документации, импортировать стенд из корневого `src/` или копировать реализацию «временно» в оба места.

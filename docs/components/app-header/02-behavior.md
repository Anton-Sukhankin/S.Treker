# Верхняя навигация приложения: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает S-Tracker.
2. Пункт `Задачи` находится в активном состоянии.
3. Рабочая область задач видна под хедером.
4. Пользователь выбирает пункт `Поиск`.
5. Пункт `Поиск` получает активное состояние.
6. Рабочая область задач скрыта.
7. Рабочая область поиска видна под хедером.
8. Пользователь выбирает пункт `Задачи`.
9. Пункт `Задачи` получает активное состояние.
10. Рабочая область поиска скрыта.
11. Рабочая область задач видна под хедером.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Открытие приложения | Приложение не загружено | Активен пункт `Задачи`; рабочая область задач видна. |
| 2 | Выбор пункта `Поиск` | Активен пункт `Задачи`; рабочая область задач видна | Активен пункт `Поиск`; рабочая область задач скрыта; рабочая область поиска видна. |
| 3 | Выбор пункта `Задачи` | Активен пункт `Поиск`; рабочая область поиска видна | Активен пункт `Задачи`; рабочая область поиска скрыта; рабочая область задач видна. |

## 3. Вторичные механики

### Закрытие слоев задач при переходе в поиск

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Выбор пункта `Поиск` | В рабочей области задач открыт дровер, модальное окно, выпадающий список или плавающая панель выбора задач | Открытые слои задач закрыты; выбранные задачи сняты; рабочая область поиска видна. |

### Видимые пункты без переключения рабочей области

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Выбор `Документы`, `Архив`, `Отчеты`, `Шаблоны` или `Пользователи` | Активен `Задачи` или `Поиск` | Текущая рабочая область остается без изменения в текущем прототипе. |

## 4. Короткие внешние результаты

| Действие в текущем компоненте | Компонент-получатель | Видимый результат |
|---|---|---|
| Выбор `Задачи` | Рабочая область задач | Компоненты задач видны под хедером. |
| Выбор `Поиск` | Рабочая область поиска | Рабочая область поиска видна под хедером. |

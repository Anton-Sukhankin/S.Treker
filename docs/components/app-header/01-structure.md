# Верхняя навигация приложения: структура

## 1. Расположение

| Условие | Область интерфейса | Видимый результат |
|---|---|---|
| Приложение открыто | Верхняя фиксированная область над рабочим содержимым | Видны бренд `S-Tracker`, иконки слева, навигационные пункты и пользовательская зона справа. |

## 2. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Бренд `S-Tracker` | Часть компонента | Отображается в левой части верхней навигации. |
| Навигационные пункты | Часть компонента | Отображаются в одной горизонтальной строке. |
| Пункт `Задачи` | Часть компонента и источник состояния раздела | При активном состоянии показывает рабочую область задач. |
| Пункт `Поиск` | Часть компонента и источник состояния раздела | При активном состоянии показывает рабочую область поиска. |
| Рабочая область задач | Внешний получатель результата | Получает видимость при активном пункте `Задачи`. |
| Рабочая область поиска | Внешний получатель результата | Получает видимость при активном пункте `Поиск`. |
| Внутренний интерфейс задач | Не входит | Описывается в `left-navigation`, `toolbar`, `queues`, `tasks`, `filters`, `column-settings`, `bulk-actions`, `pagination`. |
| Внутренний интерфейс поиска | Не входит | Описывается в комплекте рабочей области поиска и детальных комплектов документного поиска. |

## 3. Визуальный эталон

| Состояние компонента | Зарезервированный путь | Что должно быть видно на эталоне |
|---|---|---|
| Активны `Задачи` | `assets/app-header-tasks-active.png` | Верхняя навигация; пункт `Задачи` выделен; рабочая область задач видна ниже хедера. |
| Активен `Поиск` | `assets/app-header-search-active.png` | Верхняя навигация; пункт `Поиск` выделен; рабочая область поиска видна ниже хедера. |

## 4. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Состав | Что не входит |
|---|---|---|---|---|---|
| Левая зона хедера | Левый край верхней области | Навигационные пункты справа | Приложение открыто | Иконки продукта, бренд `S-Tracker` | Левая навигация задач. |
| Навигационная зона | Центральная часть верхней области после бренда | Бренд слева, пользовательская зона справа | Приложение открыто | `Задачи`, `Документы`, `Архив`, `Поиск`, `Отчеты`, `Шаблоны`, `Пользователи` | Рабочее содержимое выбранного раздела. |
| Активный пункт | Внутри навигационной зоны | Остальные пункты той же строки | Выбран раздел `Задачи` или `Поиск` | Один пункт с активной индикацией | Счетчики и данные рабочего раздела. |
| Пользовательская зона | Правый край верхней области | Навигационная зона слева | Приложение открыто | Иконка уведомления, аватар или пользовательская индикация | Настройки пользователя как отдельный сценарий. |

## 5. Элементы и условия показа

| Элемент | Условие показа | Видимое состояние |
|---|---|---|
| `Задачи` | Приложение открыто | Пункт виден; активен при открытой рабочей области задач. |
| `Поиск` | Приложение открыто | Пункт виден; активен при открытой рабочей области поиска. |
| `Документы`, `Архив`, `Отчеты`, `Шаблоны`, `Пользователи` | Приложение открыто | Пункты видны; в текущем прототипе не меняют рабочую область S-Tracker. |

## 6. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| Рабочая область поиска | Получатель результата | Рабочая область поиска занимает место под хедером вместо области задач. | `search-workspace/02-behavior.md`, `search-workspace/03-data-states-rules.md`. |
| Компоненты рабочей области задач | Получатели результата | При активном пункте `Задачи` рабочая область задач видна под хедером. | `left-navigation`, `toolbar`, `queues`, `tasks`, `pagination`, `filters`, `column-settings`, `bulk-actions`. |

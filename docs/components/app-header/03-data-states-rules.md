# Верхняя навигация приложения: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Верхняя навигация | Активный раздел | Один пункт навигации имеет активную индикацию. |
| Рабочая область задач | Видимость задач | Видна при активном пункте `Задачи`; скрыта при активном пункте `Поиск`. |
| Рабочая область поиска | Видимость поиска | Видна при активном пункте `Поиск`; скрыта при активном пункте `Задачи`. |
| Компоненты задач | Открытые слои и выбранные задачи | При переходе в `Поиск` слои задач закрыты, выбранный набор задач очищен. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| `Задачи` активны | Приложение открыто или пользователь выбрал `Задачи` | Рабочая область задач видна; рабочая область поиска скрыта. | Пользователь выбирает `Поиск`. |
| `Поиск` активен | Пользователь выбрал `Поиск` | Рабочая область задач скрыта; рабочая область поиска видна. | Пользователь выбирает `Задачи`. |
| Нереализованный раздел выбран | Пользователь выбирает пункт без рабочего раздела в текущем прототипе | Текущая активная рабочая область остается без изменения. | Пользователь выбирает `Задачи` или `Поиск`. |

## 3. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| Рабочая область задач | Получатель состояния раздела | Активен пункт `Задачи` | `Задачи` имеет активную индикацию | Компоненты задач видны под хедером. |
| Рабочая область поиска | Получатель состояния раздела | Активен пункт `Поиск` | `Поиск` имеет активную индикацию | Рабочая область поиска видна под хедером. |
| Компоненты задач | Источник открытых слоев | Пользователь выбирает `Поиск` при открытом слое задач | `Поиск` получает активную индикацию | Открытые слои задач закрыты; выбор задач очищен. |

## 4. Ограничения ответственности

| Область | Правило |
|---|---|
| Список задач | Верхняя навигация не рассчитывает набор задач, очереди, фильтры, колонки или пагинацию. |
| Рабочая область поиска | Верхняя навигация не рассчитывает документы, фильтры поиска, связанные документы, настройки колонок поиска или массовые действия документов. |
| Нереализованные пункты | Верхняя навигация не создает рабочие области для пунктов, которые не имеют реализации в текущем прототипе. |

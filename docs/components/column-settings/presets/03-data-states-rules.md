# Пресеты колонок: данные, состояния и правила

Этот файл фиксирует состояния и контракты дочерней зоны `Пресеты колонок`. Сохраненный пресет хранит набор настраиваемых колонок текущего контекста: общие атрибуты и атрибуты, добавленные из `Библиотека атрибутов`. Черновик колонок, футер действий и примененное состояние таблицы принадлежат родительской панели `Настройки колонок`.

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| `Пресеты колонок` | Список сохраненных пресетов текущего контекста; выбранный пункт; раскрытие выпадающего списка; открытие модального окна сохранения | Поле текущего пресета и выпадающий список показывают только пункты текущего контекста. |
| `Настройки колонок` | Черновик колонок; футер действий `По умолчанию` и `Применить`; примененное состояние таблицы | Выбор и удаление пресета меняют черновик родителя; таблица задач меняется только после `Применить` в футере родителя. |
| `Общие атрибуты` | Видимый список колонок из черновика родителя | После выбора `Базовое отображение` список показывает базовый набор текущего контекста; после выбора сохраненного пресета список показывает набор из пресета. |
| `Библиотека атрибутов` | Индикация атрибутов, добавленных в черновик или сохраненный пресет | При раскрытой библиотеке добавленные из библиотеки атрибуты показывают кнопку действия со стрелкой назад; при выборе базы доступные строки показывают кнопку действия с иконкой плюса. |
| Табличный список задач | Примененный набор динамических колонок | Таблица сохраняет прежний набор после выбора, сохранения или удаления пресета и получает новый набор только после `Применить` в футере родителя. |

## 2. Термины состояния

| Термин | Значение в `Пресеты колонок` | Видимый результат |
|---|---|---|
| Текущий контекст | `Все задачи`, выбранный бизнес-домен, пользовательская группа или родительская область значения группировки | Выпадающий список показывает только пресеты этого контекста. |
| Базовое отображение | Базовый набор общих атрибутов текущего контекста без атрибутов, добавленных из библиотеки | Поле текущего пресета показывает `Базовое отображение`; список `Общие атрибуты` показывает базовый набор. |
| Сохраненный пресет | Именованный набор настраиваемых колонок текущего контекста | В выпадающем списке виден пункт с названием пресета и кнопкой удаления. |
| Выбранный пресет | Пункт, название которого показано в поле текущего пресета | В выпадающем списке этот пункт имеет выбранное состояние. |
| Черновик родителя | Временный набор колонок открытой панели до `Применить` | Список колонок в `Общие атрибуты` показывает черновик; таблица задач сохраняет примененное состояние. |

## 3. Контекст пресета

| Текущая область левой навигации | Контекст сохранения и показа пресета |
|---|---|
| `Все задачи` | Пресет сохраняется и показывается в контексте `Все задачи`. |
| Конкретный бизнес-домен | Пресет сохраняется и показывается в контексте выбранного бизнес-домена. |
| Пользовательская группа | Пресет сохраняется и показывается в контексте выбранной пользовательской группы. |
| Значение группировки внутри `Все задачи` | Пресет сохраняется и показывается в контексте `Все задачи`, а не отдельного значения группировки. |
| Значение группировки внутри бизнес-домена | Пресет сохраняется и показывается в контексте родительского бизнес-домена, а не отдельного значения группировки. |

Пресет одного контекста не виден в выпадающем списке другого контекста.

## 4. Состав состояния сохраненного пресета

| Составляющая | Правило | Видимый результат после выбора пресета |
|---|---|---|
| Общий атрибут | Пресет хранит наличие, порядок и видимость общей настраиваемой колонки текущего контекста | В `Общие атрибуты` колонка видна в сохраненном порядке и с сохраненной видимостью. |
| Атрибут из `Библиотека атрибутов` | Пресет хранит наличие, порядок и видимость атрибута, который был добавлен из библиотеки перед сохранением | В `Общие атрибуты` этот атрибут виден в сохраненном порядке и показывает кнопку действия со стрелкой возврата. |
| Видимость колонки | Значение `видима` включает колонку в применяемый набор; значение `скрыта` исключает колонку из применяемого набора | После `Применить` в футере родителя таблица получает только колонки со значением `видима`. |
| Порядок колонок | Порядок записей в пресете задает порядок настраиваемых колонок в черновике родителя | В `Общие атрибуты` список колонок показывает порядок из выбранного пресета. |

Закрепленные колонки выбора строки, номера задачи и наименования задачи не входят в состояние пресета.

## 5. Состояния компонента

| Состояние | Условие | Видимый результат |
|---|---|---|
| Выбрано `Базовое отображение` | Поле текущего пресета содержит `Базовое отображение` | Список `Общие атрибуты` показывает базовый набор текущего контекста; добавленные из библиотеки атрибуты отсутствуют. |
| Выбран сохраненный пресет | Поле текущего пресета содержит название сохраненного пресета | Список `Общие атрибуты` показывает состав, порядок и видимость из пресета. |
| Выпадающий список закрыт | Поле текущего пресета не раскрыто | Под полем нет списка пунктов; поле сохраняет текст выбранного пресета или `Базовое отображение`. |
| Выпадающий список открыт | Поле текущего пресета раскрыто | Под полем виден пункт `Базовое отображение` и сохраненные пресеты текущего контекста. |
| Модальное окно сохранения открыто | Пользователь нажал активную кнопку `Сохранить` | Видны заголовок `Сохранение пресета`, поле `Название пресета`, кнопки `Отмена` и `Подтвердить`. |
| Модальное окно сохранения закрыто | Пользователь отменил сохранение, закрыл окно или подтвердил непустое название | Модальный слой не виден; строка пресетов остается в области `Общие атрибуты`. |

## 6. Доступность кнопки `Сохранить`

| Условие черновика родителя | Состояние кнопки `Сохранить` |
|---|---|
| Состав, порядок и видимость колонок совпадают с выбранным сохраненным пресетом | Неактивна. |
| Состав, порядок и видимость колонок совпадают с `Базовое отображение`, когда выбран пункт `Базовое отображение` | Неактивна. |
| Отличается состав общих атрибутов | Активна. |
| Отличается состав атрибутов, добавленных из библиотеки | Активна. |
| Отличается порядок минимум одной настраиваемой колонки | Активна. |
| Отличается видимость минимум одной настраиваемой колонки | Активна. |

## 7. Правила сохранения

| Условие | Видимый результат |
|---|---|
| Пользователь подтвердил пустое название | Модальное окно остается открытым; список пресетов сохраняет прежний состав; поле текущего пресета сохраняет прежний текст. |
| Пользователь подтвердил новое название | В выпадающем списке текущего контекста виден новый пункт с этим названием; поле текущего пресета показывает это название. |
| Пользователь подтвердил название существующего пресета текущего контекста | В выпадающем списке остается один пункт с этим названием; его сохраненный набор получает состояние текущего черновика родителя. |
| Черновик родителя содержит атрибуты из `Библиотека атрибутов` | Сохраненный пресет получает эти атрибуты вместе с общими атрибутами, порядком и видимостью. |
| Пресет сохранен без `Применить` | Таблица задач сохраняет прежний примененный набор колонок. |

## 8. Правила выбора

| Выбранный пункт | Состояние черновика родителя | Состояние `Общие атрибуты` | Состояние `Библиотека атрибутов` |
|---|---|---|---|
| `Базовое отображение` | Черновик получает базовый набор текущего контекста. | Список показывает базовые общие атрибуты; атрибуты, добавленные из библиотеки, отсутствуют. | Если библиотека раскрыта, доступные строки показывают кнопку действия с иконкой плюса. |
| Сохраненный пресет без атрибутов из библиотеки | Черновик получает состав, порядок и видимость из пресета. | Список показывает общие атрибуты из пресета. | Если библиотека раскрыта, доступные строки показывают кнопку действия с иконкой плюса. |
| Сохраненный пресет с атрибутами из библиотеки | Черновик получает общие атрибуты и атрибуты из библиотеки, сохраненные в пресете. | Список показывает общие атрибуты и добавленные из библиотеки атрибуты; добавленные из библиотеки атрибуты показывают кнопку действия со стрелкой возврата. | Если библиотека раскрыта, строки этих атрибутов показывают кнопку действия со стрелкой назад вместо кнопки действия с иконкой плюса. |

При любом выборе пресета таблица задач сохраняет прежний примененный набор колонок до `Применить` в футере родителя.

## 9. Правила удаления

| Условие удаления | Состояние списка пресетов | Состояние поля текущего пресета | Состояние черновика родителя | Состояние таблицы задач |
|---|---|---|---|---|
| Удаляется невыбранный сохраненный пресет | Пункт пресета исчезает из выпадающего списка. | Поле сохраняет прежний текст. | Черновик сохраняет состав до удаления пресета. | Таблица сохраняет прежний примененный набор колонок. |
| Удаляется выбранный сохраненный пресет | Пункт пресета исчезает из выпадающего списка. | Поле получает текст `Базовое отображение`. | Черновик получает базовый набор текущего контекста. | Таблица сохраняет прежний примененный набор колонок до следующего `Применить`. |
| После удаления сохраненных пресетов в текущем контексте не осталось | В выпадающем списке виден только пункт `Базовое отображение`. | Поле показывает `Базовое отображение`, если удаленный пресет был выбран; иначе поле сохраняет прежний текст. | Черновик меняется только при удалении выбранного пресета. | Таблица сохраняет прежний примененный набор колонок. |

У пункта `Базовое отображение` нет кнопки удаления.

## 10. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в `Пресеты колонок` | Результат в связанном компоненте |
|---|---|---|---|---|
| `Настройки колонок` | Родительский владелец черновика | Пользователь выбирает `Базовое отображение` | Поле текущего пресета показывает `Базовое отображение`. | Черновик родителя получает базовый набор текущего контекста. |
| `Настройки колонок` | Родительский владелец черновика | Пользователь выбирает сохраненный пресет | Поле текущего пресета показывает название выбранного пресета. | Черновик родителя получает общие атрибуты, атрибуты из библиотеки, порядок и видимость из пресета. |
| `Настройки колонок` | Источник черновика для сохранения | Пользователь подтверждает сохранение с непустым названием | Список пресетов текущего контекста получает новый пункт или обновляет существующий пункт; поле текущего пресета показывает подтвержденное название. | Черновик родителя сохраняет текущий состав, порядок и видимость; таблица задач не меняется до `Применить`. |
| `Настройки колонок` | Родительский владелец футера | Пользователь нажимает `По умолчанию` в футере родителя | Пресеты не создают новый пункт и не открывают модальное окно сохранения. | Черновик родителя получает базовый набор текущего контекста; таблица задач не меняется до `Применить`. |
| `Настройки колонок` | Родительский владелец примененного состояния | Пользователь нажимает `Применить` в футере родителя | Пресеты не создают, не удаляют и не переименовывают пункты. | Таблица задач получает состав, порядок и видимость колонок из текущего черновика родителя. |
| `Общие атрибуты` | Получатель набора колонок из выбранного пресета | Пользователь выбирает сохраненный пресет | Пресет остается выбранным. | Список показывает общие атрибуты и добавленные из библиотеки атрибуты из пресета. |
| `Библиотека атрибутов` | Получатель признака атрибутов, добавленных из библиотеки | Пользователь выбирает сохраненный пресет с атрибутами из библиотеки | Пресет остается выбранным. | При раскрытой библиотеке строки этих атрибутов показывают кнопку действия со стрелкой назад. |
| Табличный список задач | Получатель примененного состояния родителя | Пользователь выбирает, сохраняет или удаляет пресет без `Применить` | Список пресетов, выбранный пункт или черновик родителя меняется. | Таблица сохраняет прежний примененный набор колонок. |

## 11. Ограничения ответственности

| Область | Правило |
|---|---|
| Футер `Настройки колонок` | Не входит в `Пресеты колонок`; кнопки `По умолчанию` и `Применить` выполняют действия родительской панели. |
| Черновик колонок | Принадлежит родителю `Настройки колонок`; пресеты выбирают, сохраняют или удаляют состояние относительно этого черновика, но не применяют его к таблице напрямую. |
| Табличный вид | Получает новый набор колонок только после `Применить` в футере родителя. |
| Карточный вид | Не меняется при выборе, сохранении или удалении пресета. |
| Данные задач | Не меняются при выборе, сохранении или удалении пресета. |
| Значения атрибутов | Не меняются при выборе, сохранении или удалении пресета. |
| Фильтры и поиск | Не меняются при выборе, сохранении или удалении пресета. |
| `Библиотека атрибутов` | Не удаляет атрибуты при сохранении, выборе или удалении пресета; меняется только индикация строк, добавленных в черновик или сохраненный пресет. |
| Сохраненные пресеты | Доступны в рамках текущей работы страницы. |

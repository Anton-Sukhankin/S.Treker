# Пресеты колонок: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает панель `Настройки колонок` из табличного вида списка задач.
2. В области `Общие атрибуты` поле текущего пресета показывает `Базовое отображение` или название выбранного сохраненного пресета текущего контекста.
3. Пользователь меняет черновик колонок: скрывает колонку, показывает колонку, меняет порядок или добавляет атрибут из `Библиотека атрибутов`.
4. Кнопка `Сохранить` в строке пресетов становится активной.
5. Пользователь нажимает активную кнопку `Сохранить`.
6. Поверх открытой панели и таблицы задач видно модальное окно `Сохранение пресета`.
7. Пользователь вводит непустое название пресета и нажимает `Подтвердить`.
8. Модальное окно закрыто; в выпадающем списке текущего контекста виден пресет с введенным названием; поле текущего пресета показывает введенное название.
9. Таблица задач сохраняет прежний набор колонок до нажатия `Применить` в футере родительской панели.

## 2. Раскрытие списка пресетов

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по полю текущего пресета | Выпадающий список закрыт | Под полем текущего пресета виден выпадающий список с пунктом `Базовое отображение` и сохраненными пресетами текущего контекста. |
| Клик по полю текущего пресета | Выпадающий список открыт | Выпадающий список закрыт; поле текущего пресета сохраняет прежний текст. |
| Клик вне поля текущего пресета и выпадающего списка | Выпадающий список открыт | Выпадающий список закрыт; поле текущего пресета сохраняет прежний текст. |

## 3. Выбор `Базовое отображение`

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по пункту `Базовое отображение` | Выпадающий список открыт | Поле текущего пресета получает текст `Базовое отображение`; список колонок в `Общие атрибуты` получает базовый набор текущего контекста; выпадающий список закрыт. |
| Клик по пункту `Базовое отображение` | До клика был выбран сохраненный пресет | Выбранный сохраненный пресет теряет выбранное состояние; пункт `Базовое отображение` становится текущим пунктом поля. |
| Клик по пункту `Базовое отображение` | В черновике были атрибуты, добавленные из библиотеки | В `Общие атрибуты` виден базовый набор родительских общих атрибутов текущего контекста; добавленные из библиотеки атрибуты в этом списке отсутствуют. |
| Клик по пункту `Базовое отображение` | `Библиотека атрибутов` раскрыта | Доступные строки библиотеки показывают кнопку действия с иконкой плюса. |
| Клик по пункту `Базовое отображение` | Таблица задач видна за панелью | Таблица задач сохраняет прежний примененный набор колонок до `Применить` в футере родителя. |

## 4. Выбор сохраненного пресета

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по сохраненному пресету | Выпадающий список открыт | Поле текущего пресета получает название выбранного пресета; список колонок в `Общие атрибуты` получает состав, порядок и видимость из выбранного пресета; выпадающий список закрыт. |
| Клик по сохраненному пресету | Пресет содержит общие атрибуты и атрибуты, добавленные из библиотеки | В `Общие атрибуты` видны общие атрибуты пресета и добавленные из библиотеки атрибуты; добавленные из библиотеки атрибуты показывают кнопку действия со стрелкой возврата. |
| Клик по сохраненному пресету | Пресет содержит атрибуты, добавленные из библиотеки, и `Библиотека атрибутов` раскрыта | В библиотеке строки этих атрибутов показывают кнопку действия со стрелкой назад вместо кнопки действия с иконкой плюса. |
| Клик по сохраненному пресету | Таблица задач видна за панелью | Таблица задач сохраняет прежний примененный набор колонок до `Применить` в футере родителя. |

## 5. Доступность кнопки `Сохранить`

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Скрытие или показ колонки | Черновик родителя отличается от выбранного пресета или `Базовое отображение` по видимости минимум одной колонки | Кнопка `Сохранить` активна. |
| Изменение порядка колонок | Черновик родителя отличается от выбранного пресета или `Базовое отображение` по порядку колонок | Кнопка `Сохранить` активна. |
| Добавление атрибута из `Библиотека атрибутов` | Черновик родителя отличается от выбранного пресета или `Базовое отображение` по составу колонок | Кнопка `Сохранить` активна. |
| Возврат черновика к выбранному пресету или `Базовое отображение` | Состав, порядок и видимость колонок совпадают с выбранным пресетом или базой | Кнопка `Сохранить` неактивна. |

## 6. Открытие модального окна сохранения

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по активной кнопке `Сохранить` | Панель `Настройки колонок` открыта; черновик родителя отличается от выбранного пресета или базы | Видно модальное окно `Сохранение пресета`; поле `Название пресета` пустое; строка пресетов, список колонок, футер родителя и таблица задач остаются позади модального слоя. |
| Клик по неактивной кнопке `Сохранить` | Черновик родителя совпадает с выбранным пресетом или базой | Модальное окно не открывается; поле текущего пресета сохраняет прежний текст. |

## 7. Подтверждение сохранения

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по `Подтвердить` | Поле `Название пресета` пустое | Модальное окно остается открытым; выпадающий список пресетов сохраняет прежний состав. |
| Клик по `Подтвердить` | Поле `Название пресета` содержит новое название | Модальное окно закрыто; в выпадающем списке текущего контекста виден пресет с введенным названием; поле текущего пресета показывает введенное название. |
| Клик по `Подтвердить` | Поле `Название пресета` содержит название существующего пресета текущего контекста | Модальное окно закрыто; существующий пункт с этим названием остается единственным пунктом с таким названием; его сохраненный набор получает состояние текущего черновика родителя. |
| Клик по `Подтвердить` | Черновик родителя содержит атрибуты, добавленные из библиотеки | Сохраненный пресет получает эти атрибуты; в `Общие атрибуты` эти атрибуты показывают кнопку действия со стрелкой возврата. |
| Клик по `Подтвердить` | Таблица задач видна за панелью | Таблица задач сохраняет прежний примененный набор колонок до `Применить` в футере родителя. |

## 8. Закрытие модального окна без сохранения

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке закрытия в хедере модального окна | Модальное окно открыто | Модальное окно закрыто; список пресетов сохраняет прежний состав; черновик колонок родителя сохраняет состав до закрытия окна. |
| Клик по `Отмена` | Модальное окно открыто | Модальное окно закрыто; список пресетов сохраняет прежний состав; черновик колонок родителя сохраняет состав до отмены. |

## 9. Удаление пресета

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке удаления у сохраненного пресета | Удаляемый пресет не выбран | Пункт пресета исчезает из выпадающего списка; поле текущего пресета сохраняет прежний текст; черновик колонок родителя сохраняет состав до удаления пресета. |
| Клик по кнопке удаления у сохраненного пресета | Удаляемый пресет выбран | Пункт пресета исчезает из выпадающего списка; поле текущего пресета получает текст `Базовое отображение`; список колонок в `Общие атрибуты` получает базовый набор текущего контекста. |
| Клик по кнопке удаления у сохраненного пресета | Удаляемый пресет был ранее применен к таблице | Таблица задач сохраняет текущий примененный набор колонок до следующего `Применить` в футере родителя. |
| Клик по кнопке удаления у сохраненного пресета | После удаления сохраненных пресетов в текущем контексте не осталось | В выпадающем списке виден только пункт `Базовое отображение`. |

У пункта `Базовое отображение` нет кнопки удаления.

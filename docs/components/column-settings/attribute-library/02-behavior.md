# Библиотека атрибутов: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает панель `Настройки колонок`.
2. Пользователь нажимает кнопку библиотеки в родительском футере.
3. Слева от `Общие атрибуты` становится видима область `Библиотека атрибутов`.
4. В области `Библиотека атрибутов` видны хедер, поле `Поиск атрибута...` и список доступных атрибутов.
5. Пользователь находит нужный атрибут в списке или вводит текст в поле `Поиск атрибута...`.
6. Пользователь нажимает кнопку действия с иконкой плюса у нужного атрибута.
7. Строка выбранного атрибута остается в списке библиотеки; кнопка действия в этой строке показывает иконку стрелки назад.
8. В конце списка `Общие атрибуты` видна строка выбранного атрибута; в этой строке видна кнопка действия с иконкой стрелки назад.
9. Табличный список задач сохраняет прежний состав колонок.
10. Пользователь нажимает `Применить` в родительской панели `Настройки колонок`.
11. Панель `Настройки колонок` закрывается.
12. Табличный список задач показывает новую колонку.

## 2. Открытие и закрытие библиотеки

| Действие пользователя | Исходное состояние | Итог в библиотеке | Итог во внешних областях |
|---|---|---|---|
| Нажимает кнопку библиотеки в родительском футере | Панель `Настройки колонок` открыта, библиотека закрыта | Слева от `Общие атрибуты` видна область `Библиотека атрибутов` с поиском и списком доступных атрибутов | Родительский футер остается внешней нижней областью панели; табличный список задач не меняет колонки. |
| Нажимает кнопку библиотеки повторно | Библиотека открыта | Область `Библиотека атрибутов` скрыта; поле поиска и список атрибутов не видны | `Общие атрибуты` остаются единственной рабочей областью тела панели; табличный список задач не меняет колонки. |
| Закрывает всю панель `Настройки колонок` без `Применить` | Библиотека открыта или закрыта, в черновике есть непримененные изменения | Библиотека скрыта вместе с панелью | Табличный список задач сохраняет прежние колонки. |

## 3. Поиск атрибута

| Действие пользователя | Исходное состояние | Итог в списке библиотеки |
|---|---|---|
| Вводит текст в поле `Поиск атрибута...` | Библиотека открыта, поле поиска пустое или содержит другой текст | Список показывает только доступные атрибуты, название которых содержит введенный текст. |
| Очищает поле `Поиск атрибута...` | Библиотека открыта, в поле есть введенный текст | Список показывает все доступные атрибуты выбранной области задач. |
| Вводит текст без совпадений | Библиотека открыта | На месте списка виден текст `Атрибуты не найдены`; строки атрибутов не видны. |
| Нажимает кнопку действия с иконкой плюса у атрибута при активном поиске | Атрибут виден в результатах текущего поиска | Атрибут остается в результатах текущего поиска; кнопка действия у этого атрибута показывает иконку стрелки назад. |

Поиск работает только внутри `Библиотека атрибутов`. Ввод в поле `Поиск атрибута...` не меняет `Общие атрибуты`, фильтры задач, выбранный бизнес-домен, режим `Все задачи` и табличный список задач.

## 4. Добавление атрибута

| Действие пользователя | Исходное состояние | Итог в библиотеке | Итог в `Общие атрибуты` | Итог в таблице задач |
|---|---|---|---|---|
| Нажимает кнопку действия с иконкой плюса у атрибута | Атрибут виден в списке библиотеки и не добавлен в черновик | Строка атрибута остается в списке; кнопка действия у этого атрибута показывает иконку стрелки назад | В конце списка колонок видна строка добавленного атрибута с кнопкой действия с иконкой стрелки назад | Таблица не меняет колонки. |
| Добавляет первый атрибут из библиотеки | В черновике нет библиотечных добавлений | У добавленного атрибута кнопка действия показывает иконку стрелки назад | В `Общие атрибуты` видна одна новая строка библиотечного атрибута | Таблица не меняет колонки. |
| Добавляет несколько атрибутов | В черновике уже есть минимум один библиотечный атрибут | У каждого добавленного атрибута кнопка действия показывает иконку стрелки назад | В конце списка колонок видны строки всех добавленных библиотечных атрибутов | Таблица не меняет колонки. |
| Нажимает `Применить` после добавления | В черновике есть минимум один добавленный библиотечный атрибут | Библиотека скрывается вместе с панелью `Настройки колонок` | Черновик становится примененным состоянием родительской панели | Таблица показывает добавленные колонки. |

## 5. Возврат атрибута в библиотеку

| Действие пользователя | Исходное состояние | Итог в `Общие атрибуты` | Итог в библиотеке | Итог в таблице задач |
|---|---|---|---|---|
| Нажимает кнопку действия с иконкой стрелки назад у добавленного атрибута в `Общие атрибуты` | Атрибут добавлен из библиотеки и виден в `Общие атрибуты` | Строка атрибута удаляется из списка колонок черновика | Если атрибут проходит текущий поиск, его строка видна с кнопкой действия с иконкой плюса | Таблица не меняет колонки. |
| Нажимает кнопку действия с иконкой стрелки назад у добавленного атрибута в библиотеке | Атрибут добавлен из библиотеки и виден в списке библиотеки | Строка атрибута удаляется из списка колонок черновика | Строка атрибута остается в библиотеке; кнопка действия показывает иконку плюса | Таблица не меняет колонки. |
| Возвращает последний добавленный библиотечный атрибут | В черновике есть один библиотечный атрибут | В `Общие атрибуты` не остается библиотечных добавлений | У возвращенного атрибута кнопка действия показывает иконку плюса | Таблица не меняет колонки. |
| Нажимает `Применить` после возврата | Возвращенный атрибут не виден в `Общие атрибуты` | Черновик без возвращенного атрибута становится примененным состоянием | Библиотека скрывается вместе с панелью | Таблица не показывает возвращенную колонку. |

## 6. Сброс библиотечных добавлений

Кнопка `Сбросить` находится в родительском футере `Настройки колонок`. Для библиотеки она является внешним действием, которое удаляет из черновика только атрибуты, добавленные из библиотеки.

| Условие | Состояние кнопки `Сбросить` в родительском футере |
|---|---|
| Библиотека закрыта | Кнопка `Сбросить` не видна. |
| Библиотека открыта, библиотечных добавлений в черновике нет | Кнопка `Сбросить` видна в неактивном состоянии. |
| Библиотека открыта, в черновике есть минимум один библиотечный атрибут | Кнопка `Сбросить` активна. |

| Действие пользователя | Исходное состояние | Итог в `Общие атрибуты` | Итог в библиотеке | Итог в таблице задач |
|---|---|---|---|---|
| Нажимает активную кнопку `Сбросить` | В черновике есть минимум один атрибут, добавленный из библиотеки | Все библиотечные добавления удаляются из списка колонок; обычные колонки остаются видимыми | У сброшенных атрибутов кнопки действия показывают иконку плюса | Таблица не меняет колонки. |
| Нажимает `Применить` после сброса | В черновике нет библиотечных добавлений | Черновик без библиотечных добавлений становится примененным состоянием | Библиотека скрывается вместе с панелью | Таблица не показывает сброшенные колонки. |

`Сбросить` не возвращает весь список колонок к базовому состоянию. Для полного возврата черновика к базовому отображению используется родительская кнопка `По умолчанию`.

## 7. Закрытие без применения

| Условие закрытия | Итог в библиотеке и `Общие атрибуты` | Итог для таблицы задач |
|---|---|---|
| Пользователь добавил атрибуты и закрыл панель без `Применить` | Панель и библиотека скрыты; непримененный черновик не передан таблице | Таблица сохраняет прежние колонки. |
| Пользователь вернул атрибуты в библиотеку и закрыл панель без `Применить` | Панель и библиотека скрыты; непримененный черновик не передан таблице | Таблица сохраняет прежние колонки. |
| Пользователь нажал `Сбросить` и закрыл панель без `Применить` | Панель и библиотека скрыты; непримененный сброс не передан таблице | Таблица сохраняет прежние колонки. |

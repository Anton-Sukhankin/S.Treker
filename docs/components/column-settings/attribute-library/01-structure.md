# Библиотека атрибутов: структура интерфейса

## 1. Граница дочерней зоны

`Библиотека атрибутов` - дочерняя зона внутри открытой панели `Настройки колонок`. Когда библиотека открыта, в теле панели видна левая рабочая область `Библиотека атрибутов`; справа остается соседняя область `Общие атрибуты`.

Когда библиотека закрыта, в теле панели нет левой рабочей области библиотеки. В теле панели видна только область `Общие атрибуты`.

| Объект интерфейса | Статус относительно библиотеки | Правило |
|---|---|---|
| Область `Библиотека атрибутов` | Внутренняя область | При открытой библиотеке область видна слева от `Общие атрибуты`; при закрытой библиотеке область отсутствует. |
| Хедер библиотеки | Внутренняя зона | При открытой библиотеке верх области показывает текст `Библиотека атрибутов`. |
| Поле `Поиск атрибута...` | Внутренний управляющий элемент | При открытой библиотеке поле расположено под хедером библиотеки. |
| Список атрибутов | Внутренняя зона | При открытой библиотеке список расположен под полем поиска и показывает строки доступных атрибутов. |
| Строка атрибута | Внутренний элемент списка | Каждая строка показывает название атрибута слева и кнопку действия справа. |
| Пустое состояние списка | Внутреннее состояние списка | Если текущий поиск не находит доступные атрибуты, на месте строк виден текст `Атрибуты не найдены`. |
| `Общие атрибуты` | Соседняя область родителя | При добавлении атрибута из библиотеки в конце списка `Общие атрибуты` видна строка добавленного атрибута в черновике колонок. |
| Футер `Настройки колонок` | Внешняя область родителя | Футер открывает, закрывает, сбрасывает и применяет состояние родительской панели; футер не является внутренней зоной библиотеки. |
| Табличный список задач | Внешний получатель примененного состояния родителя | Библиотека не меняет таблицу напрямую; таблица получает новый набор колонок только после родительского действия `Применить`. |

Библиотека не создает новые атрибуты, не редактирует значения задач, не владеет кнопками родительского футера, не применяет черновик к таблице и не изменяет карточный вид списка задач.

## 2. Визуальный эталон

Визуальные эталоны фиксируют компоновку состояний библиотеки. Пути ниже являются зарезервированными, пока соответствующие изображения не добавлены в папку `assets` внутри этого компонента.

| Состояние | Зарезервированный путь | Что должно быть видно на эталоне |
|---|---|---|
| Библиотека закрыта | `assets/attribute-library-closed.png` | В теле панели `Настройки колонок` видна область `Общие атрибуты`; область `Библиотека атрибутов`, поле поиска и список доступных атрибутов не видны. |
| Библиотека открыта | `assets/attribute-library-open.png` | Слева видна область `Библиотека атрибутов` с хедером, полем поиска и списком атрибутов; справа видна соседняя область `Общие атрибуты`. |
| Пустой результат поиска | `assets/attribute-library-empty-search.png` | Область библиотеки открыта; поле `Поиск атрибута...` содержит введенный текст; под полем вместо строк атрибутов виден текст `Атрибуты не найдены`. |
| Атрибут добавлен из библиотеки | `assets/attribute-library-added.png` | Строка добавленного атрибута остается в списке библиотеки; кнопка действия в этой строке показывает иконку стрелки назад; в соседней области `Общие атрибуты` видна строка того же атрибута. |

Зарезервированные пути не оформляются как markdown image links. Если на эталоне показан родительский футер, он должен быть обозначен как внешняя область панели `Настройки колонок`, а не как часть библиотеки.

## 3. Пространственный контракт

| Зона | Расположение и привязка | Слой интерфейса | Условие видимости | Влияние на соседние области | Владелец состояния | Состав и исключения |
|---|---|---|---|---|---|---|
| Закрытая библиотека | Левая рабочая область библиотеки отсутствует; `Общие атрибуты` являются единственной рабочей областью тела панели | Drawer родительской панели | Панель `Настройки колонок` открыта, библиотека закрыта | `Общие атрибуты` остаются видимыми; таблица задач не меняет колонки | `Настройки колонок` | Хедер библиотеки, поле поиска, список атрибутов и пустое состояние не видны. |
| Открытая библиотека | Левая рабочая область тела панели, непосредственно слева от `Общие атрибуты` | Drawer родительской панели | Библиотека открыта через действие в родительском футере | `Общие атрибуты` остаются видимыми справа; таблица задач не получает новые колонки до родительского `Применить` | `Настройки колонок` определяют раскрытие; `Библиотека атрибутов` показывает поиск, список и пустое состояние внутри левой области | Входит хедер, поле поиска, список атрибутов или пустое состояние; список `Общие атрибуты` и родительский футер не входят. |
| Поле поиска | Под хедером внутри открытой библиотеки | Drawer родительской панели | Библиотека открыта | Поле меняет только состав строк в списке библиотеки; `Общие атрибуты` и таблица задач не меняются от ввода текста | `Библиотека атрибутов` | Поле с плейсхолдером `Поиск атрибута...`; фильтры задач и поиск по задачам не входят. |
| Список атрибутов | Под полем поиска внутри открытой библиотеки | Drawer родительской панели | Библиотека открыта и текущий поиск находит минимум один доступный атрибут | Список показывает строки доступных атрибутов; `Общие атрибуты` меняются только после действия добавления | `Библиотека атрибутов` | Строки атрибутов с названиями и кнопками действия; строки колонок из `Общие атрибуты` не входят. |
| Пустое состояние списка | На месте списка атрибутов внутри открытой библиотеки | Drawer родительской панели | Библиотека открыта и текущий поиск не находит доступные атрибуты | Строки атрибутов скрыты; `Общие атрибуты` и таблица задач не меняются | `Библиотека атрибутов` | Текст `Атрибуты не найдены`; кнопки действия атрибутов не видны. |

Открытая библиотека не создает отдельный modal, overlay или плавающую панель. Область библиотеки не перекрывает табличный список задач отдельным слоем.

## 4. Состав области библиотеки

| Часть области | Условие показа | Видимый состав |
|---|---|---|
| Хедер | Библиотека открыта | Текст `Библиотека атрибутов`. |
| Поиск | Библиотека открыта | Поле с плейсхолдером `Поиск атрибута...`. |
| Список атрибутов | Библиотека открыта и есть минимум один доступный атрибут по текущему поиску | Строки доступных атрибутов. |
| Пустое состояние | Библиотека открыта и текущий поиск не находит доступные атрибуты | Текст `Атрибуты не найдены` на месте списка. |

## 5. Строка атрибута

| Элемент строки | Позиция | Условие | Видимый состав |
|---|---|---|---|
| Название атрибута | Левая часть строки | Атрибут доступен для выбранной области задач и проходит текущий поиск | Пользовательское название атрибута. |
| Кнопка действия с иконкой плюса | Правая часть строки | Атрибут не добавлен в черновик `Общие атрибуты` | Кликабельная кнопка действия с иконкой плюса. |
| Кнопка действия с иконкой стрелки назад | Правая часть строки | Атрибут уже добавлен в черновик `Общие атрибуты` | Кликабельная кнопка действия с иконкой стрелки назад. |

После добавления атрибута строка этого атрибута остается в списке библиотеки. В строке меняется только кнопка действия: иконка плюса заменяется иконкой стрелки назад.

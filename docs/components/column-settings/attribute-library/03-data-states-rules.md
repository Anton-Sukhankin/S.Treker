# Библиотека атрибутов: данные, состояния и правила

Этот файл описывает правила, которые определяют список `Библиотека атрибутов`, состояние кнопок действия и результат библиотечных добавлений в соседних областях.

## 1. Термины и владельцы состояния

| Термин или область | Владелец состояния | Правило видимого результата |
|---|---|---|
| Доступный атрибут библиотеки | `Библиотека атрибутов` показывает результат отбора по выбранной области задач и поиску | Атрибут виден в списке библиотеки, если он скрыт по умолчанию, относится к выбранной области задач и проходит текущий поиск. |
| Библиотечное добавление | `Настройки колонок` владеют черновиком колонок | Атрибут считается библиотечным добавлением, если пользователь добавил его из библиотеки в текущий черновик `Общие атрибуты`. |
| Раскрытие библиотеки | `Настройки колонок` | При закрытой библиотеке левая область отсутствует; при открытой библиотеке слева видна `Библиотека атрибутов`. |
| Поиск библиотеки | `Библиотека атрибутов` | После ввода текста поле `Поиск атрибута...` ограничивает список библиотеки совпадениями по названию атрибута. |
| `Общие атрибуты` | `Настройки колонок` | После добавления библиотечного атрибута в `Общие атрибуты` видна строка этого атрибута как часть черновика колонок. |
| Табличный список задач | `Настройки колонок` передают примененное состояние через `Применить` | До `Применить` таблица сохраняет прежние колонки; после `Применить` таблица показывает примененный набор колонок. |

## 2. Правило доступности атрибута

Атрибут виден в списке библиотеки, если одновременно выполнены все условия.

| Условие | Атрибут проходит в список | Атрибут исключается из списка |
|---|---|---|
| Скрыт по умолчанию | Атрибут не входит в базовый набор колонок таблицы. | Атрибут входит в базовый набор колонок таблицы. |
| Относится к выбранной области задач | Атрибут принадлежит выбранному бизнес-домену или одному из бизнес-доменов режима `Все задачи`. | Атрибут не относится к выбранному бизнес-домену и не относится к доступным бизнес-доменам режима `Все задачи`. |
| Проходит поиск | Поле `Поиск атрибута...` пустое или название атрибута содержит введенный текст. | В поле `Поиск атрибута...` введен текст, которого нет в названии атрибута. |

Добавление атрибута в черновик не скрывает этот атрибут из библиотеки. После добавления меняется только кнопка действия в строке атрибута: иконка плюса заменяется иконкой стрелки назад.

## 3. Правила выбранной области задач

| Выбранная область задач | Доступные атрибуты библиотеки |
|---|---|
| `Все задачи` | Скрытые атрибуты всех бизнес-доменов, доступных текущей роли; одинаковые атрибуты показаны один раз. |
| Конкретный бизнес-домен | Скрытые атрибуты выбранного бизнес-домена. |

Текущий набор бизнес-доменов относится к одной роли в прототипе. Для другой роли количество бизнес-доменов и состав доступных атрибутов могут отличаться.

| Выбранная область задач в текущем прототипе | Атрибуты, доступные в библиотеке текущего прототипа |
|---|---|
| `Строительные договоры` | `Внутренний номер договора`, `Юридическое лицо`, `Ставка НДС`, `Валюта договора`, `Дата начала действия`, `Дата окончания действия`, `Дата фактической регистрации`, `Ссылка на скан-копию`, `Условия оплаты`, `Тип доп. соглашения`, `Ответственный от контрагента`, `Гарантийный срок`, `Этап реализации проекта`, `Ссылка на связанные сметы`. |
| `Закупки ТМЦ` | `Инициатор заявки`, `Поставщик`, `Дата поставки`, `Приоритет`, `Этап закупки`. |
| `Поручения СД` | `Ответственный контролер`, `План устранения`, `Зона проверки`, `Приоритет`. |
| `Все задачи` | Объединенный список скрытых атрибутов всех доступных бизнес-доменов; одинаковые атрибуты показаны один раз. |

## 4. Состояния списка и поиска

| Состояние | Условие | Видимый результат |
|---|---|---|
| Библиотека закрыта | Панель `Настройки колонок` открыта, библиотека не раскрыта | Левая область библиотеки, поле поиска и список атрибутов не видны. |
| Библиотека открыта без текста поиска | Поле `Поиск атрибута...` пустое | Список показывает все доступные атрибуты выбранной области задач. |
| Библиотека открыта с текстом поиска | В поле `Поиск атрибута...` есть текст и минимум один доступный атрибут содержит этот текст в названии | Список показывает только найденные атрибуты. |
| Пустой результат поиска | В поле `Поиск атрибута...` есть текст и ни один доступный атрибут не содержит этот текст в названии | На месте списка виден текст `Атрибуты не найдены`; строки атрибутов не видны. |
| Добавленный атрибут проходит текущий поиск | Атрибут добавлен в черновик и его название содержит введенный текст | Строка атрибута остается в списке; кнопка действия показывает иконку стрелки назад. |

## 5. Состояния библиотечного добавления

| Состояние черновика | Видимый результат в библиотеке | Видимый результат в `Общие атрибуты` | Видимый результат в таблице задач |
|---|---|---|---|
| Атрибут не добавлен в черновик | Строка доступного атрибута видна с кнопкой действия с иконкой плюса | Строка этого атрибута не видна как колонка черновика | Таблица сохраняет прежние колонки. |
| Атрибут добавлен из библиотеки | Строка атрибута остается видимой с кнопкой действия с иконкой стрелки назад | В списке колонок видна строка добавленного атрибута с кнопкой действия с иконкой стрелки назад | Таблица сохраняет прежние колонки до `Применить`. |
| Атрибут возвращен через кнопку действия с иконкой стрелки назад | Строка атрибута видна с кнопкой действия с иконкой плюса, если атрибут проходит текущий поиск | Строка атрибута не видна в списке колонок черновика | Таблица сохраняет прежние колонки до `Применить`. |
| Родительский черновик уже содержит атрибут, который входит в библиотеку | Строка этого атрибута видна с кнопкой действия с иконкой стрелки назад, если атрибут доступен для выбранной области задач | В `Общие атрибуты` видна строка этого атрибута | Таблица сохраняет прежние колонки до `Применить`. |

## 6. Сброс библиотечных добавлений

| Условие | Состояние кнопки `Сбросить` в родительском футере | Видимый результат |
|---|---|---|
| Библиотека закрыта | Кнопка `Сбросить` не видна | Сброс библиотечных добавлений недоступен через библиотеку. |
| Библиотека открыта, библиотечных добавлений в черновике нет | Кнопка `Сбросить` видна в неактивном состоянии | Черновик не меняется; кнопки действия в библиотеке остаются в текущем состоянии. |
| Библиотека открыта, есть минимум одно библиотечное добавление | Кнопка `Сбросить` активна | После нажатия `Сбросить` все библиотечные добавления удалены из черновика; обычные колонки остаются в черновике; у сброшенных атрибутов в библиотеке видны кнопки действия с иконкой плюса. |

`Сбросить` не равен действию `По умолчанию`. `Сбросить` удаляет только библиотечные добавления из текущего черновика; `По умолчанию` возвращает весь черновик колонок к базовому отображению родительской панели.

## 7. Контракт применения к таблице

| Состояние черновика перед `Применить` | Видимый результат после `Применить` |
|---|---|
| Атрибут добавлен из библиотеки и виден в `Общие атрибуты` | В табличном списке задач видна новая колонка. |
| Атрибут возвращен в библиотеку и не виден в `Общие атрибуты` | В табличном списке задач эта колонка не видна. |
| Библиотечные добавления сброшены в черновике | Табличный список задач показывает колонки без сброшенных библиотечных добавлений. |
| Панель закрыта без `Применить` | Табличный список задач сохраняет прежний набор колонок. |

Если у задачи нет значения добавленного атрибута, после применения в ячейке этой колонки показано пустое значение. В режиме `Все задачи` пустое значение также показано у задач из доменов, где добавленный атрибут не используется.

## 8. Контракты взаимодействия

| Связанный компонент или область | Роль связанной области | Условие | Результат в библиотеке атрибутов | Результат в связанной области |
|---|---|---|---|---|
| `Настройки колонок` | Родительский владелец черновика, раскрытия библиотеки и применения к таблице | Пользователь открывает или закрывает библиотеку, добавляет, возвращает или сбрасывает библиотечный атрибут | Левая область библиотеки видима или скрыта; строка атрибута получает кнопку действия с иконкой плюса или стрелки назад | Черновик родительской панели получает новый состав колонок; примененное состояние таблицы не меняется до `Применить`. |
| Родительский футер `Настройки колонок` | Внешний источник действий библиотеки и родительского применения | Пользователь нажимает кнопку библиотеки, `Сбросить` или `Применить` | После кнопки библиотеки область открыта или закрыта; после `Сбросить` сброшенные атрибуты показывают иконку плюса; после `Применить` библиотека скрыта вместе с панелью | Футер остается областью родителя; таблица показывает новый набор колонок только после `Применить`. |
| `Общие атрибуты` | Соседняя область родителя, где виден черновик колонок | Атрибут добавлен из библиотеки | Строка атрибута в библиотеке остается видимой с кнопкой действия с иконкой стрелки назад | В `Общие атрибуты` видна строка добавленного атрибута. |
| `Общие атрибуты` | Соседняя область родителя, где виден черновик колонок | Атрибут возвращен через кнопку действия с иконкой стрелки назад | Строка атрибута в библиотеке показывает кнопку действия с иконкой плюса, если атрибут проходит текущий поиск | В `Общие атрибуты` строка возвращенного атрибута не видна. |
| Табличный список задач | Получатель примененного состояния родительской панели | Пользователь нажимает `Применить` в `Настройки колонок` | Библиотека скрыта вместе с панелью | Таблица показывает примененный набор колонок. |

## 9. Ограничения ответственности

| Область | Правило |
|---|---|
| Новые атрибуты | Библиотека атрибутов не создает новые атрибуты. |
| Значения задач | Библиотека атрибутов не изменяет значения задач. |
| Примененное состояние таблицы | Библиотека атрибутов не изменяет табличный список задач до родительского `Применить`. |
| Родительский футер | Библиотека атрибутов не владеет кнопками `Сбросить`, `По умолчанию` и `Применить`; эти действия принадлежат панели `Настройки колонок`. |
| Обычные колонки | Сброс библиотечных добавлений не удаляет обычные колонки из черновика. |
| Пресеты | Библиотека атрибутов не создает, не сохраняет и не удаляет пресеты колонок. |
| Карточный вид | Библиотека атрибутов не изменяет карточный вид списка задач. |

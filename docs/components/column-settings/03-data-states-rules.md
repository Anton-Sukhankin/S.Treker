# Настройки колонок: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Видимый результат |
|---|---|---|
| `Настройки колонок` | Черновик колонок | Открытая панель показывает состав, порядок, видимость и признак добавления из библиотеки для каждой динамической колонки черновика. |
| `Настройки колонок` | Примененное состояние колонок текущего контекста | Табличный список задач показывает только примененный состав, порядок и видимость динамических колонок. |
| `Настройки колонок` | Состояние `Библиотека открыта` или `Библиотека закрыта` | При закрытой библиотеке в теле панели видна только область `Общие атрибуты`; при открытой библиотеке слева видна область `Библиотека атрибутов`, а справа остается `Общие атрибуты`. |
| `Настройки колонок` | Футер действий | Футер показывает кнопку библиотеки, `По умолчанию`, `Применить`; `Сбросить` видна только при открытой библиотеке. |
| `Пресеты колонок` | Выбранный пункт пресета и сохраненные пресеты текущего контекста | Выбор `Базовое отображение` или сохраненного пресета меняет черновик родительского компонента. |
| `Библиотека атрибутов` | Локальный список доступных атрибутов и локальные состояния строк библиотеки | Добавление, возврат или сброс библиотечных атрибутов меняет черновик родительского компонента. |
| Табличный список задач | Видимый набор динамических колонок | Таблица получает новый набор динамических колонок только после `Применить`. |
| Карточный список задач | Карточное отображение задач | Карточный вид не получает состояние колонок из настроек колонок. |

## 2. Основные состояния родителя

| Состояние | Значение | Видимый результат |
|---|---|---|
| Контекст настройки | `Все задачи` или выбранный бизнес-домен | Определяет базовый набор настраиваемых динамических колонок. |
| Базовое отображение | Минимальный набор динамических колонок текущего контекста без библиотечных добавлений | Используется при первом открытии панели без пользовательских настроек, после выбора `Базовое отображение` или после нажатия `По умолчанию`. |
| Примененное состояние | Последний набор динамических колонок после `Применить` | Таблица показывает этот состав, порядок и видимость динамических колонок. |
| Черновик колонок | Временный набор динамических колонок внутри открытой панели | Панель показывает черновик; таблица не меняется до `Применить`. |
| Выбранный пункт пресета в панели | `Базовое отображение` или название сохраненного пресета | Строка пресетов показывает выбранный пункт; черновик получает набор колонок выбранного пункта. |
| Библиотечная колонка в черновике | Динамическая колонка с признаком добавления из библиотеки | В списке `Общие атрибуты` строка этой колонки показывает кнопку действия с иконкой стрелки назад. |
| Библиотека атрибутов | Закрыта или открыта | Закрытая библиотека не занимает левую рабочую область; открытая библиотека видна слева от `Общие атрибуты`. |

Главное правило: таблица читает примененное состояние, а открытая панель редактирует черновик. Родительский компонент `Настройки колонок` владеет черновиком; список колонок, пресеты и библиотека атрибутов читают или меняют этот черновик в своих зонах.

## 3. Правила контекста

| Контекст | Базовый набор колонок |
|---|---|
| `Все задачи` | Объединенный набор дефолтных динамических колонок всех доступных бизнес-доменов. |
| Выбранный бизнес-домен | Дефолтные динамические колонки выбранного бизнес-домена. |

Один и тот же пресет, порядок и видимость колонок не переносятся автоматически между разными контекстами.

Для одного и того же контекста базовое отображение остается одинаковым. Пользовательские действия меняют черновик, примененное состояние или сохраненный пресет, но не меняют базовое отображение. Базовое отображение не включает атрибуты из библиотеки. Атрибуты из библиотеки появляются в черновике только после действия пользователя в дочерней зоне `Библиотека атрибутов` или после выбора сохраненного пресета, который содержит такие атрибуты.

## 4. Состояние одной динамической колонки

| Свойство колонки | Правило |
|---|---|
| Динамическая колонка | Строка черновика или примененного состояния показывает название настраиваемой колонки. |
| Видимость | Включенная колонка попадает в таблицу после `Применить`; выключенная колонка не попадает в таблицу после `Применить`. |
| Порядок | Порядок строк в черновике задает порядок динамических колонок после `Применить`. |
| Признак библиотечного атрибута | Действие возврата удаляет одну добавленную из библиотеки колонку из черновика; `Сбросить` удаляет из черновика все колонки с этим признаком. |

Закрепленные колонки чекбокса выбора, `№` и `Наименование` не входят в пользовательское состояние колонок. Таблица добавляет закрепленные колонки отдельно и показывает их первыми слева.

## 5. Базовое, черновое и примененное состояние

| Ситуация | Состояние панели | Состояние таблицы |
|---|---|---|
| Панель открыта без ранее примененных настроек | Черновик создан из базового отображения. | Таблица показывает базовое отображение. |
| Панель открыта после ранее примененных настроек | Черновик создан из примененного состояния. | Таблица показывает примененное состояние. |
| Черновик изменен без `Применить` | Панель показывает измененный черновик. | Таблица сохраняет прежнее примененное состояние. |
| Панель закрыта без `Применить` | Черновик отбрасывается. | Таблица сохраняет прежнее примененное состояние. |
| Нажато `Применить` | Черновик становится примененным состоянием; панель закрыта. | Таблица показывает новый набор динамических колонок. |
| Выбрано `По умолчанию` и нажато `Применить` | Черновик и примененное состояние возвращаются к базовому отображению. | Таблица показывает базовый набор динамических колонок. |

## 6. Правила восстановления видимого состояния

| Ситуация | Итог в панели | Итог в таблице |
|---|---|---|
| Сохраненный пресет нельзя показать в текущем контексте | Строка пресетов показывает `Базовое отображение`; список `Общие атрибуты` показывает базовый набор текущего контекста. | Таблица сохраняет прежнее примененное состояние до `Применить`. |
| Примененный набор колонок нельзя показать в текущем контексте | При открытии панели черновик создается из базового отображения текущего контекста. | Таблица показывает базовый набор динамических колонок текущего контекста. |
| Черновик не содержит видимых динамических колонок | Список `Общие атрибуты` возвращается к базовому набору текущего контекста. | Таблица не меняется до `Применить`. |
| Черновик содержит чекбокс выбора, `№` или `Наименование` | Эти колонки не показаны в списке `Общие атрибуты`. | Закрепленные колонки остаются первыми слева независимо от настроек. |

## 7. Правила активных колонок таблицы

| Шаг | Правило |
|---:|---|
| 1 | Родительский компонент берет базовый набор динамических колонок текущего контекста. |
| 2 | Родительский компонент добавляет колонки из примененного состояния, если они были добавлены из библиотеки. |
| 3 | Таблица показывает закрепленные колонки чекбокса выбора, `№` и `Наименование` первыми слева. |
| 4 | Таблица показывает остальные динамические колонки в порядке примененного состояния. |
| 5 | Таблица не показывает динамические колонки, которые имеют состояние `скрыта`. |
| 6 | Заголовок и строки таблицы показывают один и тот же итоговый набор колонок. |

## 8. Контракты дочерних зон с черновиком родителя

| Дочерняя зона | Условие | Изменение в родительском черновике | Видимый результат в родительской панели | Видимый результат в таблице |
|---|---|---|---|---|
| Пресеты колонок | Пользователь выбирает `Базовое отображение` | Черновик получает базовый состав, порядок и видимость динамических колонок текущего контекста. | Список `Общие атрибуты` показывает базовый набор; строка пресетов показывает `Базовое отображение`. | Таблица не меняется до `Применить`. |
| Пресеты колонок | Пользователь выбирает сохраненный пресет | Черновик получает состав, порядок и видимость динамических колонок выбранного пресета. | Список `Общие атрибуты` показывает набор выбранного пресета; строка пресетов показывает название пресета. | Таблица не меняется до `Применить`. |
| Пресеты колонок | Пользователь сохраняет или удаляет пресет | Состав черновика не становится примененным состоянием таблицы. | Строка пресетов и список пресетов получают локальный результат дочерней зоны. | Таблица не меняется до `Применить`. |
| Библиотека атрибутов | Пользователь добавляет атрибут из библиотеки | Черновик получает новую динамическую колонку с признаком добавления из библиотеки. | В `Общие атрибуты` видна строка добавленной колонки. | Таблица не меняется до `Применить`. |
| Библиотека атрибутов | Пользователь возвращает добавленный атрибут в библиотеку | Черновик теряет эту динамическую колонку. | В `Общие атрибуты` исчезает строка возвращенной колонки. | Таблица не меняется до `Применить`. |
| Библиотека атрибутов | Пользователь нажимает `Сбросить` в футере родителя | Из черновика удаляются все динамические колонки с признаком добавления из библиотеки. | `Общие атрибуты` показывает черновик без библиотечных добавлений. | Таблица не меняется до `Применить`. |

Локальный поиск, пустые состояния, список атрибутов, кнопки строк библиотеки, список пресетов, сохранение, удаление и модальное окно пресетов остаются в дочерних спецификациях.

## 9. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в настройках колонок | Результат в связанном компоненте |
|---|---|---|---|---|
| Панель инструментов | Источник открытия настроек колонок | Пользователь нажал `Настройка колонок` в табличном виде | Панель `Настройки` открыта; черновик создан из примененного или базового состояния текущего контекста. | Панель инструментов не меняет состав, поиск, фильтры или текущий контекст. |
| Табличный список задач | Получатель примененного состояния | Пользователь нажал `Применить` | Черновик становится примененным состоянием; панель закрыта. | Таблица показывает примененный состав, порядок и видимость динамических колонок. |
| Табличный список задач | Получатель закрытия без применения | Пользователь закрыл панель без `Применить` | Черновик отбрасывается; панель закрыта. | Таблица сохраняет прежнее примененное состояние колонок. |
| Пресеты колонок | Дочерняя зона, меняющая черновик | Пользователь выбрал, сохранил или удалил пресет | Черновик или выбранный пункт пресета получает результат дочерней зоны. | Полная локальная логика пресетов описана в `column-settings/presets`. |
| Библиотека атрибутов | Дочерняя зона, меняющая черновик | Пользователь добавил, вернул или сбросил библиотечные атрибуты | Черновик получает новый состав библиотечных атрибутов. | Полная локальная логика библиотеки описана в `column-settings/attribute-library`. |

## 10. Ограничения ответственности

| Область | Правило |
|---|---|
| Данные задач | Настройки колонок не изменяют значения задач. |
| Значения атрибутов | Настройки колонок не удаляют и не редактируют значения атрибутов. |
| Карточный вид | Карточный вид не зависит от настроек колонок. |
| Очереди | Настройки колонок не изменяют активную очередь и счетчики очередей. |
| Фильтры | Настройки колонок не изменяют параметры фильтрации. |
| Бизнес-домены | Настройки колонок не изменяют состав бизнес-доменов. |

# Левая навигация: структура интерфейса

## 1. Граница компонента

`Левая навигация` - постоянно видимая встроенная панель слева от правой рабочей области. Панель содержит пункты выбора области задач, вложенные группировки, пользовательские группы, закладки и область изменения ширины.

| Объект интерфейса | Статус относительно левой навигации | Структурное правило |
|---|---|---|
| Панель левой навигации | Главный UI компонента | Расположена слева в рабочем интерфейсе задач; правая рабочая область начинается после правой границы панели. |
| Основной список областей задач | Внутренняя зона | Содержит пункт `Все задачи` и бизнес-домены, доступные текущей роли. |
| Вложенные группировки | Внутренняя динамическая зона | Находятся под пунктом `Все задачи` или бизнес-доменом, для которого табличный список задач создал группировку. |
| Пользовательские группы | Внутренняя динамическая зона | Находятся под основным списком областей задач, если есть минимум одна созданная пользовательская группа. |
| Закладки | Внутренняя динамическая зона | Находятся ниже пользовательских групп, если список закладок содержит минимум одну закладку. |
| Область изменения ширины | Внутренний элемент границы панели | Находится между левой навигацией и правой рабочей областью. |
| Табличный список задач | Внешний источник действия | Содержит действие группировки в заголовке колонки; результат этого действия отображается внутри левой навигации. |
| Заголовок правой рабочей области | Внешний получатель результата | Показывает название области, выбранной в левой навигации. |
| Панель инструментов | Внешний получатель условия | Использует тип выбранной области для видимого набора действий. |
| Очереди | Внешний получатель условия | Используют тип выбранной области для видимости блока очередей. |
| Список задач | Внешний получатель результата | Показывает задачи области, выбранной в левой навигации. |
| Панель фильтрации | Внешний получатель условия | Использует выбранную область для состава доменных блоков и значений параметров. |
| Настройки колонок | Внешний получатель условия | Используют выбранную область для набора доступных динамических колонок. |

Правая рабочая область, табличный список задач, заголовок, панель инструментов, очереди, список задач, панель фильтрации и настройки колонок не входят в левую навигацию.

## 3. Пространственный контракт

### 3.1. Панель и соседняя область

| Зона | Расположение и привязка | Слой интерфейса | Условие видимости | Влияние на соседние области | Владелец состояния | Что не входит |
|---|---|---|---|---|---|---|
| Левая навигация | Левая область рабочего интерфейса задач; правая рабочая область начинается после правой границы панели | Встроенная панель | Видна в рабочем интерфейсе задач без отдельного открытия | Не перекрывает правую рабочую область; при изменении ширины задает новую начальную границу правой рабочей области | Левая навигация владеет выбранной областью задач, раскрытием группировок, пользовательскими группами, закладками и шириной панели | Заголовок, панель инструментов, очереди и список задач |
| Правая рабочая область | Соседняя область справа от левой навигации | Встроенная рабочая область | Видна в рабочем интерфейсе задач | Получает больше или меньше места после изменения ширины левой навигации; не заходит под левую навигацию | Правая рабочая область владеет своими заголовком, инструментами, очередями и списком задач | Не является частью левой навигации |
| Область изменения ширины | На границе между левой навигацией и правой рабочей областью | Встроенный элемент границы панели | Видна как зона взаимодействия на правой границе левой навигации | При перетаскивании меняет ширину левой навигации и сдвигает начало правой рабочей области; не перекрывает список задач поверх содержимого | Левая навигация владеет текущей шириной и состоянием изменения ширины | Не является отдельным drawer, overlay или декоративной линией |

### 3.2. Внутренние зоны

| Зона | Расположение внутри панели | Состав | Условие видимости | Влияние на соседние зоны | Владелец состояния |
|---|---|---|---|---|---|
| Основной список областей задач | Верхняя часть панели | Пункт `Все задачи`; пункты бизнес-доменов; счетчики; точечные индикаторы; кнопки раскрытия и сброса группировок у пунктов с группировками | Видим всегда | Остается над пользовательскими группами и закладками; родительский пункт остается на месте при показе вложенной группировки | Левая навигация |
| Вложенные группировки | Под пунктом `Все задачи` или бизнес-доменом, для которого создана группировка | Заголовок `По ...`; список значений; значения `Без значения` при наличии; бейджи; кнопки удаления значений | Видны только у пункта с созданной группировкой и раскрытой областью группировок | Занимают место внутри левой навигации под родительским пунктом; не сдвигают правую рабочую область отдельно от панели | Левая навигация после получения результата группировки из табличного списка задач |
| Пользовательские группы | Под основным списком областей задач | Заголовок блока `Новая группа`; пункты созданных пользовательских групп | Видны, если есть минимум одна пользовательская группа | Расположены отдельным блоком ниже основных областей задач; не входят во вложенную группировку родительского пункта | Левая навигация после создания группы из выбранных задач |
| Закладки | Под пользовательскими группами | Заголовки закладок; группы внутри раскрытых закладок | Видны, если список закладок содержит минимум одну закладку | Расположены отдельным блоком ниже пользовательских групп; не смешиваются с основным списком областей задач | Левая навигация |

Если вложенные группировки под одним родительским пунктом не помещаются по высоте рабочей зоны, прокручивается только область вложенных группировок этого пункта. Родительский пункт с иконкой, названием, счетчиком и кнопками группировки остается вне прокручиваемой области. Индикатор прокрутки находится поверх области группировок, не занимает ширину контента и не относится ко всей левой навигации.

## 4. Основные пункты навигации

| Тип пункта | Условие показа | Видимый текст в текущем прототипе | Правило порядка | Что обозначает пункт |
|---|---|---|---|---|
| `Все задачи` | Видим всегда | `Все задачи` | Расположен перед списком бизнес-доменов | Набор задач всех бизнес-доменов, доступных текущей роли. |
| Бизнес-домен | Бизнес-домен доступен текущей роли | `Строительный договор (ECM)`, `Закупки ТМЦ (Трекер)`, `Поручения СД` | Порядок бизнес-доменов задается текущей ролью; документация не фиксирует постоянную последовательность доменов | Набор задач выбранного бизнес-домена. |

Текущий видимый набор бизнес-доменов соответствует одной роли прототипа. Для другой роли состав пунктов бизнес-доменов и их порядок могут быть меньше, больше или другими.

## 5. Состав пункта навигации

| Элемент пункта | Расположение внутри пункта | Условие показа | Видимое состояние |
|---|---|---|---|
| Иконка типа пункта | Левая часть пункта | У пункта `Все задачи`, бизнес-домена, пользовательской группы и группы внутри закладки | Иконка показывает тип пункта. |
| Название | После иконки | У каждого пункта левой навигации | Текст пункта совпадает с названием области задач, группы или закладки. |
| Счетчик задач | Правая часть пункта | У основных пунктов, пользовательских групп, групп внутри закладок и значений группировки с задачами | Бейдж показывает иконку задачи и число задач. |
| Точечный индикатор | Правая часть пункта | Только у пунктов, где индикатор предусмотрен текущим прототипом | Маленькая точка находится справа от текста или счетчика пункта. |
| Активное состояние | Вся строка пункта | Пункт является выбранной областью задач | Строка пункта имеет активную визуальную индикацию. |
| Кнопка раскрытия группировок | Правая часть родительского пункта | У пункта `Все задачи` или бизнес-домена есть минимум одна созданная группировка | Кнопка показывает количество значений или группировок, доступных под этим пунктом. |
| Кнопка сброса группировок | Правая часть родительского пункта | У пункта `Все задачи` или бизнес-домена есть минимум одна созданная группировка | Кнопка с иконкой сброса находится в строке родительского пункта. |

## 6. Вложенные группировки

Вложенная группировка находится внутри левой навигации только после действия группировки в заголовке колонки табличного списка задач. Левая навигация не содержит кнопку создания группировки.

| Часть группировки | Расположение | Состав |
|---|---|---|
| Обертка родительского пункта | Вокруг пункта `Все задачи` или бизнес-домена, для которого создана группировка | Родительский пункт; область вложенных группировок под ним. |
| Заголовок группировки | Под родительским пунктом | Текст `По ...`; кнопка раскрытия или сворачивания списка значений. |
| Список значений | Под заголовком группировки | Значения выбранного атрибута; значение `Без значения` при наличии задач с пустым атрибутом. |
| Значение группировки | Внутри списка значений | Название значения; бейджи просрочки, новых задач, суммы и количества задач при выполнении правил из `03-data-states-rules.md`; кнопка удаления значения. |

## 7. Пользовательские группы и закладки

| Зона | Условие видимости | Состав |
|---|---|---|
| Пользовательские группы | Есть минимум одна пользовательская группа | Блок с заголовком `Новая группа`; пункты созданных пользовательских групп. |
| Пункт пользовательской группы | Пользовательская группа существует | Иконка папки; название группы; бейдж с количеством задач; кнопка удаления группы. |
| Закладки | Список закладок содержит минимум одну закладку | Блок закладок; заголовки закладок; тела раскрытых закладок. |
| Группа внутри закладки | Закладка содержит минимум одну группу | Иконка папки; название группы; бейдж с количеством задач. |

Если пользовательских групп нет, блок пользовательских групп не занимает видимую область в левой навигации. Если закладок нет, список закладок не показывает пункты.

## 8. Изменение ширины

| Элемент или состояние | Расположение | Условие видимости | Пространственный результат | Что не входит |
|---|---|---|---|---|
| Область изменения ширины | На границе между левой навигацией и правой рабочей областью | Видна как зона взаимодействия в рабочем интерфейсе задач | При перетаскивании изменяет ширину левой навигации; правая рабочая область начинается от новой правой границы панели | Не является отдельным drawer, overlay или декоративной линией. |
| Минимальная ширина | Состояние левой навигации после перетаскивания влево до предела | Только когда пользователь пытается уменьшить панель дальше минимального значения | Левая навигация сохраняет минимальную ширину; правая рабочая область не заходит под левую навигацию | Не скрывает основной список областей задач. |
| Максимальная ширина | Состояние левой навигации после перетаскивания вправо до предела | Только когда пользователь пытается увеличить панель дальше максимального значения | Левая навигация сохраняет максимальную ширину; правая рабочая область остается справа от панели | Не перекрывает правую рабочую область поверх ее содержимого. |

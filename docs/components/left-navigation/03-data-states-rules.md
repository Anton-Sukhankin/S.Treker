# Левая навигация: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата | Что область не владеет |
|---|---|---|---|
| Левая навигация | Активная область задач, раскрытие вложенных группировок, список пользовательских групп, список закладок, ширина панели | В левой навигации активен один пункт или одно значение; видимые блоки группировок, пользовательских групп и закладок соответствуют текущему состоянию этих списков. | Значения задач, активная очередь, поисковая строка, примененные фильтры и набор колонок. |
| Табличный список задач | Действие группировки в заголовке колонки | После клика по действию группировки левая навигация получает блок `По ...` под текущим пунктом `Все задачи` или бизнес-доменом. | Раскрытие, сворачивание, выбор и удаление значений внутри левой навигации. |
| Список задач | Итоговый набор задач выбранной области | После выбора области в левой навигации список задач показывает задачи этой области с учетом активной очереди, поиска, примененных фильтров и текущей страницы. | Список пунктов, группировок, пользовательских групп, закладок и ширину левой навигации. |
| Очереди | Активный этап согласования | Активная очередь ограничивает видимый список задач справа; счетчики левой навигации считаются по правилам левой навигации. | Значения счетчиков левой навигации. |
| Панель фильтрации | Примененные параметры фильтрации | Счетчики и значения группировок в левой навигации учитывают только задачи, прошедшие примененные фильтры. | Активную область задач и раскрытие блоков левой навигации. |
| Настройки колонок | Набор колонок выбранной области | После выбора области в левой навигации настройки колонок показывают доступные для этой области атрибуты таблицы. | Активную область задач и видимость пунктов левой навигации. |

## 2. Состояния выбранной области

| Состояние | Условие входа | Активный пункт в левой навигации | Заголовок правой рабочей области | Набор задач в списке |
|---|---|---|---|---|
| Все задачи | Открыт прототип или пользователь выбрал `Все задачи` | `Все задачи` | `Все задачи` | Задачи всех бизнес-доменов, доступных текущей роли. |
| Бизнес-домен | Пользователь выбрал пункт бизнес-домена | Один пункт бизнес-домена | Название выбранного бизнес-домена | Задачи выбранного бизнес-домена. |
| Значение группировки | Пользователь выбрал значение внутри раскрытой группировки | Одно значение внутри группировки | `Область • Значение` | Задачи выбранной области, у которых атрибут группировки равен выбранному значению. |
| Пользовательская группа | Пользователь выбрал пункт пользовательской группы | Один пункт пользовательской группы | Название пользовательской группы | Задачи, сохраненные в выбранной группе. |
| Группа внутри закладки | Пользователь выбрал группу внутри раскрытой закладки | Один пункт группы внутри закладки | Название группы | Задачи, сохраненные в выбранной группе внутри закладки. |

В каждый момент активна только одна область: `Все задачи`, один бизнес-домен, одно значение группировки, одна пользовательская группа или одна группа внутри закладки.

## 3. Состав бизнес-доменов

| Условие | Видимый состав левой навигации | Правило для `Все задачи` |
|---|---|---|
| Текущая роль прототипа | Видны `Строительный договор (ECM)`, `Закупки ТМЦ (Трекер)`, `Поручения СД`. | `Все задачи` собирает задачи этих доступных бизнес-доменов. |
| Другая роль | Набор и порядок бизнес-доменов могут отличаться от текущего прототипа. | `Все задачи` собирает задачи только из бизнес-доменов, доступных этой роли. |
| Бизнес-домен недоступен роли | Пункт бизнес-домена не виден в левой навигации. | Задачи недоступного домена не входят в `Все задачи`. |

## 4. Счетчики задач

| Счетчик | Условие расчета | Участие очередей | Видимое значение |
|---|---|---|---|
| `Все задачи` | Считаются задачи всех доступных бизнес-доменов, прошедшие примененные фильтры. | Активная очередь не меняет значение счетчика. | Бейдж показывает иконку задачи и число задач. |
| Бизнес-домен | Считаются задачи этого бизнес-домена, прошедшие примененные фильтры. | Активная очередь не меняет значение счетчика. | Бейдж показывает иконку задачи и число задач. |
| Пользовательская группа | Считаются задачи группы, прошедшие примененные фильтры. | Активная очередь не меняет значение счетчика. | Бейдж показывает иконку задачи и число задач. |
| Группа внутри закладки | Считаются задачи группы внутри закладки, прошедшие примененные фильтры. | Активная очередь не меняет значение счетчика. | Бейдж показывает иконку задачи и число задач. |
| Значение группировки | Считаются задачи значения группировки, прошедшие примененные фильтры. | Активная очередь не меняет значение счетчика. | Бейдж показывает иконку задачи и число задач. |

Очереди `Обработаны мной`, `Наблюдаю` и `Инициированы мной` ограничивают видимый список задач справа, но не участвуют в расчете счетчиков левой навигации.

## 5. Правила группировок

| Состояние или правило | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Группировка создана для `Все задачи` или бизнес-домена | Пользователь нажал действие группировки в заголовке колонки табличного списка задач | Под родительским пунктом виден блок `По ...` со значениями выбранного атрибута. | Пользователь сбрасывает группировки родительского пункта или удаляет последнее значение группировки. |
| Несколько группировок у одного пункта | Пользователь создал группировки по разным атрибутам для одного родительского пункта | Под пунктом видны несколько заголовков `По ...`. | Пользователь сбрасывает группировки родительского пункта или удаляет значения конкретной группировки. |
| Повторная группировка по тому же атрибуту | Пользователь повторно нажал действие группировки по атрибуту, который уже есть под активным пунктом | В левой навигации остается одна группировка по этому атрибуту с актуальным набором значений. | Пользователь сбрасывает группировки родительского пункта или удаляет последнее значение группировки. |
| Значение группировки содержит ноль задач после примененных фильтров | Примененные фильтры исключили все задачи этого значения | Значение не видно в списке значений. | Фильтры изменены так, что значение снова содержит минимум одну задачу. |
| Значение группировки содержит пустое значение атрибута | В выбранной области есть задачи с пустым атрибутом группировки | Значение видно как `Без значения` и находится после остальных значений. | После фильтрации или удаления в пустом значении не остается задач. |
| Все значения группировки стали невидимыми | Каждое значение группировки содержит ноль задач после примененных фильтров | Заголовок группировки остается видимым; список значений пуст. | Фильтры изменены так, что минимум одно значение снова содержит задачу. |

## 6. Индикаторы внутри значений группировки

| Условие в значении группировки | Видимый индикатор |
|---|---|
| Есть минимум одна просроченная задача | Красный бейдж показывает число просроченных задач. |
| Есть минимум одна новая задача | Зеленый бейдж показывает число новых задач. |
| Сумма задач больше нуля | Синий бейдж показывает сумму. |
| Есть минимум одна задача | Бейдж с иконкой задачи показывает число задач. |
| Ни одной задачи после примененных фильтров | Значение группировки не видно. |

Если сумма значения группировки равна одному миллиону рублей или больше, синий бейдж показывает сумму в миллионах рублей. Если сумма меньше одного миллиона рублей, синий бейдж показывает сумму числом без дробной части.

## 7. Контракт группировки между компонентами

| Связанный компонент | Роль связанного компонента | Условие | Результат в левой навигации | Результат в связанном компоненте |
|---|---|---|---|---|
| Табличный список задач | Источник действия группировки в заголовке колонки | Пользователь нажал кнопку действия группировки | Под активным пунктом `Все задачи` или бизнес-доменом виден блок `По ...` со значениями атрибута. | Таблица остается в табличном виде и сохраняет текущий набор задач. |
| Список задач | Получатель выбранного значения группировки | Пользователь выбрал значение группировки в левой навигации | Значение группировки получает активное состояние. | Список задач показывает задачи выбранной области, у которых атрибут группировки равен выбранному значению. |
| Панель инструментов | Внешнее условие доступности группировки через режим списка | Активен карточный вид | Новая вложенная группировка не создается через карточный вид. | Действие группировки в заголовках колонок отсутствует, потому что таблица не видна. |

После создания группировки левая навигация владеет видимостью блока `По ...`, раскрытием списка значений, активным значением, удалением значений и сбросом группировок родительского пункта. Табличный список задач остается источником действия создания группировки.

## 8. Пользовательские группы и закладки

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Пользовательских групп нет | Список пользовательских групп пуст | Блок пользовательских групп не виден. | Создана минимум одна пользовательская группа. |
| Есть минимум одна пользовательская группа | Список пользовательских групп содержит минимум одну группу | Блок пользовательских групп виден; внутри блока видны пункты групп. | Все пользовательские группы удалены. |
| Пользовательская группа содержит задачи, не проходящие примененные фильтры | В группе есть задачи, исключенные примененными фильтрами | Эти задачи не участвуют в счетчике группы и не видны в списке задач. | Фильтры изменены так, что задачи снова проходят условия. |
| Пользовательская группа удалена | Пользователь удалил группу или в группе не осталось задач | Пункт группы исчезает из левой навигации. | Группа создана заново через массовые действия. |
| Активная пользовательская группа удалена | Удаляемая группа была активной областью | Активная область получает значение `Все задачи`; заголовок показывает `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. | Пользователь выбирает другую область задач. |
| Закладок нет | Список закладок пуст | Список закладок не показывает пункты. | Список закладок получает минимум одну закладку. |
| Закладка удалена | Пользователь удалил закладку | Закладка и группы внутри нее исчезают из левой навигации. | Закладка снова присутствует в списке закладок. |
| Активная группа находилась внутри удаленной закладки | Удаленная закладка содержала активную группу | Активная область получает значение `Все задачи`; заголовок показывает `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. | Пользователь выбирает другую область задач. |

## 9. Правила изменения ширины

| Состояние | Условие входа | Видимый результат | Условие выхода |
|---|---|---|---|
| Обычное состояние курсора | Курсор находится вне области изменения ширины | Курсор показывает обычное состояние. | Курсор переходит на область изменения ширины. |
| Состояние изменения горизонтального размера | Курсор находится на области изменения ширины | Курсор показывает состояние изменения горизонтального размера. | Курсор уходит с области изменения ширины или пользователь отпускает кнопку мыши после перетаскивания. |
| Изменение ширины активно | Пользователь зажал левую кнопку мыши на области изменения ширины | Левая навигация получает новую ширину при перетаскивании; правая рабочая область начинается от новой правой границы панели. | Пользователь отпускает левую кнопку мыши. |
| Минимальная ширина | Пользователь перетаскивает границу влево до минимального значения | Дальнейшее перетаскивание влево не уменьшает левую навигацию; правая рабочая область не заходит под нее. | Пользователь перетаскивает границу вправо. |
| Максимальная ширина | Пользователь перетаскивает границу вправо до максимального значения | Дальнейшее перетаскивание вправо не увеличивает левую навигацию; правая рабочая область остается справа от панели. | Пользователь перетаскивает границу влево. |

## 10. Контракты выбранной области с соседними компонентами

| Соседний компонент | Условие выбранной области | Результат в левой навигации | Видимый результат в соседнем компоненте |
|---|---|---|---|
| Заголовок правой рабочей области | Выбран `Все задачи`, бизнес-домен, пользовательская группа или группа внутри закладки | Выбранный пункт получает активное состояние. | Заголовок показывает название выбранной области. |
| Заголовок правой рабочей области | Выбрано значение группировки | Значение группировки получает активное состояние. | Заголовок показывает формат `Область • Значение`. |
| Панель инструментов | Выбраны `Все задачи` или бизнес-домен | Активен основной пункт области задач. | Панель показывает обычный набор инструментов. |
| Панель инструментов | Выбрана пользовательская группа или группа внутри закладки | Активен пункт группы. | Часть действий переносится в область заголовка правой рабочей области. |
| Очереди | Выбраны `Все задачи` или бизнес-домен | Активен основной пункт области задач. | Очереди видны под панелью инструментов. |
| Очереди | Выбрана пользовательская группа или группа внутри закладки | Активен пункт группы. | Очереди скрыты. |
| Список задач | Выбрана любая область левой навигации | Активен один пункт или одно значение. | Список задач показывает задачи выбранной области, которые проходят активную очередь, поиск, примененные фильтры и текущую страницу. |
| Панель фильтрации | Выбран бизнес-домен | Активен пункт бизнес-домена. | Панель фильтрации показывает параметры, применимые к выбранному бизнес-домену. |
| Панель фильтрации | Выбраны `Все задачи`, пользовательская группа, группа внутри закладки или значение группировки без одного бизнес-домена | Активна область без единственного бизнес-домена. | Панель фильтрации показывает параметры для доступного набора бизнес-доменов. |
| Настройки колонок | Выбран бизнес-домен | Активен пункт бизнес-домена. | Настройки колонок показывают колонки выбранного бизнес-домена. |
| Настройки колонок | Выбраны `Все задачи` | Активен пункт `Все задачи`. | Настройки колонок показывают объединенный набор колонок доступных бизнес-доменов. |

## 11. Ограничения ответственности

| Область | Правило |
|---|---|
| Исходные данные задач | Левая навигация не изменяет значения задач. |
| Очереди | Левая навигация не изменяет значение очереди у задачи и не рассчитывает состав сегментов очередей. |
| Поиск и фильтры | Левая навигация не изменяет поисковую строку и примененные параметры фильтрации. |
| Настройки колонок | Левая навигация не изменяет состав, видимость и порядок колонок. |
| Массовые действия | Левая навигация не изменяет набор выбранных задач. |

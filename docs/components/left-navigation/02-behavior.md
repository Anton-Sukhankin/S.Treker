# Левая навигация: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает прототип.
2. В левой навигации активен пункт `Все задачи`.
3. Заголовок правой рабочей области показывает текст `Все задачи`.
4. Список задач показывает задачи всех бизнес-доменов, доступных текущей роли, с учетом активного этапа над списком.
5. Пользователь кликает по пункту бизнес-домена.
6. Выбранный пункт бизнес-домена получает активное состояние; пункт `Все задачи` теряет активное состояние.
7. Заголовок правой рабочей области показывает название выбранного бизнес-домена.
8. Список задач показывает задачи выбранного бизнес-домена с учетом активного этапа, поиска и примененных фильтров.
9. Бейджи счетчиков в левой навигации показывают числа задач по текущим данным и примененным фильтрам.

## 2. Выбор основной области задач

### 2.1. Видимый результат выбора

| Объект выбора | Видимый результат |
|---|---|
| `Все задачи` | Правая рабочая область показывает задачи всех бизнес-доменов, доступных текущей роли. |
| Бизнес-домен | Правая рабочая область показывает задачи только выбранного бизнес-домена. |
| Активная область задач | В левой навигации активен один пункт; заголовок правой рабочей области и список задач показывают результат этого пункта. |

### 2.2. Мини-путь пользователя

1. Пользователь видит пункт `Все задачи` и список бизнес-доменов в левой навигации.
2. Пользователь кликает по пункту `Все задачи` или по бизнес-домену.
3. Выбранный пункт получает активное состояние.
4. Остальные пункты левой навигации теряют активное состояние.
5. Заголовок правой рабочей области показывает название выбранного пункта.
6. Список задач показывает задачи выбранной области с учетом активного этапа, поиска и примененных фильтров.

### 2.3. Реакции интерфейса

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по `Все задачи` | Активен бизнес-домен, значение группировки, пользовательская группа или группа внутри закладки | `Все задачи` получает активное состояние; остальные пункты левой навигации теряют активное состояние; заголовок правой рабочей области показывает `Все задачи`; список задач показывает задачи всех бизнес-доменов, доступных текущей роли, с учетом активного этапа, поиска и примененных фильтров. |
| Клик по бизнес-домену | Бизнес-домен видим в левой навигации и не активен | Выбранный бизнес-домен получает активное состояние; остальные пункты левой навигации теряют активное состояние; заголовок правой рабочей области показывает название бизнес-домена; список задач показывает задачи выбранного бизнес-домена с учетом активного этапа, поиска и примененных фильтров. |
| Клик по активному пункту `Все задачи` или активному бизнес-домену | Пункт уже активен | Активный пункт сохраняет активное состояние; заголовок правой рабочей области сохраняет текущий текст; список задач сохраняет текущий набор задач. |

Поиск, примененные фильтры и активный этап не сбрасываются при выборе `Все задачи` или бизнес-домена; список задач применяет их к новой выбранной области.

## 3. Появление вложенной группировки

### 3.1. Мини-путь пользователя

1. Пользователь находится в табличном виде списка задач.
2. В заголовке группируемой колонки видна кнопка действия группировки.
3. Пользователь кликает по кнопке действия группировки.
4. Левая навигация показывает вложенную группировку под текущим пунктом `Все задачи` или бизнес-доменом.
5. Заголовок группировки показывает формат `По ...` с названием выбранного атрибута.
6. Список значений группировки показывает значения выбранного атрибута и счетчики задач.
7. Пользователь выбирает значение группировки в левой навигации.

### 3.2. Реакции интерфейса

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке действия группировки в заголовке колонки таблицы | Активен `Все задачи` или бизнес-домен; открыт табличный вид; колонка поддерживает группировку | Под активным пунктом левой навигации виден блок вложенной группировки; заголовок блока показывает формат `По ...`; список значений показывает значения выбранного атрибута. |
| Клик по кнопке действия группировки по тому же атрибуту | Под активным пунктом уже есть группировка по этому атрибуту | В левой навигации остается одна группировка по этому атрибуту; список значений показывает актуальный набор значений. |
| Клик по кнопке действия группировки | Активно значение группировки, пользовательская группа или группа внутри закладки | Новая группировка не создается; левая навигация сохраняет текущую активную область. |

Короткий внешний результат: действие начинается в табличном списке задач; левая навигация показывает блок `По ...` под активным пунктом. Полный контракт владельцев и получателей результата находится в `03-data-states-rules.md`.

## 4. Выбор значения группировки

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по значению группировки | Значение видимо под пунктом `Все задачи` или бизнес-доменом | Значение получает активное состояние; родительский пункт и остальные значения теряют активное состояние; заголовок правой рабочей области показывает формат `Область • Значение`; список задач показывает задачи выбранного значения. |
| Клик по значению `Без значения` | Значение `Без значения` видимо в списке значений группировки | Значение `Без значения` получает активное состояние; список задач показывает задачи выбранной области, у которых атрибут группировки пустой. |
| Клик по значению группировки | В поиске есть текст или в панели фильтрации есть примененные параметры | Значение получает активное состояние; список задач показывает задачи выбранного значения, которые проходят текущий поиск и примененные фильтры. |

## 5. Раскрытие и сворачивание группировок

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке раскрытия у пункта `Все задачи` или бизнес-домена | У пункта есть созданные группировки; область вложенных группировок скрыта | Область вложенных группировок под пунктом видима. |
| Клик по кнопке раскрытия у пункта `Все задачи` или бизнес-домена | У пункта есть созданные группировки; область вложенных группировок видима | Область вложенных группировок под пунктом скрыта. |
| Клик по заголовку группировки `По ...` | Список значений этой группировки скрыт | Список значений внутри этой группировки видим. |
| Клик по заголовку группировки `По ...` | Список значений этой группировки видим | Список значений внутри этой группировки скрыт. |
| Вертикальная прокрутка внутри переполненной области вложенных группировок | Список группировок или значений не помещается по высоте под пунктом `Все задачи` или бизнес-доменом | Прокручивается только область вложенных группировок этого пункта; родительский пункт остается на месте; поверх области на время прокрутки виден тонкий светло-серый индикатор без стрелок. |

При сворачивании области группировок выбранная область задач сохраняет текущее значение; список задач сохраняет текущий набор задач.

## 6. Сброс и удаление группировок

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке сброса группировок у пункта | У пункта `Все задачи` или бизнес-домена есть минимум одна группировка | Все группировки этого пункта удалены из левой навигации. |
| Клик по кнопке сброса группировок у пункта | Активно значение группировки этого пункта | Активная область получает значение родительского пункта `Все задачи` или бизнес-домена; заголовок показывает название родительского пункта; список задач показывает задачи родительского пункта. |
| Клик по кнопке удаления значения группировки | Значение видимо в списке группировки | Значение удалено из списка группировки. |
| Клик по кнопке удаления значения группировки | Удаляемое значение было активным | Активная область получает значение родительского пункта `Все задачи` или бизнес-домена; заголовок показывает название родительского пункта; список задач показывает задачи родительского пункта. |
| Удаление последнего значения группировки | В группировке не остается видимых значений | Группировка исчезает из левой навигации. |

## 7. Пользовательские группы

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Создание группы из выбранных задач | Пользователь выбрал минимум одну задачу в списке и подтвердил создание группы | В левой навигации виден блок пользовательских групп; внутри блока виден новый пункт группы. |
| Клик по пользовательской группе | Группа видима | Группа получает активное состояние; заголовок правой рабочей области показывает название группы; список задач показывает задачи этой группы. |
| Клик по кнопке удаления пользовательской группы | Группа видима | Группа удалена из левой навигации. |
| Клик по кнопке удаления пользовательской группы | Удаляемая группа была активной | Активная область получает значение `Все задачи`; заголовок показывает `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. |
| Удаление всех задач из активной пользовательской группы | После удаления в группе не остается задач | Группа удалена; активная область получает значение `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. |

## 8. Закладки

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по заголовку закладки | Закладка свернута | Тело закладки с группами видимо. |
| Клик по заголовку закладки | Закладка раскрыта | Тело закладки с группами скрыто. |
| Клик по группе внутри закладки | Группа видима | Группа получает активное состояние; заголовок правой рабочей области показывает название группы; список задач показывает задачи этой группы. |
| Клик по кнопке удаления закладки | Закладка видима | Закладка и все группы внутри нее удалены из левой навигации. |
| Клик по кнопке удаления закладки | Активна группа внутри удаляемой закладки | Активная область получает значение `Все задачи`; заголовок показывает `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. |

## 9. Изменение ширины

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Наведение на область между левой навигацией и правой рабочей областью | Курсор находится на области изменения ширины | Курсор показывает состояние изменения горизонтального размера. |
| Зажатие левой кнопки мыши на области изменения ширины | Курсор находится на области изменения ширины | Начинается изменение ширины левой навигации. |
| Перетаскивание вправо | Изменение ширины активно; новая ширина меньше максимальной | Левая навигация получает большую ширину; правая рабочая область начинается правее. |
| Перетаскивание вправо | Левая навигация достигла максимальной ширины | Ширина левой навигации сохраняет максимальное значение; правая рабочая область остается справа от левой навигации. |
| Перетаскивание влево | Изменение ширины активно; новая ширина больше минимальной | Левая навигация получает меньшую ширину; правая рабочая область начинается левее. |
| Перетаскивание влево | Левая навигация достигла минимальной ширины | Ширина левой навигации сохраняет минимальное значение; правая рабочая область не заходит под левую навигацию. |
| Отпускание левой кнопки мыши | Изменение ширины активно | Изменение ширины завершается; курсор показывает обычное состояние вне области изменения ширины. |

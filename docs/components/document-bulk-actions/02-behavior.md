# Массовые действия документов: поведение

## 1. Основной пользовательский путь

1. Пользователь выбирает один или несколько доступных документов в таблице документов.
2. Интерфейс показывает плавающую панель массовых действий документов.
3. Пользователь выбирает действие на панели.
4. Интерфейс применяет действие к выбранному набору документов или открывает связанный слой.
5. Интерфейс показывает итог действия: измененные строки, открытый дровер, модальное окно или toast.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Выбор чекбокса доступной строки документа | Выбранных документов нет | Плавающая панель видна; счетчик панели получает значение `1`. |
| 2 | Выбор нескольких доступных строк | Плавающая панель уже видна | Счетчик панели показывает количество выбранных документов. |
| 3 | Клик по кнопке закрытия панели | Выбран минимум один документ | Все строки получают невыбранное состояние; плавающая панель скрыта. |

## 3. Действия плавающей панели

### Связи документа

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Клик по `Связи документа` | Выбран минимум один документ | Открывается дровер связей; дровер получает выбранный набор документов. |

### Добавить в пакет

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Клик по `Добавить в пакет` | Выбран минимум один документ | Открывается модальное окно `Добавить в пакет`; счетчик в заголовке окна показывает количество выбранных документов; кнопка `Применить` недоступна. |
| Выбор пакета в дереве модального окна | Модальное окно открыто; целевой пакет не выбран | Дочерняя зона выбора пакетов показывает выбранный пакет; кнопка `Применить` доступна. |
| Клик по `Применить` | Выбран минимум один целевой пакет | Модальное окно закрыто; выбранные документы получают выбранный пакет; toast показывает подтверждение добавления. |
| Клик по `Отмена` или кнопке закрытия | Модальное окно открыто | Модальное окно закрыто; выбранный набор документов в таблице сохраняется. |

### Пометка на удаление

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Клик по `Пометка на удаление` | Выбран минимум один документ | Выбранные документы получают индикатор пометки на удаление; выбранный набор сбрасывается; плавающая панель скрыта; toast показывает подтверждение. |
| Выбор строки с пометкой на удаление | Документ помечен на удаление | Плавающая панель видна; кнопка `Снять пометку` видна. |
| Клик по `Снять пометку` | Среди выбранных документов есть документ с пометкой на удаление | У выбранных документов снята пометка на удаление; выбранный набор сбрасывается; плавающая панель скрыта; toast показывает подтверждение. |

### Скачать

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Клик по `Скачать` | Выбран минимум один документ | В текущем прототипе видимое состояние интерфейса не меняется. |

## 4. Короткие внешние результаты

| Действие в текущем компоненте | Компонент-получатель | Видимый результат |
|---|---|---|
| `Связи документа` | Дровер связей документа | Дровер открыт поверх рабочей области поиска. |
| `Пометка на удаление` | Список документов | Строки выбранных документов показывают индикатор пометки. |
| `Снять пометку` | Список документов | Строки выбранных документов больше не показывают индикатор пометки. |
| `Добавить в пакет` → `Применить` | Список документов | Строки выбранных документов сохраняют выбор; пакет документа изменен на выбранный пакет. |
| Выбор пакета в модальном окне | `document-package-selector` | Дерево показывает выбранные целевые пакеты для применения родительского действия. |

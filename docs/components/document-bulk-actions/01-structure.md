# Массовые действия документов: структура

## 1. Граница функционального блока

| Условие | Область интерфейса | Видимый результат |
|---|---|---|
| В таблице документов выбран минимум один доступный документ | Поверх рабочей области поиска, в нижней центральной части видимой области | Видна плавающая панель массовых действий документов. |
| Выбранных документов нет | Рабочая область поиска | Плавающая панель массовых действий документов скрыта. |

## 2. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Плавающая панель массовых действий документов | Часть компонента | Показывает счетчик выбранных документов и действия над выбранным набором. |
| Кнопка закрытия панели | Часть компонента | Снимает выбор со всех документов и скрывает панель. |
| Модальное окно `Добавить в пакет` | Часть компонента | Открывается из плавающей панели и содержит дочернюю зону выбора пакетов. |
| Дерево выбора пакетов | Дочерняя зона с собственным комплектом | Показывает пакеты и выбранные целевые пакеты внутри модального окна `Добавить в пакет`. |
| Toast после действия | Внешний получатель результата | Показывает текстовое подтверждение после пометки, снятия пометки или добавления в пакет. |
| Таблица документов | Внешняя точка входа | Чекбоксы строк и чекбокс заголовка формируют выбранный набор документов. |
| Дровер связей документа | Внешний получатель результата | Открывается после действия `Связи документа` для выбранного набора. |
| Левая панель поиска | Соседняя область без участия | Не меняет состав кнопок панели массовых действий. |

## 4. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Состав | Что не входит |
|---|---|---|---|---|---|
| Плавающая панель | Нижняя центральная часть видимой области поверх рабочей области поиска | Таблица документов остается под панелью | Выбран минимум один доступный документ | Счетчик `Результат`, кнопки действий, кнопка закрытия | Строки таблицы, фильтры, пагинация, дровер связей. |
| Счетчик панели | Левая часть плавающей панели | Кнопки действий справа | Плавающая панель видна | Текст `Результат:` и числовой бейдж выбранных документов | Счетчик результатов поиска. |
| Группа действий | Центральная часть плавающей панели | Счетчик слева; кнопка закрытия справа | Плавающая панель видна | `Связи документа`, `Добавить в пакет`, `Скачать`, `Снять пометку` при наличии помеченного документа, `Пометка на удаление` | Меню строки документа. |
| Кнопка закрытия панели | Правая часть плавающей панели | Группа действий слева | Плавающая панель видна | Иконка закрытия | Закрытие рабочей области поиска. |
| Модальное окно `Добавить в пакет` | Поверх рабочей области поиска и поверх плавающей панели | Затемненный слой перекрывает рабочую область поиска | Пользователь выбирает действие `Добавить в пакет` | Хедер с названием и счетчиком, область дочернего дерева выбора пакетов, футер с кнопками `Отмена` и `Применить` | Таблица документов, дровер связей, настройки колонок. |

## 5. Состав плавающей панели

| Элемент | Положение | Условие показа | Видимое состояние |
|---|---|---|---|
| Счетчик выбранных документов | Левая часть панели | Панель видна | Показывает количество выбранных документов. |
| Кнопка `Связи документа` | В группе действий | Панель видна | Кнопка доступна. |
| Кнопка `Добавить в пакет` | В группе действий | Панель видна | Кнопка доступна. |
| Кнопка `Скачать` | В группе действий | Панель видна | Кнопка видна; текущий прототип не показывает отдельный результат после клика. |
| Кнопка `Снять пометку` | В группе действий | Среди выбранных документов есть минимум один документ с пометкой на удаление | Кнопка видна. |
| Кнопка `Пометка на удаление` | Правая часть группы действий | Панель видна | Кнопка видна. |
| Кнопка закрытия | Крайняя правая часть панели | Панель видна | Кнопка видна. |

## 6. Состав модального окна `Добавить в пакет`

| Зона | Положение внутри модального окна | Состав зоны |
|---|---|---|
| Хедер | Верхняя часть окна | Заголовок `Добавить в пакет`, счетчик выбранных документов, кнопка закрытия. |
| Основная область | Между хедером и футером | Дочерняя зона `document-package-selector`: дерево пакетов с индикаторами выбора целевых пакетов. |
| Футер | Нижняя часть окна | Кнопки `Отмена` и `Применить`. |

## 8. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Плавающая панель | Floating bar | Выбор минимум одного доступного документа делает видимой панель со счетчиком и действиями выбранного набора. | Заполняется после утверждения DS-карты. |
| Счетчик панели | Counter / badge | Число в панели равно количеству выбранных доступных документов. | Заполняется после утверждения DS-карты. |
| Группа действий | Button group | Набор кнопок применяет действия к выбранным документам; `Снять пометку` видна только при наличии помеченного документа. | Заполняется после утверждения DS-карты. |
| Модальное окно `Добавить в пакет` | Modal | Действие `Добавить в пакет` открывает окно с дочерним деревом выбора пакетов и футером применения. | Заполняется после утверждения DS-карты. |
| Toast после действия | Toast | После успешного действия показывает текстовое подтверждение результата. | Заполняется после утверждения DS-карты. |

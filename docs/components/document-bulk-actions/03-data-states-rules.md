# Массовые действия документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| `documents-list` | Выбранный набор документов | Плавающая панель видна, если набор содержит минимум один документ. |
| Плавающая панель массовых действий | Количество выбранных документов | Счетчик панели показывает размер выбранного набора. |
| Плавающая панель массовых действий | Наличие помеченных документов в выбранном наборе | Кнопка `Снять пометку` видна, если минимум один выбранный документ помечен на удаление. |
| `document-package-selector` | Целевые пакеты | Кнопка `Применить` доступна, если выбран минимум один пакет. |
| Список документов | Пометка документа на удаление | Строка документа показывает или скрывает индикатор пометки. |
| Список документов | Пакеты документа | После применения модального окна выбранные документы получают выбранные пакеты. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Панель скрыта | Выбранных документов нет | Плавающая панель не видна. | Пользователь выбирает минимум один доступный документ. |
| Панель видна | Выбран минимум один доступный документ | Плавающая панель видна; счетчик показывает количество выбранных документов. | Пользователь снимает выбор со всех документов или применяет действие, которое сбрасывает выбранный набор. |
| Частичный выбранный набор | Выбрана часть доступных строк текущей страницы | Панель видна; счетчик показывает количество выбранных документов. | Пользователь выбирает все строки, снимает выбор или меняет выдачу. |
| Набор содержит помеченный документ | Среди выбранных документов есть минимум один документ с пометкой на удаление | Кнопка `Снять пометку` видна. | Пользователь снимает выбор с помеченных документов или применяет `Снять пометку`. |
| Модальное окно добавления в пакет открыто | Пользователь выбрал `Добавить в пакет` при непустом выбранном наборе | Модальное окно видимо; счетчик в заголовке равен количеству выбранных документов; кнопка `Применить` недоступна до выбора пакета. | Пользователь применяет добавление, нажимает `Отмена` или закрывает модальное окно. |
| Целевой пакет выбран | В дочернем дереве выбора пакетов выбран минимум один пакет | Кнопка `Применить` доступна. | Пользователь снимает выбор со всех пакетов или закрывает модальное окно. |

## 3. Счетчики, видимость и применимость

| Элемент или значение | Условие | Видимый результат |
|---|---|---|
| Счетчик плавающей панели | Выбранный набор содержит `N` документов | Бейдж панели показывает `N`. |
| Счетчик модального окна `Добавить в пакет` | Модальное окно открыто при выбранном наборе `N` документов | В заголовке окна показано число `N`. |
| Кнопка `Снять пометку` | В выбранном наборе есть минимум один документ с пометкой на удаление | Кнопка видна. |
| Кнопка `Снять пометку` | В выбранном наборе нет документов с пометкой на удаление | Кнопка скрыта. |
| Кнопка `Применить` в модальном окне | Выбран минимум один целевой пакет | Кнопка доступна. |
| Кнопка `Применить` в модальном окне | Целевой пакет не выбран | Кнопка недоступна. |

## 4. Правила данных

| Данные или значение | Источник для интерфейса | Где используется | Видимый результат |
|---|---|---|---|
| Выбранный набор документов | Чекбоксы строк и чекбокс заголовка таблицы документов | Плавающая панель, модальное окно, дровер связей | Панель и связанные слои получают количество и состав выбранного набора. |
| Пометка на удаление | Действие `Пометка на удаление` или `Снять пометку` | Строка документа и кнопка `Снять пометку` | Строка показывает индикатор пометки; кнопка снятия видна только при наличии помеченного документа в выбранном наборе. |
| Целевые пакеты | Дочернее дерево выбора пакетов в модальном окне | Действие `Применить` | Выбранные документы получают выбранные пакеты. |
| Текст toast | Завершенное действие массовой панели | Toast | Пользователь видит подтверждение выполненного действия. |

## 5. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `documents-list` | Источник выбранного набора и получатель результата | Пользователь выбирает или снимает выбор документов | Панель показывает или скрывает действия и счетчик. | Строки получают выбранное или невыбранное состояние. |
| `documents-list` | Получатель результата пометки | Пользователь применяет `Пометка на удаление` или `Снять пометку` | Панель скрыта после сброса выбранного набора. | Строки показывают или скрывают индикатор пометки. |
| `document-package-selector` | Источник целевых пакетов | Пользователь выбирает пакеты в модальном окне `Добавить в пакет` | Кнопка `Применить` становится доступной при непустом целевом наборе. | Дерево показывает выбранные строки пакетов. |
| Дровер связей документа | Получатель выбранного набора | Пользователь выбирает `Связи документа` | Панель остается в текущем состоянии до дальнейшего действия пользователя. | Дровер открывается и показывает связи выбранного набора. |
| Toast | Получатель результата | Завершено действие пометки, снятия пометки или добавления в пакет | Панель показывает состояние после действия или скрыта после сброса выбора. | Toast показывает текст подтверждения. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Таблица документов | Компонент массовых действий не создает строки и не меняет видимый набор выдачи; он получает выбранный набор из таблицы. |
| Поиск и фильтры | Компонент массовых действий не изменяет условия поиска и фильтрации. |
| Пагинация | Компонент массовых действий не меняет текущую страницу. |
| Дровер связей | Компонент массовых действий открывает дровер с выбранным набором, но не описывает внутреннюю навигацию дровера. |
| Скачать | При выборе `Скачать` видимое состояние рабочей области поиска не меняется. |

# Панель инструментов списка задач: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает обычный список задач: `Все задачи` или бизнес-домен.
2. Toolbar показывает поле `Поиск по задачам`, переключатель вида, `Печать`, `Фильтры` и `Создать задачу`.
3. Пользователь вводит текст в `Поиск по задачам`.
4. Список задач показывает только задачи, где введенный текст найден в простых текстовых или числовых значениях задачи.
5. Пользователь выбирает сегмент табличного вида в переключателе вида.
6. Карточный список скрыт; табличный список видим; `Настройка колонок` и `Скачать` видимы.
7. Пользователь нажимает `Фильтры`.
8. Поверх рабочей области видны затемнение фона и правая панель фильтрации.

## 2. Поиск

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Ввод текста в `Поиск по задачам` | Поле пустое | Поле показывает введенный текст; таблица или карточки показывают задачи, где введенный текст найден в простых текстовых или числовых значениях задачи. |
| Изменение текста в `Поиск по задачам` | Поле уже заполнено | Поле показывает новое значение; таблица или карточки показывают задачи, где новый текст найден в простых текстовых или числовых значениях задачи. |
| Очистка поля `Поиск по задачам` | Поле заполнено | Поле получает пустое значение; таблица или карточки показывают набор задач без ограничения поисковой строкой. |
| Ввод или очистка текста в `Поиск по задачам` | Правая панель фильтрации открыта | Правая панель фильтрации остается открытой; список задач за панелью получает результат поиска. |

Поиск не входит в число активных параметров на кнопке `Фильтры`.

## 3. Переключение вида

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Выбор сегмента карточного вида | Активен табличный вид | Табличный список скрыт; карточный список видим; `Настройка колонок` скрыта; `Скачать` скрыта; `Печать` остается видимой. |
| Выбор сегмента табличного вида | Активен карточный вид | Карточный список скрыт; табличный список видим; `Настройка колонок` видима; `Скачать` видима; `Печать` остается видимой. |
| Выбор уже активного сегмента | Сегмент уже выбран | Видимый список и состав кнопок не меняются. |

При переключении вида выбранная область задач, активная очередь, поисковая строка, примененные параметры фильтрации и текущий набор задач сохраняют текущие значения.

## 4. Кнопка `Фильтры` и быстрый сброс

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке `Фильтры` | Правая панель фильтрации закрыта, активных параметров фильтрации нет | Затемнение фона видимо; правая панель фильтрации видима; параметры панели открываются с пустыми значениями. |
| Клик по текстовой части кнопки `Фильтры` | Правая панель фильтрации закрыта, есть минимум один активный параметр фильтрации | Затемнение фона видимо; правая панель фильтрации видима; параметры панели открываются с текущими выбранными значениями. |
| Наведение курсора на круглый счетчик кнопки `Фильтры` | Есть минимум один активный параметр фильтрации | Число внутри счетчика скрыто; внутри счетчика видна иконка крестика. |
| Клик по круглому счетчику кнопки `Фильтры` | Есть минимум один активный параметр фильтрации | Все примененные параметры фильтрации получают пустое значение; круглый счетчик скрыт; иконка фильтра видима; поисковая строка сохраняет текущее значение; список задач показывает набор без параметров панели фильтрации. |

## 5. Кнопки действий

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по `Настройка колонок` | Активен табличный вид, кнопка видима | Затемнение фона видимо; правая панель настройки колонок видима. |
| Клик по `Скачать` | Активен табличный вид, кнопка видима | В текущем прототипе видимое состояние интерфейса не меняется. |
| Клик по `Печать` | Кнопка видима | Интерфейс показывает системное уведомление `Подготовка к печати...`. |
| Клик по `Создать задачу` | Выбраны `Все задачи` или бизнес-домен, кнопка видима | В текущем прототипе видимое состояние интерфейса не меняется. |

## 6. Пользовательская группа

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Выбор пользовательской группы в левой навигации | Открыт обычный список задач | Заголовок правого блока показывает название пользовательской группы, переключатель вида и действия списка; toolbar показывает `Поиск по задачам` и `Фильтры`; `Создать задачу` скрыта; `Очереди` скрыты; список задач расположен под toolbar. |
| Выбор сегмента карточного вида | Выбрана пользовательская группа, активен табличный вид, переключатель вида расположен в заголовке правого блока | Табличный список скрыт; карточный список видим; в заголовке правого блока скрыты `Настройка колонок` и `Скачать`; `Печать` остается видимой. |
| Выбор сегмента табличного вида | Выбрана пользовательская группа, активен карточный вид, переключатель вида расположен в заголовке правого блока | Карточный список скрыт; табличный список видим; в заголовке правого блока видны `Настройка колонок`, `Скачать` и `Печать`. |
| Клик по `Настройка колонок` | Выбрана пользовательская группа, активен табличный вид, кнопка видима в заголовке правого блока | Затемнение фона видимо; правая панель настройки колонок видима. |
| Клик по `Скачать` | Выбрана пользовательская группа, активен табличный вид, кнопка видима в заголовке правого блока | В текущем прототипе видимое состояние интерфейса не меняется. |
| Клик по `Печать` | Выбрана пользовательская группа, кнопка видима в заголовке правого блока | Интерфейс показывает системное уведомление `Подготовка к печати...`. |

Выбор этапа согласования, активное состояние сегментов и счетчики этапов относятся к компоненту `Очереди`, а не к toolbar.

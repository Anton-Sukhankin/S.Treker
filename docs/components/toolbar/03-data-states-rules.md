# Панель инструментов списка задач: данные, состояния и правила

## 1. Владельцы состояния

| Владелец | Состояние или значение | Видимый результат в toolbar | Ограничение ответственности toolbar |
|---|---|---|---|
| Левая навигация | Выбранная область задач: `Все задачи`, бизнес-домен или пользовательская группа | При `Все задачи` или бизнес-домене toolbar показывает обычную компоновку; при пользовательской группе toolbar показывает компоновку с перенесенными действиями. | Toolbar не выбирает область задач и не изменяет состав бизнес-доменов или пользовательских групп. |
| Toolbar | Поисковая строка | Поле `Поиск по задачам` показывает пустое значение или введенный текст. | Toolbar передает поисковую строку списку задач, но не изменяет значения задач. |
| Toolbar | Выбранный режим отображения | Переключатель вида показывает активный карточный или табличный режим; состав кнопок соответствует выбранному режиму. | Toolbar не строит карточки, строки таблицы или значения ячеек. |
| Панель фильтрации | Примененные параметры фильтрации и количество активных параметров | Кнопка `Фильтры` показывает иконку фильтра при `0` активных параметров или круглый счетчик при `N` активных параметрах. | Toolbar не владеет составом параметров фильтрации и не хранит черновые значения панели фильтрации. |
| Список задач | Итоговый набор задач и активный способ отображения набора | Список показывает результат поиска и выбранный режим отображения. | Toolbar не рассчитывает итоговые строки таблицы и карточки списка. |
| `Очереди` | Активный этап согласования и счетчики этапов | Toolbar не показывает сегменты очередей и не показывает счетчики этапов. | Toolbar не хранит активный этап и не рассчитывает счетчики этапов. |
| Заголовок правого блока | Название выбранной области задач и место размещения перенесенных действий | При пользовательской группе заголовок визуально содержит переключатель вида и действия списка. | Toolbar не изменяет текст заголовка выбранной области задач. |

## 2. Интерфейсные состояния toolbar

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Обычная компоновка toolbar | В левой навигации выбраны `Все задачи` или бизнес-домен | Toolbar находится под заголовком правого блока; в toolbar видны поиск, переключатель вида, `Печать`, `Фильтры`, `Создать задачу`; в табличном виде дополнительно видны `Настройка колонок` и `Скачать`. | Пользователь выбирает пользовательскую группу в левой навигации. |
| Компоновка пользовательской группы | В левой навигации выбрана пользовательская группа | Toolbar показывает `Поиск по задачам` и `Фильтры`; переключатель вида и действия списка расположены в заголовке правого блока; `Создать задачу` скрыта; `Очереди` скрыты. | Пользователь выбирает `Все задачи` или бизнес-домен в левой навигации. |
| Пустая поисковая строка | Поле `Поиск по задачам` пустое | Поисковая строка не ограничивает видимый набор задач. | Пользователь вводит текст в поле `Поиск по задачам`. |
| Заполненная поисковая строка | В поле `Поиск по задачам` введен текст | Поле показывает введенный текст; список задач показывает только задачи, которые проходят поисковую строку. | Пользователь очищает поле `Поиск по задачам`. |
| Карточный вид | В переключателе вида выбран карточный режим | Список задач показан карточками; `Настройка колонок` и `Скачать` скрыты; `Печать` остается видимой. | Пользователь выбирает табличный вид. |
| Табличный вид | В переключателе вида выбран табличный режим | Список задач показан таблицей; `Настройка колонок`, `Скачать` и `Печать` видимы. | Пользователь выбирает карточный вид. |
| Нет активных параметров фильтрации | Панель фильтрации передает `0` активных примененных параметров | На кнопке `Фильтры` видима иконка фильтра; круглый счетчик скрыт. | Панель фильтрации передает минимум один активный примененный параметр. |
| Есть активные параметры фильтрации | Панель фильтрации передает `N` активных примененных параметров, где `N` больше `0` | На кнопке `Фильтры` иконка фильтра скрыта; круглый счетчик показывает `N`. | Пользователь нажимает круглый счетчик или панель фильтрации передает `0` активных примененных параметров. |

## 3. Правила поиска и отбора задач

| Условие | Задача остается в списке | Задача исключается из списка |
|---|---|---|
| Поле `Поиск по задачам` пустое | Задача проходит правило поиска независимо от текстовых и числовых значений. | Поисковая строка не исключает задачи. |
| Поле `Поиск по задачам` заполнено | Введенный текст найден минимум в одном простом текстовом или числовом значении задачи. | Введенный текст не найден ни в одном простом текстовом или числовом значении задачи. |
| Поле заполнено и применены параметры фильтрации | Задача проходит поисковую строку и все примененные параметры фильтрации. | Задача не проходит поисковую строку или минимум один примененный параметр фильтрации. |
| Поле заполнено и активна очередь | Задача проходит поисковую строку и относится к активной очереди. | Задача не проходит поисковую строку или не относится к активной очереди. |

Поисковая строка не увеличивает счетчик активных параметров на кнопке `Фильтры`.

## 4. Правила кнопки `Фильтры`

| Состояние примененных параметров панели фильтрации | Значение счетчика | Вид кнопки `Фильтры` |
|---|---:|---|
| Все примененные параметры панели пустые | `0` | Иконка фильтра видима; круглый счетчик скрыт. |
| Активен один примененный параметр панели | `1` | Иконка фильтра скрыта; круглый счетчик показывает `1`. |
| Активны несколько примененных параметров панели | `N` | Иконка фильтра скрыта; круглый счетчик показывает количество активных примененных параметров. |
| Активна только поисковая строка | `0` | Иконка фильтра видима; круглый счетчик скрыт. |

После быстрого сброса через круглый счетчик все примененные параметры панели фильтрации получают пустое значение. Поисковая строка после быстрого сброса сохраняет текущее значение.

## 5. Контракты взаимодействия

| Тип связи | Источник | Передаваемый результат | Получатель | Видимый итог |
|---|---|---|---|---|
| Входящее условие компоновки | Левая навигация | Выбраны `Все задачи` или бизнес-домен | Toolbar | Toolbar показывает обычный состав поиска, переключателя вида и кнопок действий; `Очереди` видимы под toolbar. |
| Входящее условие компоновки | Левая навигация | Выбрана пользовательская группа | Toolbar, заголовок правого блока, `Очереди` | Toolbar показывает поиск и `Фильтры`; заголовок показывает переключатель вида и действия списка; `Очереди` скрыты. |
| Исходящий результат поиска | Поле `Поиск по задачам` в toolbar | Пустая или заполненная поисковая строка | Список задач | Список показывает задачи без ограничения поиском или только задачи, которые проходят поисковую строку. |
| Исходящий результат режима отображения | Переключатель вида в toolbar или в заголовке правого блока | Карточный или табличный режим | Список задач | Список задач виден карточками или таблицей; состав кнопок toolbar соответствует выбранному режиму. |
| Исходящее действие открытия | Кнопка `Фильтры` | Запрос на открытие панели фильтрации | Правая панель фильтрации | Правая панель фильтрации видима поверх рабочей области. |
| Входящее состояние индикатора | Панель фильтрации | Количество активных примененных параметров | Кнопка `Фильтры` | Кнопка показывает иконку фильтра при `0` или круглый счетчик `N` при активных параметрах. |
| Исходящее действие сброса | Круглый счетчик на кнопке `Фильтры` | Сброс примененных параметров панели фильтрации | Панель фильтрации и список задач | Примененные параметры фильтрации пустые; список задач показывает результат без параметров панели фильтрации и с сохраненной поисковой строкой. |
| Исходящее действие открытия | Кнопка `Настройка колонок` | Запрос на открытие панели настройки колонок | Правая панель настройки колонок | Правая панель настройки колонок видима поверх рабочей области. |
| Исходящее действие обратной связи | Кнопка `Печать` | Запрос печати текущего списка | Системное уведомление | Видимо уведомление `Подготовка к печати...`. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Исходные данные задач | Toolbar не изменяет значения задач. |
| Бизнес-домены и пользовательские группы | Toolbar не изменяет состав, порядок или доступность областей задач в левой навигации. |
| Панель фильтрации | Toolbar не создает параметры фильтрации, не хранит черновые значения панели и не владеет правилами применения параметров. |
| Библиотека атрибутов | Toolbar не изменяет состав библиотеки атрибутов. |
| Пресеты колонок | Toolbar не создает, не сохраняет и не удаляет пресеты колонок. |
| `Очереди` | Toolbar не хранит активный этап, не формирует сегменты очередей и не рассчитывает счетчики этапов. |

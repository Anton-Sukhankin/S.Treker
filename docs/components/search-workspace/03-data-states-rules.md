# Рабочая область поиска: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| `app-header` | Активный пункт `Поиск` или `Задачи` | При активном пункте `Поиск` рабочая область поиска видна; при активном пункте `Задачи` рабочая область задач видна. |
| Рабочая область поиска | Видимость области | Видна только при активном пункте `Поиск`. |
| Рабочая область задач | Видимость области задач | Скрыта при активном пункте `Поиск`; видна при активном пункте `Задачи`. |
| Поиск документов | Фильтры, таблица документов, дроверы, модальные окна, шаблоны и настройки | Состояние остается внутри рабочей области поиска. |
| Компоненты задач | Фильтры задач, колонки задач, выбор задач, очереди и пагинация задач | Не получают значения из поиска документов. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Скрыта | Активен пункт `Задачи` | Рабочая область поиска не видна; рабочая область задач видна. | Пользователь выбирает `Поиск`. |
| Видна | Активен пункт `Поиск` | Рабочая область поиска видна под хедером; рабочая область задач скрыта. | Пользователь выбирает `Задачи`. |
| Внутренний поиск изменен | Пользователь меняет фильтр, строку поиска, таблицу или слой поиска документов | Таблица документов, счетчик документов, открытый слой или поле ввода получает новое видимое состояние внутри поиска документов. | Пользователь сбрасывает или меняет соответствующее состояние внутри поиска документов. |

## 3. Счетчики, видимость и применимость

| Элемент или значение | Условие | Видимый результат |
|---|---|---|
| Счетчик документов | Поиск документов пересчитал итоговый набор документов | Заголовок поиска показывает количество документов текущего результата. |
| Таблица документов | Значения фильтров поиска документов изменились | Таблица показывает строки, соответствующие текущим условиям поиска документов. |
| Рабочая область задач | Активен `Поиск` | Задачный layout скрыт; счетчики и таблица задач не пересчитываются из-за поиска документов. |
| Слои задач | Пользователь переходит в `Поиск` при открытых task-слоях | Открытые task-слои закрыты; выбранные задачи очищены. |

## 4. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `app-header` | Источник активного раздела | Пользователь выбирает `Поиск` | Рабочая область поиска видна | Пункт `Поиск` активен. |
| `app-header` | Источник активного раздела | Пользователь выбирает `Задачи` | Рабочая область поиска скрыта | Пункт `Задачи` активен. |
| Рабочая область задач | Соседняя область | Рабочая область поиска видна | Поиск занимает область под хедером | Рабочая область задач скрыта. |
| Поиск документов | Внутренний источник результата | Пользователь меняет фильтры или поиск документов | Область поиска остается видимой | Таблица документов показывает пересчитанные строки; счетчик показывает количество документов текущего результата. |

## 5. Ограничения ответственности

| Область | Правило |
|---|---|
| Компоненты задач | Рабочая область поиска не рассчитывает задачи, очереди, task-фильтры, task-колонки, task-пагинацию и выбор задач. |
| Детальные зоны поиска документов | Этот комплект не описывает полный состав фильтров документов, таблицы документов, дровера связей, массовых действий документов и настроек колонок документов. Эти зоны описаны в собственных компонентных комплектах. |
| Данные документов | Рабочая область поиска не создает документы и не описывает правила внешнего обмена данными; видимый набор документов показывают дочерние компоненты поиска. |
| Дизайн-система | Комплект фиксирует продуктовые условия S-Tracker; стандартные механики готовых UI-компонентов не описываются. |

# Рабочая область поиска: структура

## 1. Расположение

| Условие | Область интерфейса | Видимый результат |
|---|---|---|
| В верхней навигации активен пункт `Поиск` | Под хедером S-Tracker, вместо рабочей области задач | Видна рабочая область поиска документов. |
| В верхней навигации активен пункт `Задачи` | Под хедером S-Tracker | Рабочая область поиска скрыта; видна рабочая область задач. |

## 2. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Область поиска под хедером | Часть компонента | Занимает место рабочей области задач при активном пункте `Поиск`. |
| Левая панель поиска документов | Область размещения дочерних компонентов | Содержит `search-filters` и `search-filter-templates`. |
| Основная область результатов документов | Область размещения дочерних компонентов | Содержит заголовок выдачи, `documents-list`, `document-bulk-actions` и `document-column-settings`. |
| Слои поиска документов | Область размещения дочерних компонентов | Содержит `document-relations-drawer`, `document-package-selector`, календарь, выпадающие списки и toast внутри рабочей области поиска. |
| Верхняя навигация S-Tracker | Внешняя точка входа | Пункт `Поиск` показывает компонент; пункт `Задачи` скрывает компонент. |
| Рабочая область задач | Соседняя область | Скрыта, когда рабочая область поиска видна. |

## 4. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Состав | Что не входит |
|---|---|---|---|---|---|
| Контейнер рабочей области поиска | Под хедером S-Tracker | Хедер сверху; рабочая область задач заменена | Активен пункт `Поиск` | Одна встроенная область поиска документов | Левая навигация задач, панель инструментов задач, список задач. |
| Левая панель поиска документов | Левая часть рабочей области поиска | Основная область результатов справа | Рабочая область поиска видна | Вкладки фильтров и сохраненных шаблонов; поля и действия поиска документов | Правая панель фильтрации задач. |
| Основная область результатов документов | Правая часть рабочей области поиска | Левая панель поиска документов слева | Рабочая область поиска видна | Заголовок `Поиск по документам`, счетчик, действия, таблица документов, пагинация | Список задач S-Tracker. |
| Слои поиска документов | Поверх рабочей области поиска | Левая панель и область результатов под слоем | Пользователь открывает соответствующий слой внутри поиска документов | Дровер связей, дровер настроек колонок, модальные окна, календарь, выпадающие списки, floating bar, toast | Слои задач S-Tracker. |

## 5. Элементы и условия показа

| Элемент или зона | Условие показа | Видимое состояние |
|---|---|---|
| Рабочая область поиска | Активен пункт `Поиск` | Область видна под хедером. |
| Рабочая область поиска | Активен пункт `Задачи` | Область скрыта. |
| Содержимое поиска документов | Рабочая область поиска видна | Левая панель фильтров и таблица документов доступны внутри области поиска. |

## 6. Динамический состав

| Набор элементов | От чего зависит состав | Правило отображения |
|---|---|---|
| Результаты документов | Значения фильтров поиска документов | Таблица документов показывает набор, рассчитанный внутри рабочей области поиска. |
| Слои поиска документов | Действие пользователя внутри поиска документов | Открытый слой отображается внутри рабочей области поиска и не перекрывает task workspace, потому что task workspace скрыт. |

## 7. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `app-header` | Точка входа | Пункт `Поиск` показывает рабочую область поиска; пункт `Задачи` скрывает ее. | `app-header/02-behavior.md`, `app-header/03-data-states-rules.md`. |
| Рабочая область задач | Соседняя область | Когда поиск виден, task workspace скрыт. | `search-workspace/03-data-states-rules.md`. |

## 8. Дочерние и соседние комплекты поиска

| Комплект | Размещение в рабочей области поиска | Роль в составе |
|---|---|---|
| `search-filters` | Левая панель поиска документов | Фильтры и дополнительные атрибутные условия поиска. |
| `search-filter-templates` | Левая панель поиска документов | Сохраненные шаблоны условий поиска. |
| `documents-list` | Основная область результатов документов | Таблица выдачи, строки документов, счетчик и пагинация выдачи. |
| `document-bulk-actions` | Поверх основной области результатов документов | Плавающая панель действий выбранных документов. |
| `document-package-selector` | Модальное окно поверх рабочей области поиска | Выбор пакетов для действия `Добавить в пакет`. |
| `document-relations-drawer` | Правый слой поверх рабочей области поиска | Связи одного документа или выбранного набора документов. |
| `document-column-settings` | Правый слой поверх рабочей области поиска | Настройка колонок таблицы документов. |

## 9. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Контейнер рабочей области поиска | Рабочая область / layout section | Активный пункт `Поиск` делает видимой область поиска документов и скрывает рабочую область задач. | Заполняется после утверждения DS-карты. |
| Левая панель поиска документов | Sidebar / tabs | Активная вкладка определяет видимость фильтров или сохраненных шаблонов. | Заполняется после утверждения DS-карты. |
| Основная область результатов документов | Content area | Показывает заголовок, действия, таблицу документов и пагинацию внутри раздела `Поиск`. | Заполняется после утверждения DS-карты. |
| Слои поиска документов | Drawer / modal / floating bar / toast | Слои открываются только из действий внутри поиска документов и остаются в границах рабочей области поиска. | Заполняется после утверждения DS-карты. |

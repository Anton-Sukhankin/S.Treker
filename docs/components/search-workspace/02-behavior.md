# Рабочая область поиска: поведение

## 1. Основной пользовательский путь

1. Пользователь находится в S-Tracker с активным пунктом `Задачи`.
2. Пользователь выбирает пункт `Поиск` в верхней навигации.
3. Рабочая область задач скрывается.
4. Рабочая область поиска отображается под хедером S-Tracker.
5. Пользователь вводит текст в поле полнотекстового поиска документов.
6. Таблица документов показывает строки и счетчик, соответствующие введенному значению.
7. Пользователь выбирает пункт `Задачи` в верхней навигации.
8. Рабочая область поиска скрывается.
9. Рабочая область задач отображается под хедером S-Tracker.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Выбор пункта `Поиск` | Активен пункт `Задачи`; рабочая область задач видна | Рабочая область задач скрыта; рабочая область поиска видна. |
| 2 | Ввод текста в поле полнотекстового поиска документов | Рабочая область поиска видна; поле поиска пустое | Поле получает введенный текст; таблица документов и счетчик результата пересчитаны. |
| 3 | Выбор пункта `Задачи` | Активен пункт `Поиск`; рабочая область поиска видна | Рабочая область поиска скрыта; рабочая область задач видна. |

## 3. Вторичные механики

### Закрытие task-слоев при входе в поиск

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Выбор пункта `Поиск` | В рабочей области задач открыт дровер, модальное окно, выпадающий список или плавающая панель выбора задач | Слои задач закрыты; выбор задач очищен; рабочая область поиска видна. |

### Изолированная работа поиска документов

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Работа с фильтрами, таблицей, дроверами или модальными окнами поиска документов | Рабочая область поиска видна | Изменяется только интерфейс поиска документов; рабочая область задач остается скрытой и не получает состояния поиска документов. |

## 4. Короткие внешние результаты

| Действие в текущем компоненте | Компонент-получатель | Видимый результат |
|---|---|---|
| Переход в `Поиск` | `app-header` | Пункт `Поиск` активен. |
| Возврат в `Задачи` | `app-header` | Пункт `Задачи` активен. |

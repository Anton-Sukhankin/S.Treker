# Список документов: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает раздел `Поиск`.
2. Интерфейс показывает таблицу документов в правой части рабочей области поиска.
3. Пользователь вводит значение в фильтрах, выбирает тип документа, выбирает пакет, переключает доступность или меняет страницу.
4. Таблица показывает строки документов, которые соответствуют текущим условиям выдачи и текущей странице.
5. Пользователь выбирает строку документа или открывает меню строки.
6. Интерфейс показывает выбранное состояние строки или действие одного документа.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Выбор пункта `Поиск` в верхней навигации | Активен раздел `Задачи` | Под хедером видна рабочая область поиска; таблица документов показывает первую страницу выдачи. |
| 2 | Ввод текста в поле полнотекстового поиска | Таблица показывает исходную выдачу | Таблица показывает документы, у которых номер или наименование содержит введенный текст; счетчик результатов получает число найденных документов. |
| 3 | Выбор типа документа в левой панели поиска | Таблица показывает выдачу без выбранного типа или с другим набором типов | Таблица показывает документы выбранных типов; выбранный тип виден как тег в левой панели. |
| 4 | Выбор пакета в дереве поиска | Таблица показывает выдачу без выбранного пакета или с другим пакетом | Таблица показывает документы выбранного пакета; выбранный пакет виден как тег в левой панели. |
| 5 | Переключение страницы пагинации | В выдаче больше одной страницы | Таблица заменяет строки на документы выбранной страницы. |
| 6 | Выбор чекбокса строки доступного документа | Строка не выбрана | Строка получает выбранное состояние; плавающая панель действий показывает счетчик выбранных документов. |
| 7 | Открытие меню строки доступного документа | Меню строки закрыто | Под кнопкой меню строки виден список действий одного документа. |

## 3. Вторичные механики

### Выбор всех видимых строк текущей страницы

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Выбор чекбокса в заголовке таблицы | На текущей странице есть доступные невыбранные документы | Все доступные строки текущей страницы получают выбранное состояние; плавающая панель показывает количество выбранных документов. |
| Снятие выбора чекбокса в заголовке таблицы | Все доступные строки текущей страницы выбраны | Все доступные строки текущей страницы получают невыбранное состояние; если выбранных документов не осталось, плавающая панель скрыта. |
| Выбор части строк текущей страницы | На странице выбрана часть доступных строк | Чекбокс в заголовке таблицы показывает промежуточное состояние частичного выбора. |

### Недоступный документ

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Попытка выбрать недоступную строку | Документ недоступен пользователю | Строка не получает выбранное состояние; чекбокс и меню строки остаются недоступными. |

### Меню строки

| Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---|---|---|
| Клик по кнопке меню строки | Меню закрыто | Меню строки открыто; остальные открытые меню строк закрыты. |
| Клик по пункту `Связи документа` | Меню строки открыто | Открывается дровер связей документа; меню строки закрыто. |
| Клик по пункту пометки на удаление | Меню строки открыто | Строка получает или теряет индикатор пометки на удаление. |

## 4. Короткие внешние результаты

| Действие в текущем компоненте | Компонент-получатель | Видимый результат |
|---|---|---|
| Выбор минимум одного доступного документа | Плавающая панель действий с документами | Панель видна; счетчик панели показывает количество выбранных документов. |
| Открытие пункта `Связи документа` в меню строки | Дровер связей документа | Дровер показывает связанные документы выбранной строки. |
| Изменение фильтров или поиска | Счетчик результатов | Счетчик показывает количество документов в итоговой выдаче до пагинации. |

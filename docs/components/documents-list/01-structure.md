# Список документов: структура

## 1. Расположение

| Условие | Область интерфейса | Видимый результат |
|---|---|---|
| Активен раздел `Поиск` | Правая часть рабочей области поиска документов, справа от левой панели фильтров | Видна таблица документов с заголовком результатов, действиями над выдачей и пагинацией. |
| Активен раздел `Задачи` | Рабочая область под хедером S-Tracker | Список документов скрыт вместе с рабочей областью поиска. |

## 2. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Таблица документов | Часть компонента | Содержит заголовок колонок, строки документов, чекбоксы выбора, индикаторы документа, меню строки и пустое состояние. |
| Заголовок результатов поиска | Соседняя зона текущей рабочей области | Показывает название выдачи, счетчик найденных документов и действия над поиском; не является частью таблицы документов. |
| Левая панель поиска | Внешнее условие | Значения фильтров задают набор документов, который показывает таблица. |
| Пагинация документов | Соседняя зона | Переключает страницу набора документов; таблица показывает строки текущей страницы. |
| Плавающая панель действий с документами | Внешний получатель результата | При выборе минимум одного доступного документа получает выбранный набор и показывает счетчик выбранных документов. |
| Дровер связей документа | Внешний получатель результата | Открывается из меню строки или массового действия и показывает связанные документы. |
| Настройки колонок документов | Внешнее условие | Меняют состав и порядок видимых колонок таблицы. |

## 4. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Состав | Что не входит |
|---|---|---|---|---|---|
| Основная область результатов | Правая часть рабочей области поиска | Левая панель фильтров слева; хедер S-Tracker сверху | Активен раздел `Поиск` | Заголовок результатов, действия над выдачей, таблица документов, пагинация | Рабочая область задач S-Tracker. |
| Таблица документов | Под заголовком результатов и действиями над выдачей | Пагинация расположена ниже таблицы | Есть рабочая область поиска | Заголовок колонок, строки документов, меню строки, чекбоксы выбора | Фильтры, шаблоны поиска, настройки колонок, дровер связей. |
| Заголовок таблицы | Верхняя строка таблицы | Строки документов ниже | Таблица видна | Чекбокс выбора всех видимых строк текущей страницы; заголовки видимых колонок; пустая ячейка меню строки | Плавающая панель действий. |
| Строка документа | В теле таблицы, под заголовком колонок | Соседние строки выше и ниже | Документ входит в текущую страницу выдачи | Чекбокс выбора, значения видимых колонок, индикаторы документа, меню действий строки | Содержимое дровера связей и модальных окон. |
| Пустое состояние | В теле таблицы вместо строк документов | Заголовок колонок остается выше | Текущая выдача не содержит документов | Одна строка с текстом пустого результата | Чекбоксы строк, меню строки, индикаторы документов. |

## 5. Каркас строки документа

| Зона строки | Положение внутри строки | Состав зоны |
|---|---|---|
| Выбор строки | Первая ячейка строки | Чекбокс выбора документа. |
| Основные значения | После ячейки выбора, в порядке видимых колонок | Дата документа, номер, наименование, дата изменения, тип и добавленные атрибуты. |
| Ячейка наименования | В колонке `Наименование` | Текст наименования, индикатор пометки на удаление, индикатор пакета, индикатор нескольких маршрутов при наличии нескольких пакетов. |
| Действия строки | Последняя ячейка строки | Кнопка меню строки с действиями одного документа. |

## 6. Элементы и условия показа

| Элемент или зона | Условие показа | Видимое состояние |
|---|---|---|
| Чекбокс строки | Документ доступен пользователю | Чекбокс доступен для выбора. |
| Чекбокс строки | Документ недоступен пользователю | Чекбокс недоступен; строка имеет состояние недоступного документа. |
| Чекбокс в заголовке таблицы | На текущей странице есть доступные документы | Пользователь может выбрать или снять выбор со всех доступных строк текущей страницы. |
| Чекбокс в заголовке таблицы | На текущей странице выбрана часть доступных документов | Чекбокс показывает промежуточное состояние частичного выбора. |
| Индикатор пометки на удаление | Документ имеет состояние `помечен на удаление` | В ячейке наименования виден индикатор пометки. |
| Индикатор нескольких маршрутов | Документ входит в несколько пакетов | В ячейке наименования виден индикатор нескольких маршрутов и доступен список маршрутов. |
| Индикатор пакета | Документ входит в один пакет | В ячейке наименования виден индикатор пакета. |
| Меню строки | Документ доступен пользователю | Кнопка меню доступна. |
| Меню строки | Документ недоступен пользователю | Кнопка меню недоступна. |

## 7. Динамический состав

| Набор элементов | От чего зависит состав | Правило отображения |
|---|---|---|
| Видимый набор строк | Текущие фильтры, поиск, переключатель доступности, настройки связанных документов, сортировка и текущая страница | Таблица показывает только документы текущей страницы итоговой выдачи. |
| Видимые колонки | Примененная конфигурация колонок документов | Каждая строка показывает значения только для видимых колонок; порядок колонок совпадает с примененной конфигурацией. |
| Дополнительные атрибуты | Добавленные в отображение атрибуты документа | Таблица добавляет отдельную колонку для каждого примененного атрибута. |
| Состояние строки | Доступность документа, пометка на удаление, наличие нескольких пакетов | Строка показывает соответствующие индикаторы и доступность действий. |

## 8. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `search-workspace` | Родительская рабочая область | Список документов находится в правой части рабочей области поиска. | `search-workspace/01-structure.md`, `search-workspace/03-data-states-rules.md`. |
| `search-filters` | Внешнее условие | Значения фильтров меняют видимый набор строк таблицы. | `search-filters/03-data-states-rules.md`, `documents-list/03-data-states-rules.md`. |
| Плавающая панель действий с документами | Внешний получатель результата | Выбранный набор документов передается в панель действий. | `document-bulk-actions/01-structure.md`, `document-bulk-actions/03-data-states-rules.md`. |
| Пагинация документов | Соседняя зона | Таблица показывает строки текущей страницы. | `documents-list/03-data-states-rules.md`. |

## 9. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Таблица документов | Table | Показывает строки текущей страницы итоговой выдачи с примененными колонками и состояниями строк. | Заполняется после утверждения DS-карты. |
| Заголовок таблицы | Table header / checkbox | Чекбокс заголовка выбирает или снимает выбор со всех доступных строк текущей страницы. | Заполняется после утверждения DS-карты. |
| Строка документа | Table row | Строка показывает значения документа, доступность выбора, индикаторы и меню строки. | Заполняется после утверждения DS-карты. |
| Пустое состояние | Empty state | При нулевой выдаче тело таблицы содержит одну строку пустого результата. | Заполняется после утверждения DS-карты. |

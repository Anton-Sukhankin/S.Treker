# Список документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Левая панель поиска | Условия поиска и фильтрации документов | Список документов получает итоговую выдачу документов, которые соответствуют всем текущим условиям. |
| Список документов | Видимый набор текущей страницы | Таблица показывает не больше 20 строк текущей страницы итоговой выдачи. |
| Список документов | Выбранные документы | Выбранные строки имеют выбранное состояние; плавающая панель действий получает количество выбранных документов. |
| Список документов | Сортировка таблицы | Таблица показывает строки в порядке выбранной сортировки. |
| Настройки колонок документов | Примененная конфигурация колонок | Таблица показывает колонки, которые входят в примененную конфигурацию. |
| Пагинация документов | Текущая страница | Таблица показывает строки выбранной страницы. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Исходная выдача | Раздел `Поиск` открыт; пользователь не изменял условия поиска | Таблица показывает первую страницу исходного набора документов. | Пользователь вводит значение поиска, выбирает фильтр, переключает доступность, меняет сортировку или страницу. |
| Отфильтрованная выдача | Пользователь изменил минимум одно условие поиска | Таблица показывает документы, которые проходят текущие условия; счетчик результатов показывает число документов до пагинации. | Пользователь сбрасывает условия поиска или меняет условия на другой набор. |
| Пустая выдача | Итоговая выдача не содержит документов | Тело таблицы показывает строку пустого результата; строки документов и чекбоксы строк не видны. | Пользователь меняет условия так, что выдача содержит минимум один документ. |
| Строка выбрана | Пользователь выбрал чекбокс доступной строки или выбрал строку кликом | Строка имеет выбранное состояние; чекбокс строки выбран. | Пользователь снимает выбор строки, сбрасывает выбор или меняет выдачу так, что строка больше не входит в видимый набор. |
| Частичный выбор страницы | На текущей странице выбрана часть доступных строк | Чекбокс в заголовке таблицы показывает промежуточное состояние. | Пользователь выбирает все доступные строки страницы или снимает выбор со всех строк страницы. |
| Документ недоступен | Документ имеет ограничение доступа для пользователя | Строка имеет состояние недоступного документа; чекбокс и меню строки недоступны. | Состояние прекращается только при изменении данных доступности документа. |
| Документ помечен на удаление | Пользователь применил действие пометки на удаление к документу | В ячейке наименования виден индикатор пометки; строка имеет состояние помеченного документа. | Пользователь снимает пометку на удаление. |

## 3. Счетчики, видимость и применимость

| Элемент или значение | Условие | Видимый результат |
|---|---|---|
| Счетчик результатов | Таблица получает итоговую выдачу после поиска, фильтров и переключателей | Счетчик показывает число документов в итоговой выдаче до пагинации. |
| Тело таблицы | Итоговая выдача содержит документы | Тело таблицы показывает строки текущей страницы. |
| Тело таблицы | Итоговая выдача не содержит документов | Тело таблицы показывает пустое состояние. |
| Чекбокс в заголовке таблицы | Все доступные строки текущей страницы выбраны | Чекбокс выбран. |
| Чекбокс в заголовке таблицы | Часть доступных строк текущей страницы выбрана | Чекбокс показывает промежуточное состояние. |
| Чекбокс в заголовке таблицы | Ни одна доступная строка текущей страницы не выбрана | Чекбокс не выбран. |
| Плавающая панель действий | Выбран минимум один доступный документ | Панель видна; счетчик панели показывает количество выбранных документов. |
| Плавающая панель действий | Выбранных документов нет | Панель скрыта. |

## 4. Правила данных

| Данные или значение | Источник для интерфейса | Где используется | Видимый результат |
|---|---|---|---|
| Номер документа | Документ текущей выдачи | Колонка `Номер` | В строке показан номер документа. |
| Наименование документа | Документ текущей выдачи | Колонка `Наименование` | В строке показано наименование документа. |
| Дата документа | Документ текущей выдачи | Колонка `Дата документа` | В строке показана дата документа. |
| Дата изменения | Документ текущей выдачи | Колонка `Изменено` | В строке показана дата последнего изменения. |
| Тип документа | Документ текущей выдачи | Колонка `Тип` и фильтр типа документа | В строке показан тип документа; фильтр типа ограничивает итоговую выдачу. |
| Доступность документа | Документ текущей выдачи | Строка документа и фильтр `Доступные мне` | Недоступный документ не выбирается и не открывает меню строки; при включенном фильтре доступности недоступные документы исключаются из выдачи. |
| Пакеты документа | Документ текущей выдачи | Индикатор пакета и фильтр пакета | Строка показывает пакет или несколько маршрутов; фильтр пакета ограничивает итоговую выдачу выбранной веткой. |
| Связанные документы | Связи документа | Выдача при включенном поиске связанных документов и дровер связей | Таблица может включать документы, связанные с найденными документами; дровер показывает связанные документы выбранного документа. |
| Дополнительные атрибуты | Примененная конфигурация колонок | Дополнительные колонки таблицы | Для каждого добавленного атрибута строка показывает значение документа. |

## 5. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `search-workspace` | Родительская рабочая область | Активен раздел `Поиск` | Список документов виден в правой части рабочей области поиска. | Рабочая область поиска показывает левую панель и основную область результатов. |
| Левая панель поиска | Источник условий выдачи | Пользователь меняет поиск, фильтры, пакет, период, атрибуты или переключатель доступности | Таблица показывает новый итоговый набор документов; текущая страница возвращается к первой странице. | Левая панель сохраняет выбранные значения и теги. |
| Пагинация документов | Источник текущей страницы | Пользователь выбирает страницу или стрелку пагинации | Таблица показывает строки выбранной страницы. | Пагинация показывает выбранный номер страницы. |
| Настройки колонок документов | Источник примененной конфигурации колонок | Пользователь применяет конфигурацию колонок | Таблица показывает только примененные колонки в примененном порядке. | Панель настроек колонок сохраняет примененное состояние. |
| Плавающая панель действий с документами | Получатель выбранного набора | Пользователь выбирает минимум один доступный документ | Выбранные строки имеют выбранное состояние. | Панель видна и показывает количество выбранных документов. |
| Дровер связей документа | Получатель выбранного документа или набора документов | Пользователь открывает `Связи документа` из меню строки или массовое действие сбора связей | Таблица сохраняет текущую выдачу. | Дровер показывает связанные документы. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Левая панель поиска | Список документов не создает и не сохраняет условия поиска; он показывает результат текущих условий. |
| Данные документов | Список документов не создает документы и не меняет исходные значения документа, кроме текущего состояния пометки на удаление в прототипе. |
| Настройки колонок | Список документов не открывает и не сохраняет конфигурацию колонок; он применяет уже установленную конфигурацию к видимым строкам. |
| Плавающая панель действий | Список документов не выполняет массовые действия; он передает выбранный набор как видимое состояние выбора. |
| Дровер связей | Список документов не строит внутреннюю навигацию дровера; он передает выбранный документ или выбранный набор. |
| Пагинация | Список документов не формирует элементы пагинации; он показывает строки страницы, заданной пагинацией. |

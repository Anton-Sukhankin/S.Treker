# Шаблоны поиска документов: структура

## 1. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Вкладка `Сохраненные шаблоны` | Часть компонента | Показывает список сохраненных шаблонов поиска. |
| Карточка шаблона | Часть компонента | Показывает название, дату создания и кнопку удаления. |
| Пустое состояние | Часть компонента | Показывается, если сохраненных шаблонов нет. |
| Форма сохранения шаблона | Часть компонента | Показывается в футере вкладки `Фильтры` после выбора `Сохранить`. |
| Фильтры поиска документов | Источник и получатель состояния | Передают текущие условия для сохранения и получают условия при применении шаблона. |
| Таблица документов | Получатель результата | После применения шаблона показывает выдачу документов по сохраненным условиям. |

## 3. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Слой интерфейса | Состав | Что не входит |
|---|---|---|---|---|---|---|
| Вкладка `Сохраненные шаблоны` | Верхняя часть левой панели поиска рядом с вкладкой `Фильтры` | Список шаблонов ниже | Активен раздел `Поиск` | Inline | Текст вкладки | Верхняя навигация S-Tracker. |
| Список шаблонов | Внутри левой панели под вкладками | Пустое состояние занимает эту же область | Активна вкладка `Сохраненные шаблоны`; есть минимум один шаблон | Inline | Карточки шаблонов | Поля фильтров. |
| Карточка шаблона | В списке шаблонов | Другие карточки выше или ниже | Список шаблонов не пустой | Inline | Название, дата создания, кнопка удаления | Значения фильтров внутри карточки не раскрываются. |
| Пустое состояние | В области списка шаблонов | Вкладки панели выше | Активна вкладка `Сохраненные шаблоны`; шаблонов нет | Inline | Иконка и текст `Отсутствуют сохраненные шаблоны` | Форма сохранения шаблона. |
| Форма сохранения | В футере вкладки `Фильтры` вместо кнопок `Сбросить` / `Сохранить` | Блоки фильтров выше | Пользователь выбирает `Сохранить` во вкладке `Фильтры` | Inline | Поле имени, кнопки `Отмена`, `Сохранить` | Список сохраненных шаблонов. |

## 4. Состав шаблона

| Значение | Источник | Где используется | Видимый результат |
|---|---|---|---|
| Название шаблона | Поле имени в форме сохранения | Карточка шаблона | Показывается как основной текст карточки. |
| Дата создания | Момент сохранения | Карточка шаблона | Показывается строкой `Создано: <дата>`. |
| Значения фильтров | Текущее состояние фильтров поиска | Применение шаблона | Вкладка `Фильтры` получает сохраненные значения. |
| Атрибутные фильтры | Добавленные дополнительные атрибуты | Применение шаблона | Блок дополнительных атрибутов восстанавливает сохраненный состав и значения. |

## 5. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `search-filters` | Источник и получатель состояния | Сохранение берет текущие условия; применение записывает условия обратно в фильтры. | `search-filter-templates/03-data-states-rules.md`, `search-filters/03-data-states-rules.md`. |
| `documents-list` | Получатель результата | После применения шаблона таблица документов показывает пересчитанную выдачу. | `documents-list/03-data-states-rules.md`. |

## 6. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Вкладка `Сохраненные шаблоны` | Tabs | Активная вкладка показывает список сохраненных шаблонов вместо полей фильтров. | Заполняется после утверждения DS-карты. |
| Список шаблонов | List | При наличии сохраненных шаблонов показывает карточки шаблонов. | Заполняется после утверждения DS-карты. |
| Карточка шаблона | Card / list item | Показывает название, дату создания и кнопку удаления шаблона. | Заполняется после утверждения DS-карты. |
| Пустое состояние | Empty state | При отсутствии шаблонов показывает текст пустого состояния. | Заполняется после утверждения DS-карты. |
| Форма сохранения | Inline form | После выбора `Сохранить` во вкладке `Фильтры` показывает поле имени и кнопки `Отмена` / `Сохранить`. | Заполняется после утверждения DS-карты. |

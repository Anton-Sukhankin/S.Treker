# Шаблоны поиска документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Шаблоны поиска документов | Список сохраненных шаблонов | Вкладка `Сохраненные шаблоны` показывает карточки или пустое состояние. |
| Шаблоны поиска документов | Форма сохранения | Футер вкладки `Фильтры` показывает форму вместо кнопок управления. |
| Фильтры поиска документов | Текущие условия фильтров | Шаблон получает эти значения при сохранении. |
| Фильтры поиска документов | Примененные значения шаблона | Поля фильтров получают сохраненные значения после выбора карточки. |
| Таблица документов | Итоговая выдача | После применения шаблона таблица показывает документы по сохраненным условиям. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Список шаблонов пустой | Сохраненных шаблонов нет | Видно пустое состояние `Отсутствуют сохраненные шаблоны`. | Пользователь сохраняет первый шаблон. |
| Есть сохраненные шаблоны | Сохранен минимум один шаблон | Видны карточки шаблонов. | Пользователь удаляет все шаблоны. |
| Форма сохранения открыта | Пользователь выбирает `Сохранить` во вкладке `Фильтры` | В футере видны поле имени, `Отмена`, `Сохранить`; стандартные кнопки футера скрыты. | Пользователь сохраняет шаблон или выбирает `Отмена`. |
| Шаблон применен | Пользователь выбирает карточку шаблона | Вкладка `Фильтры` активна; поля фильтров показывают значения шаблона; таблица пересчитана. | Пользователь меняет фильтры, сбрасывает их или применяет другой шаблон. |

## 3. Состав сохраняемого состояния

| Значение шаблона | Источник | Правило сохранения | Правило применения |
|---|---|---|---|
| Название | Поле имени шаблона | Сохраняется непустой текст поля. | Показывается в карточке шаблона. |
| Дата создания | Момент сохранения | Сохраняется дата создания в пользовательском формате. | Показывается в карточке шаблона. |
| Полнотекстовый поиск | Поле полнотекстового поиска | Сохраняется текущее значение поля. | Значение записывается в поле полнотекстового поиска. |
| Типы документов | Мультивыбор типа документа | Сохраняется набор выбранных типов. | Теги и чекбоксы типов получают сохраненное состояние. |
| Пакеты | Дерево пакетов | Сохраняется набор выбранных пакетов. | Поле пакета показывает сохраненный счетчик; дерево получает сохраненные выбранные ветки. |
| Период документа | Поле периода | Сохраняется текущее значение поля. | Значение записывается в поле периода. |
| `Доступные мне` | Переключатель доступности | Сохраняется состояние включено или выключено. | Переключатель получает сохраненное состояние. |
| `Искать связанные` | Переключатель связанных документов | Сохраняется состояние включено или выключено. | Переключатель получает сохраненное состояние. |
| Дополнительные атрибуты | Блок атрибутных фильтров | Сохраняется состав блоков и их значения. | Блоки атрибутов создаются заново с сохраненными значениями. |

## 4. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `search-filters` | Источник состояния | Пользователь сохраняет шаблон | Шаблон добавляется в список. | Фильтры сохраняют текущие видимые значения. |
| `search-filters` | Получатель состояния | Пользователь применяет шаблон | Список шаблонов сохраняется без изменений. | Поля фильтров получают сохраненные значения. |
| `documents-list` | Получатель результата | Шаблон применен | Текущий шаблон остается сохраненным. | Таблица показывает выдачу по условиям шаблона. |

## 5. Ограничения ответственности

| Область | Правило |
|---|---|
| Фильтры поиска документов | Шаблоны не вычисляют выдачу документов; они только записывают значения в фильтры. |
| Таблица документов | Шаблоны не строят строки таблицы и не меняют пагинацию напрямую. |
| Настройки колонок | Шаблоны поиска не являются пресетами колонок и не меняют состав колонок. |
| Данные документов | Шаблоны не меняют документы, связи, доступность и пометки на удаление. |

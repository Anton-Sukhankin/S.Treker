# Фильтры поиска документов: поведение

## 1. Основной пользовательский путь

| Шаг | Действие пользователя | Начальное состояние | Реакция интерфейса | Итоговое состояние |
|---|---|---|---|---|
| 1 | Пользователь открывает раздел `Поиск` | Активен любой раздел S-Tracker | Рабочая область поиска становится видимой; вкладка `Фильтры` активна. | Таблица документов показывает исходную выдачу. |
| 2 | Пользователь вводит текст в полнотекстовое поле | Поле доступно | Таблица документов показывает строки, соответствующие введенному тексту. | Счетчик результатов и строки таблицы соответствуют введенному тексту. |
| 3 | Пользователь открывает тип документа | Мультивыбор закрыт | Выпадающий список типов становится видимым. | Пользователь видит чекбоксы типов документов. |
| 4 | Пользователь выбирает тип документа | Список типов открыт | Первые два выбранных типа видны отдельными тегами; количество остальных показано тегом `+ N`; таблица показывает документы выбранных типов. | Выдача содержит документы выбранных типов. |
| 5 | Пользователь открывает дерево пакетов | Дерево закрыто | Выпадающее дерево пакетов становится видимым. | Пользователь видит иерархию пакетов. |
| 6 | Пользователь выбирает пакет | Дерево пакетов открыто | Выбранная ветка и ее дочерние пакеты получают выбранное состояние; в поле дерева виден счетчик выбранных узлов. | Таблица показывает документы выбранной ветки; переключатель `Искать связанные` виден. Если выбраны все доступные пакеты, таблица показывает исходный набор без ограничения по пакету. |
| 7 | Пользователь выбирает `Искать связанные` | Выбран минимум один пакет | Таблица добавляет связанные документы к выдаче выбранной ветки, если такие документы есть. | Связанные документы могут появиться в выдаче как дополнительные строки. |
| 8 | Пользователь открывает поле периода документа и выбирает дату | Режим диапазона выключен | Календарь становится видимым; выбранный день получает сплошную заливку; дата записывается в поле. | Таблица показывает документы выбранной даты. |
| 9 | Пользователь включает `Диапазон дат` и выбирает две даты | Календарь открыт; переключатель диапазона включен | Первая и вторая даты получают сплошную заливку; дни между ними получают фон диапазона; обе даты записываются в поле. | Таблица показывает документы от первой до второй даты включительно. |
| 10 | Пользователь добавляет атрибутный фильтр | Меню атрибутов содержит доступный атрибут | В блоке дополнительных атрибутов виден новый фильтр. | После ввода или выбора значения таблица показывает документы, соответствующие этому атрибуту. |
| 11 | Пользователь выбирает `Сбросить` | В фильтрах есть выбранные значения | Значения полей, чекбоксов, тегов и переключателей очищаются. | Таблица возвращается к исходной выдаче; добавленные атрибутные блоки остаются без значений. |

## 2. Переключатель `Доступные мне`

| Действие пользователя | Начальное состояние | Реакция интерфейса | Итоговое состояние |
|---|---|---|---|
| Включение `Доступные мне` | Переключатель выключен | Таблица документов показывает только доступные пользователю документы. | В выдаче остаются документы, доступные пользователю. |
| Выключение `Доступные мне` | Переключатель включен | Таблица документов показывает документы без ограничения по доступности. | В выдачу возвращаются документы без ограничения по доступности. |

## 3. Удаление и очистка выбранных значений

| Действие пользователя | Начальное состояние | Реакция интерфейса | Итоговое состояние |
|---|---|---|---|
| Закрытие тега типа документа | В поле типа виден выбранный тег | Тег удаляется; чекбокс типа снимается; таблица показывает выдачу без этого условия типа. | Тип документа больше не участвует в условиях выдачи. |
| Наведение на тег `+ N` | Выбрано больше двух типов документов | Под тегом становится виден список типов сверх первых двух. | Пользователь видит скрытые выбранные значения и кнопки их удаления. |
| Удаление типа из списка `+ N` | Список скрытых типов виден | Значение удаляется из списка; соответствующий чекбокс снимается; число `N` уменьшается. | Удаленный тип больше не участвует в условиях выдачи. |
| Нажатие крестика в теге `+ N` | Выбрано больше двух типов документов | Все типы сверх первых двух удаляются; соответствующие чекбоксы снимаются. | В поле остаются первые два тега; тег `+ N` скрыт. |
| Закрытие счетчика пакетов | В поле пакета виден счетчик `Выбрано: N` | Выбранные пакеты очищаются; дерево перерисовывается. | Переключатель `Искать связанные` скрыт и выключен. |
| Нажатие кнопки очистки периода | В поле периода записана дата или диапазон; справа видна кнопка с крестиком | Значение поля и выбранные состояния календаря очищаются; таблица пересчитывается без условия периода. | Кнопка с крестиком скрыта; остальные условия поиска сохраняются. |
| Удаление атрибутного фильтра | Атрибутный блок добавлен | Блок удаляется из списка дополнительных атрибутов. | Этот атрибут больше не участвует в условиях выдачи. |

## 4. Пустой результат

| Условие | Реакция интерфейса | Итоговое состояние |
|---|---|---|
| Совокупность условий не возвращает документы | Таблица документов показывает пустое состояние. | Счетчик результатов показывает `0`; строки документов не видны. |

# Фильтры поиска документов: структура

## 1. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Левая панель фильтров поиска документов | Часть компонента | Показывает поля и переключатели, которые формируют условия выдачи документов. |
| Полнотекстовый поиск | Часть компонента | Принимает текст для поиска по документам. |
| Мультивыбор типа документа | Часть компонента | Показывает выбранные типы документов и выпадающий список типов. |
| Дерево пакетов | Часть компонента | Показывает иерархию пакетов документов и выбранные ветки. |
| Переключатель `Искать связанные` | Часть компонента | Видим после выбора минимум одного пакета. |
| Поле периода документа | Часть компонента | Открывает календарь выбора даты или диапазона. |
| Дополнительные атрибуты | Часть компонента | Показывают добавленные пользователем фильтры по атрибутам документа. |
| Кнопка `Сбросить` | Часть компонента | Сбрасывает значения фильтров без удаления добавленных атрибутных блоков. |
| Кнопка `Сохранить` | Связь с шаблонами | Открывает форму сохранения текущих условий как шаблона. |
| Таблица документов | Получатель результата | Показывает итоговую выдачу после изменения условий поиска. |
| Сохраненные шаблоны поиска | Соседняя вкладка панели | Применяют сохраненный набор условий к текущему компоненту. |

## 4. Состав фильтров

| Элемент | Положение | Условие показа | Видимое состояние |
|---|---|---|---|
| Полнотекстовое поле | Блок полнотекстового поиска | Вкладка `Фильтры` активна | Показывает введенный текст или placeholder. |
| Теги типа документа | В поле типа документа | Выбран минимум один тип | Показывают первые два выбранных типа. Если выбрано больше двух типов, следующий тег показывает `+ N` и кнопку удаления всех скрытых значений. |
| Список скрытых типов | Под тегом `+ N` | Пользователь наводит указатель на тег `+ N` или переводит фокус на его элементы | Показывает выбранные типы сверх первых двух; у каждого значения есть кнопка удаления. |
| Выпадающий список типов | Под полем типа документа | Пользователь открывает поле типа документа | Показывает типы документов с чекбоксами. |
| Счетчик выбранных пакетов | В поле дерева пакетов | Выбран минимум один пакет или дочерняя ветка | Показывает `Выбрано: N`. |
| Переключатель `Искать связанные` | Под деревом пакетов | Выбран минимум один пакет | Переключатель виден. |
| Меню атрибутов | Под кнопкой `Добавить фильтр` | Пользователь открывает меню добавления фильтра | Показывает доступные атрибуты, которые еще не добавлены. |
| Добавленный атрибутный фильтр | В блоке дополнительных атрибутов | Пользователь выбрал атрибут в меню | Показывает заголовок атрибута, поле значения и иконку удаления блока. |

## 5. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `documents-list` | Получатель результата | Изменение условий фильтрации меняет видимый набор строк таблицы документов. | `search-filters/03-data-states-rules.md`, `documents-list/03-data-states-rules.md`. |
| `search-filter-templates` | Соседняя зона панели | Кнопка `Сохранить` открывает форму сохранения текущих условий. | `search-filter-templates/02-behavior.md`, `search-filter-templates/03-data-states-rules.md`. |
| `document-relations-drawer` | Не является владельцем фильтра | Переключатель `Искать связанные` добавляет связанные документы в выдачу, но не открывает дровер. | `search-filters/03-data-states-rules.md`. |

## 6. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Вкладки панели | Tabs | Активная вкладка определяет видимость фильтров или сохраненных шаблонов. | Заполняется после утверждения DS-карты. |
| Полнотекстовое поле | Input | Введенный текст становится условием выдачи документов. | Заполняется после утверждения DS-карты. |
| Поле типа документа | MultiSelect | Выбранные типы документов отображаются тегами и ограничивают выдачу. | Заполняется после утверждения DS-карты. |
| Поле дерева пакетов | TreeSelect | Выбранные ветки пакетов задают набор документов и показывают счетчик выбора. | Заполняется после утверждения DS-карты. |
| Поле периода | Date input / calendar | Выбранная дата или диапазон задает условие выдачи документов; после выбора в правой части поля видна кнопка очистки. | Заполняется после утверждения DS-карты. |
| Дополнительный атрибутный фильтр | Dynamic filter control | Добавленный атрибут показывает собственное поле значения и участвует в выдаче документов. | Заполняется после утверждения DS-карты. |
| Кнопки футера | Button group | `Сбросить` очищает значения фильтров; `Сохранить` открывает форму сохранения шаблона. | Заполняется после утверждения DS-карты. |

# Фильтры поиска документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Фильтры поиска документов | Текст полнотекстового поиска | Таблица документов получает выдачу, соответствующую введенному тексту. |
| Фильтры поиска документов | Выбранные типы документов | Поле типа показывает теги; таблица ограничивает выдачу выбранными типами. |
| Фильтры поиска документов | Выбранные пакеты | Поле пакета показывает счетчик; таблица ограничивает выдачу выбранными ветками пакетов. |
| Фильтры поиска документов | Переключатель `Искать связанные` | Таблица добавляет документы, связанные с найденными документами. |
| Фильтры поиска документов | Дата или диапазон дат документа | Поле показывает одну дату либо две границы диапазона; таблица ограничивает выдачу выбранной датой или включительным диапазоном. |
| Фильтры поиска документов | Дополнительные атрибуты | Таблица ограничивает выдачу значениями добавленных атрибутных фильтров. |
| Переключатель `Доступные мне` | Условие доступности | Таблица исключает недоступные пользователю документы. |
| `documents-list` | Итоговая выдача | Показывает строки и счетчик после применения всех условий. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Без условий поиска | Раздел `Поиск` открыт; пользователь не выбрал значения фильтров | Таблица показывает исходную выдачу документов. | Пользователь вводит текст, выбирает фильтр, включает переключатель или применяет шаблон. |
| Выдача по условиям | Активно минимум одно условие поиска | Таблица показывает документы, которые соответствуют всем активным условиям. | Пользователь сбрасывает фильтры или меняет условия. |
| Пустая выдача | Ни один документ не соответствует активным условиям | Таблица показывает пустое состояние; счетчик результатов равен `0`. | Пользователь меняет или сбрасывает условия. |
| Выбраны типы документов | Выбран минимум один тип | Первые два типа показаны отдельными тегами; остальные представлены тегом `+ N`. Hover или фокус на `+ N` показывает список скрытых типов с индивидуальным удалением. | Пользователь снимает все выбранные типы или нажимает `Сбросить`. |
| Выбраны пакеты | Выбран минимум один пакет или дочерняя ветка | Поле пакета показывает счетчик `Выбрано: N`; блок `Искать связанные` виден. | Пользователь очищает выбор пакетов или нажимает `Сбросить`. |
| Выбраны все пакеты | Выбраны все доступные пакеты, содержащие документы | Условие пакета не сокращает выдачу; таблица показывает документы всех пакетов с учетом остальных активных фильтров. | Пользователь снимает выбор минимум с одного пакета или очищает выбор пакетов. |
| Выбрана одна дата | Режим диапазона выключен; пользователь выбирает день | Выбранный день получает сплошную заливку; поле показывает одну дату. Текущая дата, если она видна в календаре, обозначена обводкой. | Пользователь выбирает другой день, включает режим диапазона или нажимает `Сбросить`. |
| Выбран диапазон дат | Режим диапазона включен; пользователь выбирает начало и конец | Обе границы получают сплошную заливку; промежуточные дни получают фон диапазона; поле показывает обе даты. | Пользователь начинает новый диапазон, выключает режим диапазона или нажимает `Сбросить`. |
| Добавлены атрибутные фильтры | Пользователь выбрал атрибут в меню `Добавить фильтр` | Атрибутный блок виден в блоке дополнительных атрибутов. | Пользователь удаляет атрибутный блок. |

## 3. Правила отбора

| Условие | Правило выдачи | Видимый результат |
|---|---|---|
| Текст поиска заполнен | Документ остается в выдаче, если его номер, наименование или доступные текстовые поля соответствуют введенному тексту. | Таблица показывает найденные документы; счетчик равен числу найденных документов до пагинации. |
| Выбран минимум один тип документа | Документ остается в выдаче, если его тип входит в выбранный набор. | Строки других типов не видны. |
| Выбран минимум один пакет | Документ остается в выдаче, если его пакет входит в выбранную ветку. | Строки документов вне выбранной ветки не видны. |
| Выбраны все доступные пакеты | Ограничение по пакету считается неактивным; остальные условия поиска продолжают применяться. | Таблица показывает документы всех пакетов, соответствующие остальным фильтрам. |
| Включен `Искать связанные` | К основной выдаче добавляются документы, связанные с найденными документами. | Добавленные связанные строки получают состояние вторичного результата. |
| Выбрана одна дата документа | Документ остается в выдаче, если его дата совпадает с выбранной датой. | Строки других дат не видны. |
| Выбран диапазон дат документа | Документ остается в выдаче, если его дата находится между началом и концом диапазона включительно. | Строки до начала и после конца диапазона не видны. |
| Включен `Доступные мне` | Документ остается в выдаче, если он доступен пользователю. | Недоступные документы не видны в выдаче. |
| Заполнен атрибутный фильтр | Документ остается в выдаче, если значение документа соответствует условию атрибута. | Строки без соответствия атрибуту не видны. |

## 4. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `documents-list` | Получатель выдачи | Пользователь меняет любое условие поиска | Фильтры сохраняют выбранные значения. | Таблица показывает новый итоговый набор; текущая страница возвращается к первой. |
| `search-filter-templates` | Источник сохраненного набора | Пользователь применяет шаблон | Поля фильтров получают значения из шаблона. | Вкладка переключается на `Фильтры`; таблица показывает документы по условиям шаблона. |
| `document-relations-drawer` | Соседний компонент связей | Пользователь включает `Искать связанные` | Дровер не открывается. | Таблица документов может показать связанные документы в выдаче. |

## 5. Ограничения ответственности

| Область | Правило |
|---|---|
| Таблица документов | Фильтры не строят строки таблицы и не владеют пагинацией. |
| Дровер связей | Фильтры не открывают дровер связей и не управляют его вложенной навигацией. |
| Шаблоны поиска | Фильтры не сохраняют шаблон; они передают актуальные значения фильтров в компонент шаблонов. |
| Настройки колонок | Фильтры не меняют состав и порядок колонок таблицы документов. |
| Данные документов | Фильтры не меняют значения документов; они формируют только условия выдачи. |

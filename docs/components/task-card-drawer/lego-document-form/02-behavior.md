# Lego-форма карточки задачи: поведение

Первоначально доступен этап `Потребность`. После явного подтверждения открывается следующий этап; завершённые этапы и первый незавершённый доступны для возврата, будущие этапы disabled.

Изменение поля делает draft несохранённым, но не перестраивает DOM поля и не сбрасывает фокус. Switch НДС перестраивает только форму активного этапа, потому что добавляет или скрывает поле ставки. Изменение подтверждённого этапа снимает подтверждение с него и последующих этапов.

Аккордеон скрывает или показывает сетку и активную форму без изменения draft и навигации по этапам.

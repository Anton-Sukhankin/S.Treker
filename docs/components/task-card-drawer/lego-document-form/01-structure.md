# Lego-форма карточки задачи: структура

Компонент расположен вторым аккордеоном карточки задачи. Header содержит стрелку, title процесса и badge `Шаг N из 5`. Под ним находится адаптивная сетка пяти равных карточек этапов с gap `7 px` и минимальной шириной колонки `200 px`, затем блок активного этапа с padding `16 px`.

Первый этап содержит обязательные общие компоненты `Input` `Предмет договора` и `Select` `Объект строительства (справочник)`. Третий этап содержит сумму, switch НДС, условную ставку НДС, валюту и disabled-поля неизвестных справочников. Второй, четвёртый и пятый этапы показывают source-limited состояния без вымышленных атрибутов.

Карточки этапов и их контейнер не имеют теней и дополнительной серой подложки.

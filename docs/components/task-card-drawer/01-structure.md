# Карточка задачи: структура интерфейса

## Граница компонента

`task-card-drawer` — один правый немодальный drawer поверх раздела `Задачи`. Он создаётся для выбранного `taskId`, не входит в строку или карточку списка, не меняет их компоновку и не создаёт overlay над рабочей областью.

## Пространственный контракт

| Зона | Размер и положение | Состав |
|---|---|---|
| Drawer | Базовая ширина `740 px`, минимум `520 px`, максимум `1100 px`; закреплён справа на всю высоту окна | Header, прокручиваемая контентная область, фиксированный footer |
| Header | Минимальная высота `88 px`, padding `20 px`, белый фон | Иконка задачи `24 px` на серой подложке `48 px`; номер; разделитель `4 px`; title с многоточием; кнопка закрытия |
| Основной режим | Padding `16 px`, вертикальная прокрутка | Аккордеон `О задаче`, аккордеон Lego-формы |
| `О задаче` | Поверхность без тени; header `48 px`; содержимое в сетке из двух колонок | Исполнитель, статус, срок исполнения, описание; кнопки истории и комментариев |
| Режим истории или комментариев | Занимает всю контентную высоту между неизменными header и footer | Кнопка возврата и прокручиваемый список; остальные аккордеоны скрыты |
| Footer | Минимальная высота `64 px`, padding `12 px 20 px`, закреплён снизу | Слева icon-only `Сохранить`, справа primary-действие текущего этапа |

Title находится в одной строке с номером. Между группой title и закрытием остаётся `16 px`; полный title доступен через нативную подсказку. Значения `Исполнитель`, `Срок исполнения` и `Описание` имеют размер `14 px`, насыщенность `500`, line-height `20 px`.

Комментарии не имеют карточного фона, скругления или отдельных промежутков. Каждый элемент имеет вертикальные внутренние отступы `16 px`, не имеет горизонтальных внутренних отступов и отделён нижним border. Имя автора имеет насыщенность `500`.

## Дочерний компонент

Lego-форма описана в `docs/components/task-card-drawer/lego-document-form/` и использует общие `Input`, `Select`, `Button`, `Drawer`, `Modal` и `Toast` из `src/ui/components`.

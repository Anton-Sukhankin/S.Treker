# Список задач: поведение

## Открытие карточки задачи

При клике по наименованию позиции список передаёт её `taskId` в `task-card-drawer`. Режим списка, текущая страница, фильтры и выбранные чекбоксы остаются без изменений. Drawer не создаёт overlay: доступные наименования остаются интерактивными, и выбор другого наименования сразу переключает карточку на соответствующий `taskId`. После закрытия drawer фокус возвращается к последнему наименованию-инициатору.

## 1. Основной пользовательский путь

1. Пользователь открывает прототип.
2. По умолчанию выбран раздел `Все задачи`.
3. По умолчанию активна очередь `К исполнению`.
4. По умолчанию активен карточный вид списка задач.
5. Список задач показывает видимый набор текущей страницы после выбранной области, активной очереди, поисковой строки, примененных фильтров и пагинации.
6. Пользователь видит задачи текущей страницы в карточном виде.
7. Пользователь переключает список в табличный вид.
8. Список показывает тот же видимый набор текущей страницы в таблице.
9. Пользователь выбирает задачи чекбоксами, копирует email автора, меняет страницу или возвращается в карточный вид.

## 2. Первичная загрузка

| Условие | Видимый результат |
|---|---|
| Прототип открыт | В левой навигации выбран раздел `Все задачи`. |
| Прототип открыт | В очередях активен сегмент `К исполнению`. |
| Прототип открыт | В панели инструментов активен сегмент карточного вида. |
| После выбранной области, активной очереди, поиска, примененных фильтров, сортировки и текущей страницы есть задачи | В списке задач видны карточки задач текущей страницы. |
| После выбранной области, активной очереди, поиска, примененных фильтров, сортировки и текущей страницы задач нет | В списке задач видно пустое состояние карточного вида. |

## 3. Переключение карточного и табличного вида

| Действие пользователя | Исходное состояние | Итог в списке задач | Итог в панели инструментов |
|---|---|---|---|
| Выбирает сегмент карточного вида в переключателе вида | Активен табличный вид | Карточный вид видим; табличный вид скрыт; видимый набор текущей страницы не меняется. | Кнопки `Настройка колонок`, `Скачать` и `Печать` скрыты. |
| Выбирает сегмент табличного вида в переключателе вида | Активен карточный вид | Табличный вид видим; карточный вид скрыт; видимый набор текущей страницы не меняется. | Кнопки `Настройка колонок`, `Скачать` и `Печать` видимы. |

Переключение вида не меняет выбранный раздел, активную очередь, поисковую строку, примененные фильтры, отобранный набор до пагинации, текущую страницу и выбранные задачи.

## 4. Выбор очереди

| Действие пользователя | Исходное состояние | Итог в списке задач |
|---|---|---|
| Выбирает другой сегмент очереди | В списке видны задачи прежней активной очереди | Список показывает задачи выбранной очереди внутри текущей области с учетом поисковой строки, примененных параметров фильтрации, сортировки и текущей страницы. |

Состав сегментов, активное состояние, счетчики и красная индикация описаны в компоненте `Очереди`.

## 5. Создание группировки из заголовка таблицы

| Действие пользователя | Исходное состояние | Итог в списке задач | Итог в левой навигации |
|---|---|---|---|
| Нажимает действие группировки в заголовке колонки | Активен табличный вид; выбран `Все задачи` или бизнес-домен; колонка поддерживает группировку | Список остается в табличном виде; видимый набор текущей страницы не меняется. | Под текущим пунктом видна вложенная группировка с названием `По <название атрибута>`. |
| Нажимает действие группировки по тому же атрибуту повторно | В левой навигации уже есть группировка по этому атрибуту | Список остается в текущем состоянии. | Под текущим пунктом остается одна группировка по этому атрибуту с актуальным набором значений. |

Действие группировки не видно в карточном виде, в сгруппированном представлении и в пользовательской группе.

## 6. Изменение области задач

| Действие пользователя в левой навигации | Итог в списке задач |
|---|---|
| Выбирает `Все задачи` | Список показывает задачи всех бизнес-доменов, доступных текущей роли. |
| Выбирает бизнес-домен | Список показывает только задачи выбранного бизнес-домена. |
| Выбирает значение внутри группировки бизнес-домена | Список показывает только задачи выбранного бизнес-домена с выбранным значением группировки. |
| Выбирает пользовательскую группу | Список показывает только задачи, входящие в выбранную пользовательскую группу. |

При смене области задач список сохраняет активную очередь и применяет ее к новой области.

## 7. Поиск и примененные фильтры

| Входящее изменение | Итог в списке задач |
|---|---|
| В поле `Поиск по задачам` введен текст | Список показывает только задачи, которые совпадают с введенным текстом и проходят остальные активные условия. |
| Поле `Поиск по задачам` очищено | Список показывает задачи текущей области и активной очереди без поискового сужения. |
| Параметры панели фильтрации применены | Список показывает только задачи, прошедшие все примененные параметры фильтрации. |
| Активные параметры панели фильтрации сброшены | Список показывает задачи текущей области и активной очереди без фильтрационного сужения. |

Если после поиска или примененных фильтров в текущей странице нет задач, список показывает пустое состояние текущего режима отображения.

## 8. Выбор задач в списке

| Действие пользователя | Исходное состояние | Итог в списке задач | Итог в `Массовых действиях` |
|---|---|---|---|
| Выбирает чекбокс карточки | Задача не входит в набор выбранных задач | Чекбокс карточки активен; карточка получает выбранное состояние. | Плавающая панель видна; счетчик показывает количество выбранных задач. |
| Снимает выбор чекбокса карточки | Задача входит в набор выбранных задач | Чекбокс карточки пуст; карточка теряет выбранное состояние. | Если выбранных задач не осталось, плавающая панель скрыта; иначе счетчик уменьшается. |
| Выбирает чекбокс строки таблицы | Задача не входит в набор выбранных задач | Чекбокс строки активен; строка получает выбранное состояние. | Плавающая панель видна; счетчик показывает количество выбранных задач. |
| Снимает выбор чекбокса строки таблицы | Задача входит в набор выбранных задач | Чекбокс строки пуст; строка теряет выбранное состояние. | Если выбранных задач не осталось, плавающая панель скрыта; иначе счетчик уменьшается. |

Одна и та же задача сохраняет выбранное состояние при переключении карточного и табличного вида.

## 9. Выбор всех видимых строк в таблице

Выбор всех через заголовок доступен только в табличном виде.

| Действие пользователя | Исходное состояние видимых строк текущей страницы | Итог в строках таблицы | Итог чекбокса в заголовке |
|---|---|---|---|
| Нажимает пустой чекбокс в заголовке | Не выбрана ни одна видимая строка | Все видимые строки текущей страницы становятся выбранными. | Чекбокс в заголовке активен. |
| Нажимает чекбокс в заголовке | Все видимые строки текущей страницы выбраны | Со всех видимых строк текущей страницы снимается выбор. | Чекбокс в заголовке пуст. |
| Снимает выбор с одной строки после выбора всех | Выбраны все видимые строки текущей страницы | Выбранными остаются только строки, чекбоксы которых активны. | Чекбокс в заголовке получает промежуточное состояние выбора. |

Точный вид промежуточного состояния чекбокса в заголовке описан в `03-data-states-rules.md`.

## 10. Копирование email автора

| Действие или результат | Состояние интерфейса |
|---|---|
| Пользователь нажимает email автора в карточке или таблице | Выбор карточки или строки не меняется. |
| Копирование email успешно | Интерфейс показывает toast `Адрес скопирован`. |
| Копирование email не удалось | Интерфейс показывает toast `Не удалось скопировать адрес`. |

## 11. Пагинация

| Действие или входящее изменение | Итог в списке задач |
|---|---|
| Пользователь нажимает номер страницы в пагинации | Список показывает карточки или строки выбранной страницы. |
| Пользователь нажимает кнопку навигации со стрелкой вперед в пагинации | Список показывает карточки или строки следующей страницы. |
| Пользователь нажимает кнопку навигации со стрелкой назад в пагинации | Список показывает карточки или строки предыдущей страницы. |
| Изменяется активная очередь, область задач или примененные фильтры | Список пересобирает видимый набор; текущая страница возвращается к первой. |

Детальные состояния стрелок, номеров страниц, скрытия пагинации и разрывов `...` описывает компонент `Пагинация`.

## 12. Горизонтальный скролл таблицы

| Действие или состояние | Итог в таблице |
|---|---|
| Пользователь скроллит таблицу вправо | Колонки `чекбокс выбора`, `№`, `Наименование` остаются закрепленными слева. |
| Таблица имеет горизонтальный сдвиг больше 0 | У закрепленной области видимо правое визуальное отделение. |
| Пользователь возвращает скролл к началу | Правое визуальное отделение закрепленной области скрыто. |

## 13. Пустой результат

| Условие | Итог в списке задач |
|---|---|
| После области задач, активной очереди, поиска, примененных фильтров, сортировки и текущей страницы нет задач | Вместо карточек или строк показано пустое состояние текущего режима отображения. |
| После изменения области задач, активной очереди, поиска или примененных фильтров появились задачи | Пустое состояние скрыто; список показывает карточки или строки текущей страницы. |

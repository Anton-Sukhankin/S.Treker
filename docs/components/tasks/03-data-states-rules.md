# Список задач: данные, состояния и правила

## Контракт с карточкой задачи

Наименование строки или карточки содержит `.js-open-task-card[data-task-id]`. Этот `taskId` совпадает с `id` строки основной модели. Открытие drawer не добавляет `taskId` в набор массового выбора и не меняет состояние очередей, фильтров, колонок, пагинации или режима отображения.

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Список задач | Отобранный набор до пагинации, видимый набор текущей страницы, визуальные состояния задач, пустое состояние | Список показывает карточки, строки таблицы или пустое состояние после области, очереди, поиска, фильтров, сортировки и пагинации. |
| Панель инструментов | Поисковая строка и режим отображения | Список получает поисковую строку и выбранный режим; карточный или табличный вид становится видимым внутри списка. |
| Левая навигация | Выбранная область задач и созданные группировки | Список получает область задач: `Все задачи`, бизнес-домен, пользовательскую группу или значение группировки. |
| Очереди | Активный этап согласования | Список получает активную очередь для обычного списка задач. |
| Панель фильтрации | Примененные параметры фильтрации | Список получает примененные параметры и исключает задачи, которые их не проходят. |
| Настройки колонок | Примененный состав и порядок динамических колонок | Табличный вид показывает только примененные динамические колонки справа от закрепленных колонок. |
| Пагинация | Текущая страница | Список показывает только задачи текущей страницы из отобранного набора. |
| Массовые действия | Набор выбранных задач | Чекбоксы списка показывают выбранное состояние задач из набора массовых действий. |

## 2. Входные значения и состояния списка

| Состояние или значение | Значение | Видимый результат |
|---|---|---|
| Выбранная область задач | `Все задачи`, бизнес-домен, пользовательская группа или сгруппированное значение | В наборе остаются только задачи выбранной области. |
| Активная очередь | Один сегмент в компоненте `Очереди` | В наборе остаются только задачи активного этапа согласования. |
| Поисковая строка | Пустая или заполненная строка | Заполненная строка оставляет в наборе только задачи, совпадающие с введенным текстом. |
| Примененные параметры фильтрации | Пустые или активные параметры | Активные параметры исключают задачи, которые не проходят условия фильтрации. |
| Режим отображения | Карточный или табличный | Один и тот же видимый набор текущей страницы показан карточками или строками таблицы. |
| Отобранный набор до пагинации | Задачи после области, очереди, поиска, примененных фильтров и сортировки | Набор передается пагинации для расчета страниц. |
| Текущая страница | Одна страница отобранного набора | В списке видны только задачи этой страницы. |
| Примененные настройки колонок | Набор динамических колонок для табличного вида | Меняются только динамические колонки таблицы; карточный вид не меняется. |
| Выбранные задачи | Набор отмеченных задач | Чекбоксы выбранных задач активны; плавающая панель массовых действий видима при непустом наборе. |

## 3. Правило сборки набора задач

| Порядок | Правило | Результат |
|---:|---|---|
| 1 | Берутся задачи активной очереди | В наборе остаются задачи одного этапа согласования. |
| 2 | Применяется выбранная область задач | В наборе остаются задачи выбранного домена, группы, значения или всех доступных доменов. |
| 3 | Применяются поисковая строка и активные параметры фильтрации | В наборе остаются задачи, прошедшие поиск и фильтры. |
| 4 | Применяется сортировка | Формируется отобранный набор до пагинации: новые задачи идут выше обычных; просроченные идут выше обычных после новых. |
| 5 | Применяется пагинация | Формируется видимый набор текущей страницы. |
| 6 | Применяется режим отображения | Видимый набор текущей страницы показан карточками или строками таблицы. |

Если после шага 5 видимый набор текущей страницы пуст, список показывает пустое состояние текущего режима отображения.

## 4. Правила выбранной области задач

| Выбранная область | Задача остается в наборе |
|---|---|
| `Все задачи` | Бизнес-домен задачи доступен текущей роли. |
| Конкретный бизнес-домен | Бизнес-домен задачи совпадает с выбранным доменом. |
| Сгруппированное значение | Задача принадлежит выбранному домену и имеет выбранное значение в атрибуте группировки. |
| `Без значения` внутри группировки | У задачи нет значения в атрибуте группировки. |
| Пользовательская группа | Задача входит в выбранную пользовательскую группу. |

## 5. Правила колонок таблицы

| Условие | Видимый результат в таблице |
|---|---|
| Табличный вид активен | Закрепленные колонки чекбокса, `№` и `Наименование` всегда видимы слева и не отключаются настройками колонок. |
| Выбран раздел `Все задачи` | Динамическая область использует объединенный набор колонок доступных бизнес-доменов. |
| Выбран бизнес-домен | Динамическая область использует колонки выбранного бизнес-домена. |
| Выбрана пользовательская группа, не привязанная к одному бизнес-домену | Динамическая область использует объединенный набор колонок. |
| Колонка скрыта в настройках колонок и настройки применены | Колонка не видна в динамической области таблицы. |
| Атрибут из библиотеки добавлен в настройках колонок и настройки применены | Колонка атрибута видна в динамической области таблицы. |

Настройки колонок не влияют на карточный вид.

## 6. Правила значений задачи

| Значение | Правило отображения |
|---|---|
| Номер | Показан как номер задачи. |
| Наименование | Показано с иконкой задачи; длинный текст обрезается многоточием. |
| Статус | Показан как цветной тег с белым текстом. |
| Автор | Показан как аватар, имя и email. |
| Email автора | Показан под именем автора. |
| Дата | Показана с иконкой календаря. |
| Значение отсутствует | В ячейке таблицы показан пустой маркер `–`. |
| Атрибут неприменим к домену задачи | В объединенной таблице показан пустой маркер `–`. |

## 7. Статусы задачи

Статус задачи является атрибутом задачи. Этапы над списком задач не являются статусами задачи.

| Статус | Цвет тега |
|---|---|
| Новая | Циан |
| Назначена | Фиолетовый |
| В работе | Синий |
| Назначение снято | Серый |
| Завершена | Зеленый |
| Отменена | Темно-серый |
| Отклонена | Красный |

Каждый статус отображается в виде контрастного цветного тега с белым текстом.

## 8. Визуальные состояния задачи

| Состояние задачи | Условие входа | Карточный вид | Табличный вид | Условие выхода |
|---|---|---|---|---|
| Обычная | У задачи нет признака новой задачи и нет признака просрочки | Карточка без зеленой или красной левой индикации | Строка без зеленой или красной левой индикации | Задача получает признак новой задачи или просрочки. |
| Новая | У задачи есть признак новой задачи | Зеленоватая подложка и зеленая левая индикация | Зеленоватые ячейки и зеленая левая индикация в первой ячейке | У задачи снят признак новой задачи. |
| Просроченная | У задачи есть признак просрочки | Розоватая подложка, красная левая индикация, красная дата просрочки | Розоватые ячейки, красная левая индикация в первой ячейке, красная дата просрочки | У задачи снят признак просрочки. |
| Выбранная | Задача входит в набор выбранных задач | Чекбокс активен; карточка сохраняет выбранное состояние | Чекбокс активен; строка сохраняет выбранное состояние | Задача удалена из набора выбранных задач. |

У просроченной задачи красным выделяется значение даты, которая считается сроком или контрольной датой. Красная обводка у тега статуса не используется.

## 9. Правило даты просрочки

| Условие | Дата, которая получает состояние просрочки |
|---|---|
| Задача относится к бизнес-домену `Строительные договоры` | Дата создания. |
| Задача относится к бизнес-домену `Закупки ТМЦ` | Срок. |
| Задача относится к бизнес-домену `Поручения СД` | Дата проверки. |
| Задача относится к бизнес-домену `Поручения СД`, список открыт в объединенном режиме и в таблице видна колонка `Система` | Дата создания. |

В карточном виде для просроченной задачи показана одна дата: срок для `Закупки ТМЦ`, дата проверки для `Поручения СД`, иначе дата создания.

## 10. Правила выбора задач

| Состояние выбора | Видимый результат |
|---|---|
| Набор выбранных задач пуст | Все видимые чекбоксы задач пустые; плавающая панель массовых действий скрыта. |
| Выбрана одна задача | Чекбокс этой задачи активен; плавающая панель массовых действий видима. |
| Выбрано несколько задач | Чекбоксы выбранных задач активны; счетчик плавающей панели показывает количество выбранных задач. |
| Выбраны все видимые строки таблицы | Чекбокс в заголовке таблицы активен. |
| Выбрана часть видимых строк таблицы | Чекбокс в заголовке таблицы находится в промежуточном состоянии выбора и показывает внутренний синий индикатор частичного выбора. |

Чекбокс в заголовке таблицы получает состояние только по видимым строкам текущей страницы.
При переключении карточного и табличного вида набор выбранных задач не меняется; чекбоксы тех же задач активны в новом режиме.

## 11. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в списке задач | Результат в связанном компоненте |
|---|---|---|---|---|
| Панель инструментов | Источник поисковой строки | Пользователь вводит текст в поле `Поиск по задачам` или очищает поле | Список показывает задачи, которые проходят новое поисковое условие. | Поле `Поиск по задачам` показывает введенный текст или пустое значение. |
| Панель инструментов | Источник режима отображения | Пользователь выбирает сегмент карточного или табличного вида | В списке виден выбранный режим; второй режим скрыт. | Выбранный сегмент переключателя получает активное состояние. |
| Левая навигация | Источник выбранной области задач | Пользователь выбирает область задач | Список показывает задачи выбранной области. | Активный пункт левой навигации получает выбранное состояние. |
| Очереди | Источник активного этапа согласования | Пользователь выбирает сегмент очереди | Список показывает задачи активной очереди. | Выбранный сегмент получает активное состояние. |
| Панель фильтрации | Источник примененных параметров | Пользователь нажал `Применить` или быстро сбросил фильтры | Список показывает задачи, которые проходят примененные параметры. | Панель фильтрации показывает примененное или сброшенное состояние параметров. |
| Пагинация | Получатель отобранного набора до пагинации и источник текущей страницы | Отобранный набор до пагинации собран или пользователь выбирает страницу | Список показывает видимый набор текущей страницы. | Пагинация показывает страницы отобранного набора и активную страницу. |
| Настройки колонок | Источник примененного набора колонок | Пользователь нажал `Применить` в настройках колонок | Табличный вид получает примененный набор динамических колонок. | Примененный набор становится текущим состоянием настроек колонок. |
| Левая навигация | Получатель результата создания группировки | Пользователь нажал действие группировки в заголовке колонки таблицы | Набор видимых задач, режим отображения и текущая страница не изменяются. | Левая навигация показывает вложенную группировку под активным пунктом `Все задачи` или бизнес-доменом. |
| Левая навигация | Источник выбранного значения группировки | Пользователь выбирает значение группировки в левой навигации | Список показывает только задачи выбранного значения. | Значение группировки получает активное состояние. |
| Массовые действия | Получатель набора выбранных задач | Пользователь выбирает чекбокс задачи или чекбокс заголовка таблицы | Чекбоксы выбранных задач активны. | Плавающая панель массовых действий видна, если выбран минимум один чекбокс. |

## 12. Ограничения ответственности

| Область | Правило |
|---|---|
| Исходные данные задач | Список задач не изменяет значения задач. |
| Поисковая строка | Список задач не изменяет значение поля `Поиск по задачам`. |
| Режим отображения | Список задач не меняет режим без выбранного сегмента в панели инструментов. |
| Параметры фильтрации | Список задач не изменяет примененные параметры фильтрации. |
| Бизнес-домены | Список задач не изменяет состав бизнес-доменов. |
| Очереди | Список задач не изменяет значение очереди у задачи. |
| Текущая страница | Список задач не показывает элементы управления страницами; пагинация владеет текущей страницей. |
| Настройки колонок | Список задач не создает, не сохраняет и не удаляет наборы колонок. |
| Пресеты и библиотека атрибутов | Список задач не создает, не сохраняет и не удаляет пресеты или библиотечные атрибуты. |
| Вложенная группировка | Список задач содержит действие группировки в заголовке таблицы, но созданный блок группировки показывает и хранит левая навигация. |

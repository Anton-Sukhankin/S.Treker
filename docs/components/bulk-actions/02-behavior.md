# Массовые действия: поведение

## 1. Основной пользовательский путь

1. Пользователь находится в списке задач.
2. Пользователь выбирает чекбокс одной задачи в карточке или строке таблицы.
3. Карточка или строка получает выбранное состояние.
4. Плавающая панель массовых действий видна в нижней центральной части блока списка задач.
5. Бейдж в панели показывает `1`.
6. Пользователь нажимает `Переместить в группу`.
7. Поверх интерфейса видно модальное окно `Перемещение в группу`.
8. Пользователь вводит название новой группы.
9. Пользователь нажимает `Переместить`.
10. Модальное окно закрыто.
11. Левая навигация показывает новую пользовательскую группу с выбранной задачей.
12. Выбранная задача теряет выбранное состояние.
13. Плавающая панель массовых действий скрыта.
14. Toast-уведомление показывает текст `Задачи перемещены в "Название группы"`.

## 2. Выбор задач

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по пустому чекбоксу карточки | Карточный вид активен; карточка не выбрана. | Карточка получает выбранное состояние; плавающая панель видна; счетчик показывает количество выбранных задач. |
| Клик по выбранному чекбоксу карточки | Карточный вид активен; карточка выбрана. | Карточка теряет выбранное состояние; счетчик показывает новое количество выбранных задач; если выбранных задач не осталось, плавающая панель скрыта. |
| Клик по пустому чекбоксу строки | Табличный вид активен; строка не выбрана. | Строка получает выбранное состояние; плавающая панель видна; счетчик показывает количество выбранных задач. |
| Клик по выбранному чекбоксу строки | Табличный вид активен; строка выбрана. | Строка теряет выбранное состояние; счетчик показывает новое количество выбранных задач; если выбранных задач не осталось, плавающая панель скрыта. |
| Клик по пустому чекбоксу заголовка таблицы | Табличный вид активен; на текущей странице есть минимум одна видимая строка; не все видимые строки выбраны. | Все видимые строки текущей страницы получают выбранное состояние; плавающая панель видна; счетчик показывает количество выбранных задач. |
| Клик по выбранному чекбоксу заголовка таблицы | Табличный вид активен; все видимые строки текущей страницы выбраны. | Все видимые строки текущей страницы теряют выбранное состояние; счетчик показывает новое количество выбранных задач; если выбранных задач не осталось, плавающая панель скрыта. |
| Клик по чекбоксу одной строки после выбора всех видимых строк | Табличный вид активен; после клика минимум одна, но не все видимые строки текущей страницы выбраны. | Чекбокс заголовка таблицы показывает частичный выбор; счетчик показывает новое количество выбранных задач. |

Чекбоксы и выбранное состояние карточек и строк расположены в списке задач. Массовые действия показывают панель по полученному набору выбранных задач.

## 3. Изменение видимого набора при активном выборе

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Смена страницы таблицы | Выбрана минимум одна задача. | Список задач показывает страницу, выбранную пользователем; плавающая панель остается видимой; счетчик продолжает показывать количество выбранных задач. |
| Ввод или изменение поиска | Выбрана минимум одна задача. | Список задач показывает задачи, подходящие под поиск; плавающая панель остается видимой; счетчик продолжает показывать количество выбранных задач. |
| Применение или изменение фильтров | Выбрана минимум одна задача. | Список задач показывает задачи, подходящие под активные фильтры; плавающая панель остается видимой; счетчик продолжает показывать количество выбранных задач. |
| Выбор другой области в левой навигации | Выбрана минимум одна задача. | Список задач показывает задачи выбранной области; плавающая панель остается видимой; счетчик продолжает показывать количество выбранных задач. |

## 4. Снятие выбора

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по кнопке снятия выбора с иконкой крестика в плавающей панели | Выбрана минимум одна задача. | Все чекбоксы карточек, строк и заголовка таблицы становятся пустыми; карточки и строки теряют выбранное состояние; плавающая панель скрыта. |

## 5. Открытие и закрытие модального окна

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по `Переместить в группу` | Выбрана минимум одна задача; плавающая панель видна. | Видно модальное окно `Перемещение в группу`; поле `Название новой группы` пустое; выбранные задачи остаются выбранными. |
| Клик по кнопке закрытия модального окна | Модальное окно `Перемещение в группу` открыто. | Модальное окно закрыто; выбранные чекбоксы остаются выбранными; плавающая панель остается видимой. |
| Клик по `Отмена` | Модальное окно `Перемещение в группу` открыто. | Модальное окно закрыто; выбранные чекбоксы остаются выбранными; плавающая панель остается видимой. |

## 6. Перемещение в группу

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Ввод текста в поле `Название новой группы` | Модальное окно `Перемещение в группу` открыто. | Поле содержит введенный текст. |
| Клик по `Переместить` | Модальное окно открыто; поле `Название новой группы` содержит текст. | Создана пользовательская группа с введенным названием; модальное окно закрыто; выбранные задачи теряют выбранное состояние; плавающая панель скрыта; левая навигация показывает новую группу; toast показывает `Задачи перемещены в "Название группы"`. |
| Клик по `Переместить` | Модальное окно открыто; поле `Название новой группы` пустое. | Создана пользовательская группа с названием `Группа`; модальное окно закрыто; выбранные задачи теряют выбранное состояние; плавающая панель скрыта; левая навигация показывает новую группу; toast показывает `Задачи перемещены в "Группа"`. |

Создание пользовательской группы не удаляет задачи из исходных бизнес-доменов.

## 7. Удаление из пользовательской группы

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Клик по `Удалить из группы` | Активна пользовательская группа; выбрана минимум одна задача из этой группы. | Выбранные задачи удалены из пользовательской группы; выбранные задачи теряют выбранное состояние; плавающая панель скрыта. |
| Клик по `Удалить из группы` | После удаления в пользовательской группе остается минимум одна задача. | Левая навигация содержит пункт этой группы; список задач показывает оставшиеся задачи группы. |
| Клик по `Удалить из группы` | После удаления в пользовательской группе не остается задач. | Пункт группы исчезает из левой навигации; активная область получает значение `Все задачи`; список задач показывает задачи всех доступных бизнес-доменов. |
| Клик по `Удалить из группы` | Активно сгруппированное значение, а не пользовательская группа. | Плавающая панель остается видимой; выбранные чекбоксы остаются выбранными; список задач остается на текущем сгруппированном значении; активный пункт левой навигации не меняется. |
| Клик по `Удалить из группы` | Активна группа внутри закладки, а не пользовательская группа. | Плавающая панель остается видимой; выбранные чекбоксы остаются выбранными; список задач остается на текущей группе внутри закладки; активный пункт левой навигации не меняется. |

После удаления каждой выбранной задачи из группы toast-уведомление показывает сообщение об удалении этой задачи. Если группа стала пустой, следующее toast-уведомление сообщает, что группа удалена.

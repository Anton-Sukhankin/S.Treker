# Массовые действия: структура интерфейса

## 1. Граница функционального блока

`Массовые действия` - функциональный блок для действий над набором выбранных задач.

Главный UI блока - плавающая панель массовых действий. Дочерний UI блока - модальное окно `Перемещение в группу`.

Чекбоксы задач находятся в списке задач. Они не входят в плавающую панель, но создают входное состояние блока: при выборе минимум одной задачи плавающая панель видна.

| Объект интерфейса | Роль для функционального блока | Видимая область | Правило границы |
|---|---|---|---|
| Чекбокс карточки задачи | Внешняя точка выбора одной задачи | Карточка задачи в списке задач | При выборе чекбокса карточка входит в набор выбранных задач; при снятии выбора карточка выходит из набора. |
| Чекбокс строки таблицы | Внешняя точка выбора одной задачи | Первая закрепленная колонка строки таблицы | При выборе чекбокса строка входит в набор выбранных задач; при снятии выбора строка выходит из набора. |
| Чекбокс заголовка таблицы | Внешняя точка выбора видимых строк текущей страницы | Первая закрепленная колонка заголовка таблицы | При выборе чекбокса видимые строки текущей страницы входят в набор выбранных задач; при снятии выбора эти строки выходят из набора. |
| Выбранное состояние карточки или строки | Внешнее состояние списка задач | Карточка или строка таблицы | Показывает, что задача входит в набор выбранных задач; плавающая панель не переносит карточку или строку внутрь себя. |
| Плавающая панель массовых действий | Главный UI блока | Нижняя центральная часть блока списка задач в правой рабочей области | Видна при количестве выбранных задач больше `0`; содержит счетчик, кнопки действий и кнопку снятия выбора. |
| Модальное окно `Перемещение в группу` | Дочерний UI блока | Модальный слой поверх интерфейса S-Tracker | Открывается из кнопки `Переместить в группу`; содержит поле названия новой пользовательской группы и кнопки завершения или отмены действия. |
| Список задач | Внешний источник выбора и получатель результата | Правая рабочая область | Содержит точки выбора задач; после завершенного группового действия показывает задачи без выбранного состояния. |
| Левая навигация | Внешнее условие видимого набора и получатель результата | Левая панель | Активная область задает видимый набор задач; после создания группы показывает новый пункт, после удаления пустой активной пользовательской группы не показывает этот пункт. |
| Toast-уведомление | Внешний получатель результата | Системная область уведомлений | Показывает текст результата после создания группы или удаления задач из группы. |

## 3. Пространственный контракт

### 3.1. Плавающая панель массовых действий

| Правило | Значение |
|---|---|
| Условие видимости | Количество выбранных задач больше `0`. |
| Условие появления | Пользователь выбирает чекбокс карточки, строки таблицы или заголовка таблицы, и набор выбранных задач становится непустым. |
| Условие скрытия | Набор выбранных задач становится пустым после снятия выбора, клика по кнопке снятия выбора с иконкой крестика или завершенного группового действия. |
| Точки выбора | Чекбоксы карточек, строк и заголовка таблицы остаются в списке задач; панель не содержит эти чекбоксы. |
| Слой | Плавающий слой поверх блока списка задач в правой рабочей области. |
| Область привязки | Карточный или табличный список задач в правой рабочей области. |
| Расположение | Нижняя центральная часть блока списка задач; центрирование относится к правой рабочей области, а не ко всей ширине экрана. |
| Влияние на список задач | Панель находится поверх нижней части карточного или табличного списка; она не добавляет строку в таблицу, не добавляет карточку и не меняет состав колонок. |
| Влияние на соседние области | Панель не сдвигает пагинацию, панель инструментов, очереди и левую навигацию; левую навигацию панель не перекрывает. |
| Граница с левой навигацией | Левая навигация остается соседней областью; она не входит в область размещения панели и не получает новый пункт только от факта выбора задач. |
| Владелец видимости | Функциональный блок `Массовые действия` показывает или скрывает панель по количеству задач в наборе выбранных задач. |

| Зона панели | Расположение в панели | Состав при видимой панели | Условие видимости зоны | Что не входит |
|---|---|---|---|---|
| Счетчик выбранных задач | Левая часть панели | Текст `Результат:`; бейдж с числом выбранных задач | Панель видима. | Чекбоксы карточек, строк и заголовка таблицы. |
| Основные действия | Центральная часть панели | Кнопки `Изменить статус` и `Переместить в группу` | Панель видима. | Поле названия группы и элементы модального окна. |
| Контекстные действия | После основных действий | Кнопки `Назначить`, `Взять в работу`, `Завершить`, `Удалить из группы` | Панель видима; конкретная кнопка показана только при своем продуктовом условии. | Левая навигация, список задач и toast-уведомление. |
| Снятие выбора | Правая часть панели | Кнопка снятия выбора с иконкой крестика | Панель видима. | Чекбоксы списка задач как внешние точки выбора. |

### 3.2. Модальное окно `Перемещение в группу`

| Правило | Значение |
|---|---|
| Условие видимости | Пользователь нажал кнопку `Переместить в группу` в плавающей панели. |
| Слой | Модальный слой поверх интерфейса S-Tracker; список задач и левая навигация остаются видимыми областями под модальным слоем. |
| Область привязки | Окно открывается из плавающей панели, но не размещается внутри панели и не занимает место в списке задач. |
| Связь с плавающей панелью | Плавающая панель остается признаком непустого набора выбранных задач; модальное окно получает этот набор для создания пользовательской группы. |
| Владелец видимости | Функциональный блок `Массовые действия` хранит открытое или закрытое состояние модального окна. |
| Влияние на список задач | До подтверждения действия модальное окно не меняет состав списка задач и не снимает выбранное состояние задач. |
| Влияние на левую навигацию | До подтверждения действия левая навигация не показывает новую пользовательскую группу и не задает расположение модального окна. |
| Закрытие без подтверждения | После закрытия через кнопку закрытия или `Отмена` модальное окно скрыто; выбранные задачи и плавающая панель остаются в состоянии до открытия окна. |

| Часть модального окна | Расположение | Состав |
|---|---|---|
| Хедер | Верхняя зона окна | Заголовок `Перемещение в группу`; кнопка закрытия. |
| Описание | Под хедером | Текст `Задачи будут объединены в новую кастомную группу.` |
| Поле названия | Основная зона окна | Подпись `Название новой группы`; поле ввода с плейсхолдером `Напр: Срочный ремонт БЦ`. |
| Футер | Нижняя зона окна | Кнопка `Отмена`; кнопка `Переместить`. |

## 4. Точки выбора задач

| Элемент выбора | Видимая область | Условие видимости | Роль для функционального блока |
|---|---|---|---|
| Чекбокс карточки задачи | Карточка задачи | Активен карточный вид списка задач. | Добавляет одну карточку в набор выбранных задач или убирает ее из набора. |
| Чекбокс строки таблицы | Строка таблицы | Активен табличный вид списка задач. | Добавляет одну строку в набор выбранных задач или убирает ее из набора. |
| Чекбокс заголовка таблицы | Заголовок первой закрепленной колонки таблицы | Активен табличный вид; на текущей странице есть минимум одна видимая строка. | Добавляет видимые строки текущей страницы в набор выбранных задач или убирает их из набора. |

## 5. Состав кнопок плавающей панели

| Кнопка | Часть панели | Структурная роль |
|---|---|---|
| `Изменить статус` | Основные действия | Кнопка группового действия без дочернего UI в текущей структуре. |
| `Переместить в группу` | Основные действия | Кнопка открытия модального окна `Перемещение в группу`. |
| `Назначить` | Контекстные действия | Контекстная кнопка для выбранных задач этапа `К назначению` без дочернего UI в текущей структуре. |
| `Взять в работу` | Контекстные действия | Контекстная кнопка для выбранных задач этапа `К исполнению` без дочернего UI в текущей структуре. |
| `Завершить` | Контекстные действия | Контекстная кнопка для выбранных задач этапа `В работе` без дочернего UI в текущей структуре. |
| `Удалить из группы` | Контекстные действия | Кнопка удаления выбранных задач из активной пользовательской группы. |
| Кнопка снятия выбора с иконкой крестика | Снятие выбора | Кнопка очистки набора выбранных задач. |

## 6. Внешние условия и получатели результата

| Внешняя область | Тип связи | Правило для структуры `Массовых действий` |
|---|---|---|
| Карточный и табличный список задач | Источник выбора одной задачи | Чекбокс карточки или строки создает выбранное состояние задачи; панель получает только набор выбранных задач и число в счетчике. |
| Заголовок таблицы | Источник выбора видимых строк текущей страницы | Чекбокс заголовка относится только к видимым строкам текущей страницы. |
| Фильтрация и поиск | Внешнее условие видимого набора | Видимый набор задач задает, какие карточки или строки доступны для выбора на экране. |
| Пагинация | Внешнее условие видимых строк таблицы | Чекбокс заголовка таблицы выбирает строки только на текущей странице. |
| Настройки колонок | Соседний компонент без результата для массовых действий | Чекбоксы выбора остаются доступными независимо от состава динамических колонок. |
| Этапы выбранных задач | Внешнее условие состава контекстных кнопок | Этапы выбранных задач определяют наличие кнопок `Назначить`, `Взять в работу` и `Завершить`. |
| Левая навигация | Внешнее условие и получатель результата | Активная область задает видимый набор задач; после создания группы или удаления пустой активной пользовательской группы левая навигация показывает итоговое состояние пунктов. |
| Toast-уведомление | Внешний получатель результата | После завершенного группового действия показывает текст результата. |

Массовые действия не создают задачи, не меняют атрибуты задач, не меняют состав бизнес-доменов, не меняют поисковую строку и не меняют параметры фильтрации.

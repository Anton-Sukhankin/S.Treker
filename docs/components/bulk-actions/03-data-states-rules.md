# Массовые действия: данные, состояния и правила

## 1. Владельцы состояния

| Состояние или значение | Владелец видимого состояния | Где используется | Видимый результат |
|---|---|---|---|
| Чекбокс карточки задачи | Список задач | Выбор одной задачи в карточном виде | Выбранный чекбокс показывает, что карточка входит в набор выбранных задач. |
| Чекбокс строки таблицы | Список задач | Выбор одной задачи в табличном виде | Выбранный чекбокс показывает, что строка входит в набор выбранных задач. |
| Чекбокс заголовка таблицы | Список задач | Выбор видимых строк текущей страницы таблицы | Выбран или частично выбран по состоянию видимых строк текущей страницы. |
| Набор выбранных задач | Список задач создает набор через чекбоксы; функциональный блок `Массовые действия` использует состав и количество набора | Плавающая панель, счетчик, кнопки действий, модальное окно `Перемещение в группу` | При непустом наборе панель видна; счетчик равен количеству выбранных задач. |
| Видимость плавающей панели | Функциональный блок `Массовые действия` | Нижняя центральная часть блока списка задач | Панель видна при количестве выбранных задач больше `0`; панель скрыта при количестве `0`. |
| Состав кнопок плавающей панели | Функциональный блок `Массовые действия` | Плавающая панель | Основные кнопки видны при непустом выборе; контекстные кнопки видны при своих условиях из раздела 5. |
| Состояние модального окна `Перемещение в группу` | Функциональный блок `Массовые действия` | Модальный слой поверх интерфейса | Окно видно после клика по `Переместить в группу`; окно скрыто после отмены, закрытия или подтверждения. |
| Значение поля `Название новой группы` | Модальное окно `Перемещение в группу` | Поле названия новой пользовательской группы | Пустое поле дает название `Группа`; заполненное поле дает группе введенное название. |
| Пользовательские группы и активная область задач | Левая навигация | Список пунктов навигации и выбранная область | После создания группы левая навигация содержит новый пункт; после удаления последней задачи из активной пользовательской группы этот пункт отсутствует, активная область получает значение `Все задачи`. |
| Видимый набор задач | Список задач | Правая рабочая область | Активная область левой навигации, поиск, фильтры и пагинация задают, какие карточки или строки видны пользователю. |
| Текст результата действия | Toast-уведомление | Системная область уведомлений | После создания группы или удаления задач из группы toast показывает текст результата. |

## 2. Набор выбранных задач и счетчик

| Состояние набора | Условие | Видимый результат |
|---|---|---|
| Пустой выбор | Количество выбранных задач равно `0`. | Все видимые чекбоксы задач пустые; карточки и строки не имеют выбранного состояния; плавающая панель скрыта; счетчик не виден. |
| Одна выбранная задача | В набор выбранных задач входит одна задача. | Выбранная карточка или строка имеет выбранное состояние; плавающая панель видна; бейдж счетчика показывает `1`. |
| Несколько выбранных задач | В набор выбранных задач входят две или больше задач. | Каждая видимая выбранная карточка или строка имеет выбранное состояние; плавающая панель видна; бейдж счетчика показывает количество выбранных задач. |
| Выбранная задача стала невидимой | Пользователь сменил страницу, поиск, фильтры или область левой навигации, и выбранная задача больше не входит в видимый набор. | Бейдж счетчика продолжает включать эту задачу; плавающая панель остается видимой, если общее количество выбранных задач больше `0`. |
| Выбор очищен через кнопку снятия выбора | Пользователь нажал кнопку снятия выбора с иконкой крестика. | Набор выбранных задач получает значение `0`; чекбоксы задач пустые; карточки и строки не имеют выбранного состояния; плавающая панель скрыта. |
| Выбор очищен после завершенного группового действия | Создана пользовательская группа или выбранные задачи удалены из активной пользовательской группы. | Набор выбранных задач получает значение `0`; чекбоксы задач пустые; карточки и строки не имеют выбранного состояния; плавающая панель скрыта. |

## 3. Состояния чекбокса заголовка таблицы

| Состояние чекбокса заголовка | Условие в табличном виде | Видимый результат |
|---|---|---|
| Пустой | На текущей странице таблицы нет выбранных видимых строк. | Чекбокс заголовка пустой. |
| Выбран | Количество выбранных видимых строк равно количеству видимых строк текущей страницы. | Чекбокс заголовка выбран. |
| Частичный выбор | На текущей странице выбрана минимум одна, но не все видимые строки. | Чекбокс заголовка показывает частичный выбор. |

В карточном виде чекбокс выбора всех задач не виден.

## 4. Область действия выбора

| Область | Правило состояния |
|---|---|
| Карточный вид | Чекбокс карточки добавляет одну задачу в набор выбранных задач или убирает ее из набора. |
| Табличный вид | Чекбокс строки добавляет одну задачу в набор выбранных задач или убирает ее из набора. |
| Текущая страница таблицы | Чекбокс заголовка таблицы добавляет в набор выбранных задач только видимые строки текущей страницы или убирает их из набора. |
| Поиск, фильтры, пагинация и левая навигация | Эти области меняют видимый набор задач, но сами по себе не очищают набор выбранных задач. |

## 5. Видимость кнопок плавающей панели

| Кнопка | Условие видимости | Видимый результат при выполнении условия |
|---|---|---|
| `Изменить статус` | Количество выбранных задач больше `0`. | Кнопка видна в основных действиях панели. |
| `Переместить в группу` | Количество выбранных задач больше `0`. | Кнопка видна в основных действиях панели. |
| `Назначить` | Среди выбранных задач есть минимум одна задача из этапа `К назначению`. | Кнопка видна в контекстных действиях панели. |
| `Взять в работу` | Среди выбранных задач есть минимум одна задача из этапа `К исполнению`. | Кнопка видна в контекстных действиях панели. |
| `Завершить` | Среди выбранных задач есть минимум одна задача из этапа `В работе`. | Кнопка видна в контекстных действиях панели. |
| `Удалить из группы` | Активная область относится к пользовательской группе, группе внутри закладки или сгруппированному значению. | Кнопка видна в контекстных действиях панели. |
| Кнопка снятия выбора с иконкой крестика | Количество выбранных задач больше `0`. | Кнопка видна в правой части панели. |

Если выбранные задачи относятся к нескольким этапам, плавающая панель одновременно показывает все контекстные кнопки, условия которых выполнены.

## 6. Модальное окно `Перемещение в группу`

| Состояние | Условие входа | Видимый результат | Условие выхода |
|---|---|---|---|
| Закрыто | Модальное окно не открыто. | Модальное окно не видно; выбранные задачи сохраняют свое состояние. | Пользователь нажимает `Переместить в группу`. |
| Открыто | Пользователь нажал `Переместить в группу` при непустом наборе выбранных задач. | Видны заголовок `Перемещение в группу`, описание, поле `Название новой группы`, кнопки `Отмена` и `Переместить`; поле названия пустое. | Пользователь нажимает кнопку закрытия, `Отмена` или `Переместить`. |
| Закрыто без подтверждения | Пользователь нажал кнопку закрытия или `Отмена`. | Модальное окно не видно; выбранные задачи остаются выбранными; плавающая панель остается видимой. | Пользователь снова нажимает `Переместить в группу` или снимает выбор задач. |
| Закрыто после подтверждения | Пользователь нажал `Переместить`. | Модальное окно не видно; создана пользовательская группа; выбранные задачи теряют выбранное состояние; плавающая панель скрыта. | Пользователь снова выбирает минимум одну задачу. |

| Значение поля `Название новой группы` | Условие подтверждения | Название созданной группы |
|---|---|---|
| Пустое | Пользователь нажал `Переместить`. | `Группа`. |
| Непустое | Пользователь нажал `Переместить`. | Введенный пользователем текст. |

## 7. Правила результата групповых действий

| Действие или состояние | Условие | Видимый результат |
|---|---|---|
| Создание пользовательской группы | Пользователь подтвердил `Переместить` в модальном окне. | Левая навигация содержит новую пользовательскую группу; выбранные задачи остаются в исходных бизнес-доменах; набор выбранных задач очищен; плавающая панель скрыта. |
| Toast после создания группы | Пользовательская группа создана. | Toast показывает `Задачи перемещены в "Название группы"`, где `Название группы` равно введенному названию или `Группа` для пустого поля. |
| Удаление из активной пользовательской группы | Активна пользовательская группа; выбрана минимум одна задача из этой группы; пользователь нажал `Удалить из группы`. | Выбранные задачи отсутствуют в этой пользовательской группе; набор выбранных задач очищен; плавающая панель скрыта. |
| Пользовательская группа не стала пустой после удаления | После удаления в группе остается минимум одна задача. | Левая навигация содержит пункт группы; список задач содержит оставшиеся задачи группы. |
| Пользовательская группа стала пустой после удаления | После удаления в группе нет задач. | Левая навигация не содержит пункт этой группы; активная область получает значение `Все задачи`; список задач содержит задачи из `Все задачи`. |
| `Удалить из группы` при сгруппированном значении | Активная область является сгруппированным значением, а не пользовательской группой. | Плавающая панель остается видимой; выбранные чекбоксы остаются выбранными; список задач остается на текущем сгруппированном значении; активный пункт левой навигации не меняется. |
| `Удалить из группы` при группе внутри закладки | Активная область является группой внутри закладки, а не пользовательской группой. | Плавающая панель остается видимой; выбранные чекбоксы остаются выбранными; список задач остается на текущей группе внутри закладки; активный пункт левой навигации не меняется. |
| Toast после удаления из группы | Выбранные задачи удаляются из активной пользовательской группы. | После удаления каждой выбранной задачи toast показывает сообщение об удалении этой задачи; если группа стала пустой, следующее toast-уведомление сообщает, что группа удалена. |
| Кнопки без реализованного результата | Пользователь нажал `Изменить статус`, `Назначить`, `Взять в работу` или `Завершить`. | Плавающая панель остается видимой; выбранные чекбоксы остаются выбранными; список задач и активный пункт левой навигации не меняются. |

## 8. Контракты взаимодействия

| Тип связи | Источник | Передаваемый результат | Получатель | Видимый итог |
|---|---|---|---|---|
| Выбор одной задачи | Чекбокс карточки или строки в списке задач | Набор выбранных задач и его количество | Плавающая панель массовых действий | Панель видна при количестве больше `0`; счетчик равен количеству выбранных задач. |
| Выбор видимых строк текущей страницы | Чекбокс заголовка таблицы | Видимые строки текущей страницы входят в набор выбранных задач или выходят из него | Плавающая панель массовых действий | Панель видна при количестве больше `0`; счетчик равен количеству выбранных задач. |
| Изменение видимого набора | Левая навигация, пагинация, поиск или фильтры | Новый видимый набор задач; ранее выбранные задачи остаются в наборе выбранных задач | Плавающая панель массовых действий | Панель остается видимой, если количество выбранных задач больше `0`; счетчик продолжает включать ранее выбранные задачи. |
| Снятие выбора через панель | Кнопка снятия выбора с иконкой крестика | Набор выбранных задач равен `0` | Список задач и плавающая панель | Чекбоксы задач пустые; карточки и строки не имеют выбранного состояния; панель скрыта. |
| Открытие модального окна | Кнопка `Переместить в группу` в плавающей панели | Набор выбранных задач сохранен; состояние модального окна открыто | Модальное окно `Перемещение в группу` | Модальное окно видно поверх интерфейса; список задач и левая навигация не меняют состав до подтверждения. |
| Подтверждение перемещения в группу | Модальное окно `Перемещение в группу` | Название группы и набор выбранных задач | Левая навигация | Левая навигация содержит новую пользовательскую группу. |
| Подтверждение перемещения в группу | Модальное окно `Перемещение в группу` | Набор выбранных задач очищен после создания группы | Список задач и плавающая панель | Выбранные задачи не имеют выбранного состояния; панель скрыта. |
| Создание пользовательской группы | Модальное окно `Перемещение в группу` | Название созданной группы | Toast-уведомление | Toast показывает текст `Задачи перемещены в "Название группы"`. |
| Удаление из активной пользовательской группы | Кнопка `Удалить из группы` | Выбранные задачи исключены из активной пользовательской группы | Левая навигация и список задач | Левая навигация и список задач показывают состояние группы после удаления выбранных задач. |

## 9. Ограничения ответственности

| Область | Правило |
|---|---|
| Данные задач | Массовые действия не создают задачи и не изменяют атрибуты задач. |
| Бизнес-домены | Создание пользовательской группы не удаляет задачи из исходных бизнес-доменов. |
| Этапы задач | Клики по `Изменить статус`, `Назначить`, `Взять в работу` и `Завершить` в текущем прототипе не изменяют этап задачи. |
| Левая навигация | Массовые действия добавляют пользовательскую группу после подтверждения `Переместить`; они убирают пункт активной пользовательской группы только после удаления последней задачи из этой группы. |
| Поиск и фильтры | Массовые действия не меняют поисковую строку и параметры фильтрации. |
| Пагинация | Массовые действия не устанавливают новое значение текущей страницы. |
| Настройки колонок | Массовые действия не меняют состав и порядок динамических колонок. |
| Визуальные состояния готовых компонентов | Массовые действия фиксируют только продуктовые условия S-Tracker; стандартные визуальные и интерактивные состояния готовых компонентов не входят в правила `bulk-actions`. |

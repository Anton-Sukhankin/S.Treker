# Очереди: структура интерфейса

## 1. Граница компонента

`Очереди` - горизонтальный inline-блок сегментов этапов согласования в правой рабочей области. При видимом состоянии блок занимает отдельную строку между панелью инструментов и списком задач.

Компонент владеет составом сегментов, активным сегментом, видимыми счетчиками сегментов и красной индикацией счетчика `К исполнению`. Компонент не владеет панелью инструментов, левой навигацией, составом списка задач, статусами задач, настройками колонок и массовыми действиями.

| Объект интерфейса | Статус относительно очередей | Правило |
|---|---|---|
| Горизонтальная панель сегментов | Внутренняя область компонента | При видимых очередях панель находится под панелью инструментов и содержит текущий набор сегментов этапов согласования. |
| Сегмент очереди | Внутренний элемент панели | При видимой панели каждый сегмент показывает название очереди; сегменты со счетчиком показывают число рядом с названием. |
| Активный признак сегмента | Внутреннее состояние сегмента | При видимой панели один сегмент получает активное состояние; активный признак относится к сегменту, а не к строкам списка задач. |
| Счетчик сегмента | Внутренний элемент сегмента | При видимой панели счетчик показан только у сегментов, для которых счетчик предусмотрен в текущем прототипе. |
| Красная индикация счетчика | Внутренний визуальный признак счетчика | При срабатывании правила просрочки красная индикация применяется к счетчику `К исполнению`; отдельный сегмент или статус задачи не создается. |
| Панель инструментов | Соседняя область выше | Панель инструментов остается над очередями; она не задает состав сегментов, активный сегмент или счетчики очередей. |
| Список задач | Внешний получатель результата ниже | После выбора сегмента список задач под очередями показывает задачи выбранной очереди с учетом текущих условий отбора. |
| Левая навигация | Внешнее условие видимости | Выбранная область задач задает, видна строка очередей или скрыта; левая навигация не входит в компонент. |
| Статус задачи | Внешнее значение задачи | Очереди не показывают и не изменяют статус задачи; очередь определяет только сегмент над списком задач. |

## 2. Пространственный контракт

| Зона | Расположение и привязка | Состав | Условие видимости | Слой и влияние на соседние области | Владелец состояния | Что не входит |
|---|---|---|---|---|---|---|
| Видимая панель сегментов | Правая рабочая область, отдельная строка под панелью инструментов и над списком задач | Текущий набор сегментов очередей | Открыт обычный список задач: `Все задачи`, бизнес-домен или сгруппированное значение | Inline в потоке правой рабочей области; панель занимает строку между панелью инструментов и списком задач, не перекрывает панель инструментов, левую навигацию и список задач | Очереди владеют составом сегментов, активным сегментом и счетчиками; выбранная область задач задает условие показа панели | Панель инструментов, список задач, левая навигация, массовые действия |
| Сегмент очереди | Внутри видимой панели сегментов | Название очереди; счетчик, если он предусмотрен для сегмента | Видимая панель сегментов показана | Inline внутри панели; сегмент не открывает drawer, modal, overlay, sticky-область или плавающую панель | Очереди владеют активным состоянием сегмента и видимостью счетчика | Статус задачи, строки списка задач |
| Скрытое состояние очередей | Между панелью инструментов и списком задач нет строки сегментов | Сегменты и счетчики не показаны | Выбрана пользовательская группа или кастомный список без переключения этапов | Строка очередей не занимает место; список задач остается видимым без ряда сегментов над ним | Выбранная область задач задает условие скрытия; очереди не показывают активный сегмент и счетчики | Список задач остается видимым |

## 3. Состав сегмента

| Часть сегмента | Условие видимости | Видимый результат |
|---|---|---|
| Название очереди | Сегмент находится в видимой панели очередей | Внутри сегмента показан текст очереди. |
| Счетчик задач | Для сегмента предусмотрен счетчик в текущем прототипе | Рядом с названием сегмента показано число задач. |
| Активный признак | Сегмент является активной очередью | Сегмент визуально отличается от неактивных сегментов. |
| Красная индикация счетчика | Для счетчика `К исполнению` выполнено правило красной индикации | Счетчик `К исполнению` получает красную индикацию; название сегмента и состав панели не меняются. |

## 4. Текущий видимый набор сегментов

В текущем прототипе видимая панель очередей содержит такой набор сегментов:

| Сегмент | Счетчик в текущем прототипе |
|---|---|
| `К исполнению` | Да |
| `В работе` | Да |
| `Обработаны мной` | Нет |
| `К назначению` | Да |
| `Наблюдаю` | Нет |
| `Инициированы мной` | Нет |

# Очереди: поведение

## 1. Основной пользовательский путь

1. Пользователь находится в обычном списке задач, где строка очередей видна над списком задач.
2. В строке очередей активен сегмент `К исполнению`.
3. Список задач показывает задачи текущей области, которые относятся к очереди `К исполнению`.
4. Пользователь выбирает неактивный сегмент очереди.
5. Выбранный сегмент становится активным, а предыдущий активный сегмент становится неактивным.
6. Список задач показывает задачи выбранной очереди с учетом текущей области задач, поисковой строки и примененных фильтров.
7. Счетчики в строке очередей остаются видимыми у сегментов, где они предусмотрены, и показывают значения для текущей области задач, поисковой строки и примененных фильтров.

## 2. Переключение сегмента

| Действие пользователя | Исходное состояние | Итог интерфейса |
|---|---|---|
| Пользователь выбирает неактивный сегмент очереди | Строка очередей видна; выбран другой активный сегмент | Выбранный сегмент получает активное состояние; остальные сегменты неактивны; список задач показывает задачи выбранной очереди. |
| Пользователь выбирает уже активный сегмент | Строка очередей видна; выбранный сегмент уже активен | Активный сегмент не меняется; список задач остается в текущем состоянии. |
| Пользователь выбирает неактивный сегмент при введенном поиске | Строка очередей видна; поисковая строка содержит значение | Выбранный сегмент получает активное состояние; список задач показывает задачи выбранной очереди, которые совпадают с поисковой строкой. |
| Пользователь выбирает неактивный сегмент при примененных фильтрах | Строка очередей видна; фильтры применены | Выбранный сегмент получает активное состояние; список задач показывает задачи выбранной очереди, которые проходят примененные фильтры. |

Переключение сегмента очереди не меняет выбранную область в левой навигации, поисковую строку, примененные фильтры, режим карточек или таблицы, выбранные задачи и настройки колонок.

## 3. Действия вне очередей, которые меняют видимый результат

| Действие пользователя | Условие перед действием | Видимый результат для очередей и списка задач |
|---|---|---|
| Пользователь выбирает `Все задачи`, бизнес-домен или сгруппированное значение в левой навигации | Выбранная область поддерживает переключение этапов согласования | Строка очередей видна над списком задач; список задач показывает задачи активной очереди внутри выбранной области. |
| Пользователь выбирает пользовательскую группу в левой навигации | Строка очередей была видна или скрыта | Строка очередей скрыта; список задач остается видимым без ряда сегментов над ним. |
| Пользователь выбирает кастомный список без переключения этапов | Строка очередей была видна или скрыта | Строка очередей скрыта; список задач остается видимым без ряда сегментов над ним. |
| Пользователь вводит или очищает поисковую строку | Строка очередей видна | Счетчики очередей показывают значения с учетом поисковой строки; список задач показывает задачи активной очереди с учетом поисковой строки. |
| Пользователь применяет фильтры | Строка очередей видна; в панели фильтрации есть выбранные параметры | Счетчики очередей показывают значения с учетом примененных фильтров; список задач показывает задачи активной очереди, которые проходят примененные фильтры. |
| Пользователь сбрасывает фильтры | Строка очередей видна; фильтры были применены | Счетчики очередей показывают значения текущей области без фильтрационного сужения; список задач показывает задачи активной очереди без фильтрационного сужения. |
| Пользователь переключает карточный или табличный вид списка | Строка очередей видна | Активный сегмент очереди не меняется; список задач показывает задачи активной очереди в выбранном режиме отображения. |

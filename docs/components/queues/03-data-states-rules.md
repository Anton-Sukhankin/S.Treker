# Очереди: данные, состояния и правила

## 1. Владельцы состояния и входные условия

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Очереди | Состав сегментов, активная очередь, видимость строки сегментов, счетчики очередей, красная индикация счетчика `К исполнению` | При видимых очередях один сегмент активен, а счетчики показывают значения для текущих условий отбора. При скрытых очередях строка сегментов, активный сегмент и счетчики не показаны над списком задач. |
| Левая навигация | Выбранная область задач: `Все задачи`, бизнес-домен, сгруппированное значение, пользовательская группа или кастомный список без переключения этапов | Очереди используют выбранную область как условие видимости строки сегментов и как условие расчета счетчиков; левая навигация владеет выбранной областью. |
| Поисковая строка | Введенное или пустое значение поиска | Очереди используют поисковую строку при расчете счетчиков; поле поиска владеет текстовым значением. |
| Панель фильтрации | Примененные параметры фильтрации | Очереди используют только примененные параметры при расчете счетчиков; панель фильтрации владеет выбором, применением и сбросом параметров. |
| Список задач | Итоговый набор карточек или строк активной очереди | Список задач показывает задачи активной очереди с учетом выбранной области, поисковой строки и примененных фильтров; список задач владеет карточным и табличным отображением результата. |

## 2. Сегменты очередей в текущем прототипе

| Очередь | Участвует в отборе задач | Счетчик видим |
|---|---|---|
| `К исполнению` | Да | Да |
| `В работе` | Да | Да |
| `Обработаны мной` | Да | Нет |
| `К назначению` | Да | Да |
| `Наблюдаю` | Да | Нет |
| `Инициированы мной` | Да | Нет |

Очередь не является статусом задачи. Статус задачи описывает состояние самой задачи; очередь определяет сегмент над списком задач, в который попадает задача.

## 3. Активная очередь

| Состояние | Условие входа | Видимый результат | Условие выхода |
|---|---|---|---|
| Активна очередь `К исполнению` по умолчанию | Открыт обычный список задач до пользовательского выбора другого сегмента | Сегмент `К исполнению` активен; список задач показывает задачи очереди `К исполнению`. | Пользователь выбирает другой сегмент или выбирает область, где строка очередей скрыта. |
| Активна очередь, выбранная пользователем | Пользователь выбирает неактивный сегмент в видимой строке очередей | Выбранный сегмент активен; остальные сегменты неактивны; список задач показывает задачи выбранной очереди. | Пользователь выбирает другой сегмент или выбирает область, где строка очередей скрыта. |
| Очереди скрыты | Пользователь выбирает пользовательскую группу или кастомный список без переключения этапов | Активный сегмент и счетчики не показаны над списком задач. | Пользователь выбирает `Все задачи`, бизнес-домен или сгруппированное значение. |

При видимой строке очередей в каждый момент активен один сегмент.

## 4. Видимость строки очередей

| Состояние | Условие входа | Видимый результат | Условие выхода |
|---|---|---|---|
| Очереди видны | Открыт обычный список задач: `Все задачи`, бизнес-домен или сгруппированное значение | Под панелью инструментов видна горизонтальная строка сегментов; один сегмент активен; список задач расположен ниже строки сегментов. | Пользователь выбирает пользовательскую группу или кастомный список без переключения этапов. |
| Очереди скрыты для пользовательской группы | Пользователь выбирает пользовательскую группу | Строка сегментов не видна; активный сегмент и счетчики не показаны; список задач остается видимым. | Пользователь выбирает `Все задачи`, бизнес-домен или сгруппированное значение. |
| Очереди скрыты для кастомного списка без переключения этапов | Пользователь выбирает кастомный список без переключения этапов | Строка сегментов не видна; активный сегмент и счетчики не показаны; список задач остается видимым. | Пользователь выбирает `Все задачи`, бизнес-домен или сгруппированное значение. |

## 5. Правило попадания задачи в список активной очереди

Задача видна в списке задач активной очереди только тогда, когда она проходит все условия отбора.

| Условие | Объект проходит | Объект исключается |
|---|---|---|
| Очередь | Значение очереди задачи совпадает с активной очередью. | Значение очереди задачи не совпадает с активной очередью. |
| Область задач | Задача входит в выбранные `Все задачи`, бизнес-домен или сгруппированное значение. | Задача находится вне выбранной области задач. |
| Поиск | Задача проходит текущую поисковую строку или поисковая строка пуста. | Задача не проходит текущую поисковую строку. |
| Фильтры | Задача проходит все примененные параметры фильтрации или фильтры не применены. | Задача не проходит минимум один примененный параметр фильтрации. |

Если строка очередей скрыта для пользовательской группы или кастомного списка без переключения этапов, правило активной очереди не применяется к видимому списку задач.

## 6. Правило счетчиков

Счетчик сегмента показывает количество задач, которые проходят условия отбора для очереди этого сегмента. Если строка очередей скрыта, счетчики не видны над списком задач.

| Условие счетчика | Требование для включения задачи в число |
|---|---|
| Очередь сегмента | Задача относится к очереди сегмента, для которого считается счетчик. |
| Область задач | Задача входит в выбранную область задач. |
| Поисковая строка | Задача проходит текущую поисковую строку или поисковая строка пуста. |
| Примененные фильтры | Задача проходит все примененные параметры фильтрации или фильтры не применены. |

| Значение счетчика | Видимый результат |
|---|---|
| `0` | Счетчик показывает `0` и получает пониженную визуальную насыщенность. |
| Больше `0` | Счетчик показывает количество подходящих задач. |

## 7. Правило красной индикации

| Условие | Видимый результат |
|---|---|
| Счетчик `К исполнению` больше `0`, и среди задач, входящих в счетчик текущего контекста, есть просроченная задача | Счетчик `К исполнению` получает красную индикацию. |
| Среди задач, входящих в счетчик `К исполнению` текущего контекста, нет просроченных задач | Счетчик `К исполнению` остается в обычном состоянии. |
| Просроченная задача находится в очереди, отличной от `К исполнению` | Красная индикация счетчиков других очередей не применяется. |

## 8. Контракты взаимодействия

| Тип связи | Источник | Условие | Передаваемый результат | Получатель | Видимый итог |
|---|---|---|---|---|---|
| Входящее условие видимости | Левая навигация | Пользователь выбирает `Все задачи`, бизнес-домен или сгруппированное значение | Выбранная область задач с переключением этапов | Очереди | Строка очередей видна; счетчики показывают значения для выбранной области. |
| Входящее условие скрытия | Левая навигация | Пользователь выбирает пользовательскую группу | Выбранная пользовательская группа без переключения этапов | Очереди | Строка очередей скрыта; активный сегмент и счетчики не показаны. |
| Входящее условие скрытия | Левая навигация | Пользователь выбирает кастомный список без переключения этапов | Выбранный кастомный список без переключения этапов | Очереди | Строка очередей скрыта; активный сегмент и счетчики не показаны. |
| Входящее условие счетчиков | Поисковая строка | Пользователь вводит или очищает поиск | Текущее значение поиска | Очереди | Счетчики показывают значения с учетом поисковой строки. |
| Входящее условие счетчиков | Панель фильтрации | Пользователь применяет или сбрасывает фильтры | Примененные параметры фильтрации или пустой набор примененных параметров | Очереди | Счетчики показывают значения с учетом примененных параметров. |
| Исходящий результат выбора | Очереди | Пользователь выбирает сегмент очереди | Активная очередь | Список задач | Список задач показывает карточки или строки выбранной очереди с учетом выбранной области, поисковой строки и примененных фильтров. |
| Исходящее условие отображения | Очереди | Активная очередь уже выбрана, а пользователь переключает карточный или табличный вид списка | Активная очередь без изменения | Список задач | Список задач показывает тот же набор задач активной очереди в выбранном режиме отображения. |

## 9. Ограничения ответственности

| Область | Правило |
|---|---|
| Статус задачи | Очереди не показывают и не изменяют статус задачи. |
| Значение очереди задачи | Выбор сегмента не изменяет значение очереди у задач. |
| Левая навигация | Очереди не изменяют выбранную область задач. |
| Поисковая строка | Очереди не изменяют введенный текст поиска. |
| Панель фильтрации | Очереди не выбирают, не применяют и не сбрасывают параметры фильтрации. |
| Режим списка задач | Очереди не переключают карточный и табличный режимы. |
| Настройки колонок | Очереди не изменяют состав и порядок колонок таблицы. |
| Панель инструментов | Очереди не создают и не размещают элементы панели инструментов; панель инструментов остается соседней областью над очередями. |
| Массовые действия | Очереди не показывают панель массовых действий, не выбирают задачи и не определяют набор кнопок массовых действий. |

# Пагинация: данные, состояния и правила

## 1. Термины и владельцы состояния

| Область | Состояние или значение | Условие изменения | Видимый результат |
|---|---|---|---|
| Список задач | Отобранный набор до пагинации: задачи после выбранной области, активной очереди, поиска, примененных фильтров и сортировки | Пользователь меняет область, очередь, поиск, фильтры или сортировку | Пагинация получает количество и порядок задач этого набора; список задач остается владельцем состава карточек и строк. |
| Пагинация | Текущая страница | Пользователь выбирает номер страницы, нажимает доступную кнопку навигации или внешний результат сбрасывает страницу | Активный номер в панели совпадает с текущей страницей; список задач показывает видимый набор этой страницы. |
| Пагинация | Количество страниц | Отобранный набор до пагинации получает новое количество задач | Панель показывает доступные номера страниц, если страниц больше одной. |
| Пагинация | Видимые номера страниц и разрывы `...` | Количество страниц или текущая страница меняется | Панель показывает допустимый набор номеров и разрывов для текущей позиции. |
| Список задач | Видимый набор текущей страницы | Текущая страница или отобранный набор до пагинации меняется | В карточном виде видны карточки этого набора; в табличном виде видны строки этого набора. |
| Массовые действия | Набор выбранных задач | Пользователь выбирает или снимает выбор задач | Пагинация не владеет выбранными задачами; выбранные задачи могут находиться на разных страницах. |

## 2. Интерфейсные состояния

| Состояние | Значение | Видимый результат |
|---|---|---|
| Размер страницы | 20 задач | Видимый набор текущей страницы содержит не больше 20 задач. |
| Пустой отобранный набор до пагинации | 0 задач | Пагинация скрыта; текущая страница равна 1; список задач показывает пустое состояние. |
| Короткий отобранный набор до пагинации | От 1 до 20 задач | Пагинация скрыта; текущая страница равна 1; список задач показывает все задачи отобранного набора. |
| Длинный отобранный набор до пагинации | 21 и больше задач | Пагинация видима; текущая страница находится в диапазоне от 1 до последней страницы. |
| Количество страниц | Отобранный набор до пагинации, разделенный на страницы по 20 задач с округлением вверх | Пагинация показывает номера доступных страниц по правилу видимых номеров. |
| Активный вид списка | Карточный или табличный | Текущая страница сохраняется при переключении вида; новый вид показывает видимый набор той же страницы. |

## 3. Правило разбиения задач на страницы

| Текущая страница | Какие задачи входят в видимый набор |
|---|---|
| 1 | Первые 20 задач отобранного набора до пагинации. |
| 2 | Задачи с 21-й по 40-ю в отобранном наборе до пагинации. |
| Страница N, где N больше 2 и меньше последней страницы | Задачи с позиции `(N - 1) * 20 + 1` по позицию `N * 20` в отобранном наборе до пагинации. |
| Последняя страница | Оставшиеся задачи отобранного набора до пагинации; количество задач находится в диапазоне от 1 до 20. |

Видимый набор текущей страницы сохраняет порядок задач из отобранного набора после сортировки.

## 4. Видимость и доступность элементов

| Условие | Состояние пагинации | Видимый результат |
|---|---|---|
| Отобранный набор до пагинации содержит от 0 до 20 задач | Панель скрыта | Под списком задач нет номеров страниц, кнопок навигации и разрывов `...`. |
| Отобранный набор до пагинации содержит 21 и больше задач | Панель видима | Под списком задач видны кнопки навигации, номера страниц и нужные разрывы `...`. |
| Текущая страница равна 1 | Кнопка навигации назад неактивна | Нажатие кнопки навигации назад не меняет текущую страницу и видимый набор списка. |
| Текущая страница больше 1 | Кнопка навигации назад активна | Нажатие кнопки навигации назад уменьшает текущую страницу на 1. |
| Текущая страница равна последней странице | Кнопка навигации вперед неактивна | Нажатие кнопки навигации вперед не меняет текущую страницу и видимый набор списка. |
| Текущая страница меньше последней страницы | Кнопка навигации вперед активна | Нажатие кнопки навигации вперед увеличивает текущую страницу на 1. |
| Номер страницы совпадает с текущей страницей | Номер активен | Номер показан как выбранный; повторное нажатие не меняет текущую страницу. |
| Номер страницы видим и не совпадает с текущей страницей | Номер доступен для выбора | Нажатие номера делает эту страницу текущей. |
| Между видимыми диапазонами есть скрытые страницы | Разрыв `...` видим | Разрыв остается текстовым элементом без перехода на страницу. |

## 5. Защита текущей страницы

| Условие | Состояние текущей страницы | Видимый результат |
|---|---|---|
| Отобранный набор до пагинации пуст | Текущая страница получает значение 1 | Пагинация скрыта; список задач показывает пустое состояние. |
| Текущая страница больше последней доступной страницы | Текущая страница получает значение последней доступной страницы | Список задач показывает видимый набор последней доступной страницы. |
| Текущая страница находится между 1 и последней страницей | Текущая страница остается без изменения | Список задач показывает видимый набор текущей страницы. |

## 6. Правило видимых номеров

| Количество страниц и текущая позиция | Видимые элементы пагинации |
|---|---|
| Всего 7 страниц или меньше | Все номера страниц без `...`; номер текущей страницы показан как активный. |
| Всего больше 7 страниц; текущая страница 1, 2 или 3 | `1`, `2`, `3`, `4`, `...`, последняя страница; номер текущей страницы показан как активный. |
| Всего больше 7 страниц; текущая страница в середине диапазона | `1`, `...`, предыдущая страница, текущая страница, следующая страница, `...`, последняя страница; текущая страница показана как активная. |
| Всего больше 7 страниц; текущая страница входит в последние 3 страницы | `1`, `...`, четвертая с конца страница, третья с конца страница, предпоследняя страница, последняя страница; номер текущей страницы показан как активный. |

## 7. Правила сброса и сохранения страницы

| Событие | Состояние текущей страницы | Видимый результат |
|---|---|---|
| Первичное открытие прототипа | 1 | Список задач показывает первую страницу отобранного набора до пагинации. |
| Выбор другой области задач | 1 | Список задач показывает первую страницу отобранного набора новой области. |
| Выбор другой очереди | 1 | Список задач показывает первую страницу отобранного набора активной очереди. |
| Изменение поисковой строки | 1 | Список задач показывает первую страницу результата поиска. |
| Применение фильтров | 1 | Список задач показывает первую страницу результата фильтрации. |
| Быстрый сброс фильтров | 1 | Список задач показывает первую страницу отобранного набора без активных фильтров. |
| Применение настроек колонок | 1 | Табличный список показывает первую страницу с примененным составом колонок. |
| Переключение карточного и табличного вида | Текущее значение остается без изменения | Новый вид показывает видимый набор той же страницы. |
| Выбор или снятие выбора задач | Текущее значение остается без изменения | Видимый набор текущей страницы остается на экране. |

## 8. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в пагинации | Результат в связанном компоненте |
|---|---|---|---|---|
| Список задач | Источник отобранного набора до пагинации | Изменилась область, очередь, поиск, фильтры или сортировка | Количество страниц и видимые номера пересчитываются по новому отобранному набору; текущая страница получает допустимое значение | Список задач показывает видимый набор текущей страницы. |
| Настройки колонок | Внешнее действие для табличного вида | Пользователь применяет настройки колонок | Текущая страница становится 1; количество страниц остается рассчитанным по отобранному набору до пагинации | Табличный список показывает первую страницу с примененным составом колонок. |
| Карточный список задач | Получатель текущей страницы | Активен карточный вид и текущая страница изменилась | Пагинация задает номер текущей страницы | Карточный список показывает карточки видимого набора текущей страницы. |
| Табличный список задач | Получатель текущей страницы | Активен табличный вид и текущая страница изменилась | Пагинация задает номер текущей страницы | Табличный список показывает строки видимого набора текущей страницы. |
| Чекбокс выбора всех строк таблицы | Получатель видимых строк текущей страницы | Активен табличный вид и текущая страница изменилась | Пагинация задает новый номер текущей страницы | Чекбокс получает пустое, выбранное или частичное состояние по строкам новой текущей страницы. |
| Массовые действия | Владелец набора выбранных задач | Есть выбранные задачи на других страницах | Переход на другую страницу сохраняет набор выбранных задач | Счетчик выбранных задач включает выбранные задачи с других страниц. |

## 9. Ограничения ответственности

| Область | Правило |
|---|---|
| Отобранный набор до пагинации | Пагинация не формирует отобранный набор задач; она получает количество и порядок задач от списка задач. |
| Карточки и строки списка задач | Пагинация не создает карточки, строки, колонки и ячейки; список задач показывает видимый набор текущей страницы. |
| Поиск и фильтры | Пагинация не изменяет поисковую строку и параметры фильтрации. |
| Левая навигация | Пагинация не изменяет выбранную область задач. |
| Очередь | Пагинация не изменяет активную очередь. |
| Настройки колонок | Пагинация не хранит и не применяет состав колонок; она только сбрасывает текущую страницу после применения настроек. |
| Массовые действия | Пагинация не очищает набор выбранных задач при смене страницы. |

# Пагинация: поведение

## 1. Основной пользовательский путь

1. Пользователь открывает рабочую область со списком задач.
2. Если отобранный набор до пагинации содержит 21 и больше задач, под списком видна панель пагинации; текущая страница равна 1.
3. Пользователь нажимает номер другой страницы.
4. Нажатый номер становится текущей страницей; список показывает видимый набор этой страницы.
5. Пользователь нажимает доступную кнопку навигации назад или вперед.
6. Текущая страница уменьшается или увеличивается на 1; список показывает видимый набор новой текущей страницы.

## 2. Переход по номеру страницы

| Действие пользователя | Условие | Итог пагинации | Итог списка задач |
|---|---|---|---|
| Нажатие номера другой страницы | Номер видим и не является текущей страницей | Нажатый номер становится активным номером текущей страницы. | Список показывает видимый набор выбранной страницы. |
| Нажатие активного номера страницы | Номер уже совпадает с текущей страницей | Активный номер не меняется. | Состав видимых задач не меняется. |
| Нажатие на `...` | Разрыв `...` видим между номерами | Текущая страница не меняется; `...` остается информационным элементом без перехода. | Состав видимых задач не меняется. |

## 3. Переход кнопками навигации

| Действие пользователя | Условие | Итог пагинации | Итог списка задач |
|---|---|---|---|
| Нажатие кнопки навигации назад | Текущая страница больше 1 | Активной становится предыдущая страница. | Список показывает видимый набор предыдущей страницы. |
| Нажатие кнопки навигации назад | Текущая страница равна 1 | Кнопка навигации назад неактивна; текущая страница остается 1. | Состав видимых задач не меняется. |
| Нажатие кнопки навигации вперед | Текущая страница меньше последней страницы | Активной становится следующая страница. | Список показывает видимый набор следующей страницы. |
| Нажатие кнопки навигации вперед | Текущая страница равна последней странице | Кнопка навигации вперед неактивна; текущая страница остается последней. | Состав видимых задач не меняется. |

## 4. Реакция на внешние изменения

| Внешнее действие | Итог пагинации | Итог списка задач |
|---|---|---|
| Пользователь выбирает другую область в левой навигации | Текущая страница становится 1. | Список показывает первую страницу новой области. |
| Пользователь выбирает другую очередь | Текущая страница становится 1. | Список показывает первую страницу активной очереди. |
| Пользователь вводит или очищает поисковую строку | Текущая страница становится 1. | Список показывает первую страницу результата поиска. |
| Пользователь нажимает `Применить` в панели фильтрации | Текущая страница становится 1. | Список показывает первую страницу результата фильтрации. |
| Пользователь выполняет быстрый сброс фильтров | Текущая страница становится 1. | Список показывает первую страницу без активных фильтров. |
| Пользователь применяет настройки колонок | Текущая страница становится 1. | Табличный список показывает первую страницу с примененным составом колонок. |
| Пользователь переключает карточный и табличный вид | Текущая страница не меняется. | Новый режим показывает видимый набор той же страницы. |

## 5. Пустой и короткий результат

| Ситуация | Итог пагинации | Итог списка задач |
|---|---|---|
| Отобранный набор до пагинации пуст | Пагинация скрыта; текущая страница равна 1. | Показано пустое состояние. |
| Отобранный набор до пагинации содержит от 1 до 20 задач | Пагинация скрыта; текущая страница равна 1. | Показаны все задачи отобранного набора. |
| Отобранный набор до пагинации содержит больше 20 задач | Пагинация видима. | Показан видимый набор текущей страницы: не больше 20 задач из отобранного набора до пагинации. |

## 6. Связь с выбором задач

| Действие пользователя | Итог выбора задач | Итог пагинации |
|---|---|---|
| Пользователь меняет страницу | Ранее выбранные задачи остаются выбранными. | Активной становится выбранная пользователем страница. |
| Пользователь выбирает или снимает выбор задачи чекбоксом | Набор выбранных задач получает эту задачу или теряет ее. | Текущая страница не меняется. |
| Пользователь выбирает все видимые строки таблицы | Выбранными становятся только строки текущей страницы. | Текущая страница не меняется. |

# Пагинация: структура интерфейса

## 1. Граница компонента

`Пагинация` — нижняя inline-зона навигации по страницам отобранного набора задач. Компонент находится в правой рабочей области под карточным или табличным списком задач.

| Объект интерфейса | Статус относительно пагинации | Структурное правило |
|---|---|---|
| Панель пагинации | Главный UI компонента | При отобранном наборе до пагинации от 21 задачи панель видна под списком задач и содержит кнопку навигации назад, номера страниц, возможные разрывы `...` и кнопку навигации вперед. |
| Кнопка навигации назад | Внутренний управляющий элемент | При видимой панели кнопка находится перед номерами страниц и показывает иконку стрелки назад. |
| Номер страницы | Внутренний управляющий элемент | При видимой панели каждый видимый номер показывает доступную страницу отобранного набора до пагинации. |
| Активный номер страницы | Внутреннее состояние номера | Когда номер совпадает с текущей страницей, этот номер показан как выбранный. |
| Разрыв `...` | Внутренний информационный элемент | Когда между видимыми номерами есть скрытые страницы, между диапазонами номеров виден текст `...` без действия перехода. |
| Кнопка навигации вперед | Внутренний управляющий элемент | При видимой панели кнопка находится после номеров страниц и показывает иконку стрелки вперед. |
| Список задач | Соседний компонент выше | Список задач задает отобранный набор до пагинации и получает текущую страницу; карточки и строки списка не входят в пагинацию. |

Пагинация не формирует отобранный набор задач, не меняет фильтры, поиск, очередь, выбранную область левой навигации, режим отображения и набор выбранных задач.

## 2. Визуальный эталон

Визуальный эталон для `Пагинации` не обязателен: компонент имеет одну горизонтальную inline-зону и не содержит drawer, modal, overlay или плавающую панель.

Если эталон потребуется для проверки нижнего расположения относительно списка задач, использовать зарезервированный путь `assets/pagination-visible.png`. Пока изображение не добавлено в папку компонента, путь считается зарезервированным, а не готовой ссылкой.

## 3. Пространственный контракт

| Зона | Область и привязка | Слой интерфейса | Условие видимости | Владелец состояния | Влияние на соседние области | Состав и исключения |
|---|---|---|---|---|---|---|
| Видимая панель пагинации | Правая рабочая область, отдельная нижняя строка после карточного или табличного списка задач | Inline | Отобранный набор до пагинации содержит 21 и больше задач | Пагинация определяет видимость панели и количество страниц по количеству задач, полученному от списка задач | Панель занимает место после списка; не перекрывает карточки, строки таблицы, левую навигацию, панель инструментов, очередь и панель настроек колонок | Входят: кнопка навигации назад, номера страниц, разрывы `...`, кнопка навигации вперед. Не входят: карточки задач, строки таблицы, чекбоксы выбора строк, массовые действия. |
| Скрытое состояние пагинации | Нижняя область после списка задач не занята элементами пагинации | Inline | Отобранный набор до пагинации содержит от 0 до 20 задач | Пагинация скрывает панель по количеству задач, полученному от списка задач | Под списком нет отдельной панели пагинации; пустое или короткое состояние остается состоянием списка задач | Видимые элементы пагинации отсутствуют. |
| Кнопки навигации | Края видимой панели: назад перед номерами, вперед после номеров | Inline | Панель пагинации видима | Пагинация определяет доступность кнопок по текущей странице и последней странице | Кнопки не меняют расположение номеров страниц и не сдвигают соседний список задач | Входят: кнопка навигации назад, кнопка навигации вперед. Не входят: номера страниц и разрывы. |
| Номера страниц | Центральная часть панели между кнопками навигации | Inline | Панель пагинации видима | Пагинация определяет активный номер и видимый диапазон номеров по текущей странице и количеству страниц | Номера не добавляют счетчик общего количества задач и не меняют состав карточки или строки списка задач | Входят: активный номер текущей страницы, номера доступных страниц, разрывы `...`. Не входит: счетчик общего количества задач. |

Панель пагинации не является fixed, sticky, drawer, modal, overlay или плавающей панелью.

## 4. Состав панели

| Элемент | Условие показа | Позиция внутри панели | Видимый состав |
|---|---|---|---|
| Кнопка навигации назад | Панель пагинации видима | Перед номерами страниц | Кнопка с иконкой стрелки назад. |
| Номер страницы | Панель пагинации видима и страница входит в видимый диапазон номеров | Между кнопками навигации | Число страницы. |
| Активный номер страницы | Номер страницы совпадает с текущей страницей | Между кнопками навигации | Число текущей страницы в выбранном состоянии. |
| Разрыв `...` | Между видимыми диапазонами номеров есть скрытые страницы | Между видимыми номерами страниц | Текст `...` без действия перехода. |
| Кнопка навигации вперед | Панель пагинации видима | После номеров страниц | Кнопка с иконкой стрелки вперед. |

## 5. Соседние области и исключения

| Соседняя область | Тип связи | Граница ответственности |
|---|---|---|
| Карточный список задач | Получает текущую страницу при активном карточном виде | Пагинация задает номер текущей страницы; состав карточек и их состояния остаются ответственностью списка задач. |
| Табличный список задач | Получает текущую страницу при активном табличном виде | Пагинация задает номер текущей страницы; состав строк, колонок и ячеек остается ответственностью табличного списка. |
| Чекбокс выбора всех строк таблицы | Использует видимые строки текущей страницы | Чекбокс не входит в пагинацию; его состояние рассчитывается в табличном списке по строкам текущей страницы. |
| Массовые действия | Используют набор выбранных задач | Пагинация не входит в массовые действия и не очищает выбранные задачи при смене страницы. |

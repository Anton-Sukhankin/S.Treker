# Выбор пакетов документов: структура

## 1. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Дерево выбора пакетов | Часть компонента | Показывает иерархию пакетов и выбранные целевые пакеты для действия `Добавить в пакет`. |
| Строка пакета | Часть компонента | Показывает чекбокс-индикатор, иконку папки, название пакета и состояние выбранности. |
| Вложенные строки пакетов | Часть компонента | Показываются под родительской строкой после раскрытия ветки. |
| Модальное окно `Добавить в пакет` | Родительская область | Содержит дерево выбора пакетов в основной области окна. |
| Кнопка `Применить` | Внешний получатель состояния | Доступна, если в дереве выбран минимум один пакет. |
| Плавающая панель массовых действий документов | Внешняя точка входа | Открывает родительское модальное окно с деревом выбора пакетов. |
| Таблица документов | Получатель результата родительского действия | После применения выбранные документы получают выбранные пакеты. |

## 3. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Слой интерфейса | Состав | Что не входит |
|---|---|---|---|---|---|---|
| Дерево выбора пакетов | Основная область модального окна `Добавить в пакет`, между хедером и футером | Хедер модального окна сверху; футер с действиями снизу | Модальное окно открыто | Inline внутри modal layer | Вертикальный список строк пакетов | Счетчик выбранных документов, кнопки `Отмена` и `Применить`, плавающая панель. |
| Строка пакета верхнего уровня | В списке дерева | Следующая строка пакета ниже | Дерево видимо | Inline | Чекбокс-индикатор, иконка папки, название пакета | Строка документа и чекбокс выбора документа. |
| Дочерняя группа пакетов | Под раскрытой родительской строкой | Родительская строка выше; соседние ветки дерева ниже | Пользователь раскрывает родительскую ветку | Inline | Вложенные строки пакетов, визуальная линия иерархии | Выбор документов и результат добавления в пакет. |
| Чекбокс-индикатор пакета | Левая часть строки пакета | Иконка папки и название справа | Строка пакета видима | Inline | Пустое или выбранное состояние | Чекбокс строки таблицы документов. |
| Иконка папки | Перед названием пакета | Чекбокс-индикатор слева; название справа | Строка пакета видима | Inline | Иконка закрытой, открываемой или раскрытой папки | Кнопка действия массовой панели. |

## 4. Состав строки пакета

| Элемент | Положение | Условие показа | Видимое состояние |
|---|---|---|---|
| Чекбокс-индикатор | Левая часть строки | Строка пакета видима | Пустой, если пакет не выбран; выбранный, если пакет входит в целевой набор. |
| Иконка папки | Между чекбоксом и названием | Строка пакета видима | Для пакета с дочерними узлами показывает состояние раскрытия; для конечного пакета показывает обычную папку. |
| Название пакета | Правая часть строки | Строка пакета видима | Показывает наименование пакета. |
| Визуальная линия иерархии | Перед дочерней строкой | Дочерняя строка видима | Показывает вложенность дочернего пакета относительно родительского. |

## 5. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `document-bulk-actions` | Родительский компонент | Дерево расположено внутри модального окна `Добавить в пакет`. | `document-bulk-actions/01-structure.md`, `document-bulk-actions/02-behavior.md`, `document-bulk-actions/03-data-states-rules.md`. |
| `documents-list` | Получатель результата | Таблица документов не входит в компонент выбора пакетов. | `documents-list/03-data-states-rules.md`, `document-bulk-actions/03-data-states-rules.md`. |

## 6. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Дерево выбора пакетов | Tree / tree select | Показывает иерархию пакетов внутри модального окна и хранит выбранный целевой набор пакетов. | Заполняется после утверждения DS-карты. |
| Строка пакета | Tree item | Показывает название пакета, состояние раскрытия и выбранность пакета. | Заполняется после утверждения DS-карты. |
| Чекбокс-индикатор пакета | Checkbox | Выбранное состояние строки добавляет пакет в целевой набор для действия `Добавить в пакет`. | Заполняется после утверждения DS-карты. |
| Кнопка `Применить` родительского окна | Button | Кнопка доступна только при выборе минимум одного пакета. | Заполняется после утверждения DS-карты. |

# Выбор пакетов документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Дерево выбора пакетов | Выбранные целевые пакеты | Строки выбранных пакетов показывают выбранное состояние. |
| Дерево выбора пакетов | Раскрытые ветки дерева | Дочерние строки видимы только внутри раскрытых веток. |
| `document-bulk-actions` | Доступность кнопки `Применить` | Кнопка доступна, если дерево содержит минимум один выбранный пакет. |
| `document-bulk-actions` | Выбранный набор документов | Счетчик модального окна показывает количество документов, к которым будет применен выбранный пакет. |
| `documents-list` | Пакеты документа | После применения выбранные документы получают выбранные пакеты. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Дерево открыто без выбранного пакета | Пользователь открыл модальное окно `Добавить в пакет` | Все строки пакетов не выбраны; кнопка `Применить` недоступна. | Пользователь выбирает пакет или закрывает модальное окно. |
| Пакет выбран | Пользователь выбирает строку пакета | Строка пакета показывает выбранное состояние; кнопка `Применить` доступна. | Пользователь снимает выбор с этого пакета или закрывает модальное окно. |
| Несколько пакетов выбраны | Пользователь выбирает больше одного пакета | Каждая выбранная строка показывает выбранное состояние; кнопка `Применить` доступна. | Пользователь снимает выбор со всех пакетов или закрывает модальное окно. |
| Ветка раскрыта | Пользователь выбирает иконку папки у пакета с дочерними узлами | Под родительской строкой видимы дочерние строки пакетов. | Пользователь повторно выбирает иконку папки этой ветки. |
| Модальное окно закрыто | Пользователь применяет действие, нажимает `Отмена` или закрывает окно | Дерево не видно. | Следующее открытие модального окна начинает выбор пакетов с пустого целевого набора. |

## 3. Счетчики, видимость и применимость

| Элемент или значение | Условие | Видимый результат |
|---|---|---|
| Кнопка `Применить` | Выбран минимум один пакет | Кнопка доступна. |
| Кнопка `Применить` | Выбранных пакетов нет | Кнопка недоступна. |
| Дочерние строки пакета | Родительская ветка раскрыта | Дочерние строки видимы под родительской строкой. |
| Дочерние строки пакета | Родительская ветка закрыта | Дочерние строки не видны. |

## 4. Правила данных

| Данные или значение | Источник для интерфейса | Где используется | Видимый результат |
|---|---|---|---|
| Иерархия пакетов | Дерево пакетов раздела поиска | Дерево выбора пакетов | Пользователь видит пакеты верхнего уровня и дочерние пакеты после раскрытия ветки. |
| Выбранные пакеты | Выбор строк пакетов в дереве | Массовое действие `Добавить в пакет` | После применения выбранные документы получают выбранные пакеты. |
| Названия выбранных пакетов | Строки выбранных пакетов | Toast после применения | Toast показывает названия пакетов в тексте подтверждения. |
| Количество выбранных документов | Выбранный набор из таблицы документов | Хедер модального окна | Счетчик модального окна показывает количество документов. |

## 5. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `document-bulk-actions` | Родитель модального окна и действия применения | Пользователь выбирает `Добавить в пакет` | Дерево открыто с пустым целевым набором. | Модальное окно открыто; счетчик показывает количество выбранных документов. |
| `document-bulk-actions` | Получатель выбранных пакетов | Пользователь выбирает или снимает выбор пакета | Дерево показывает актуальный целевой набор. | Кнопка `Применить` получает доступное или недоступное состояние. |
| `documents-list` | Получатель результата применения | Пользователь нажимает `Применить` при выбранном пакете | Дерево закрыто вместе с модальным окном. | Выбранные документы получают выбранные пакеты. |
| Toast | Получатель результата применения | Добавление в пакет завершено | Дерево закрыто. | Toast показывает подтверждение с количеством документов и названиями пакетов. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Таблица документов | Компонент выбора пакетов не выбирает документы и не снимает выбор документов. |
| Плавающая панель массовых действий | Компонент выбора пакетов не открывает плавающую панель и не меняет состав ее кнопок. |
| Модальное окно | Компонент выбора пакетов не владеет хедером, футером, кнопками `Отмена`, `Применить` и закрытием окна. |
| Пакеты документов | Компонент выбора пакетов не создает новые пакеты и не удаляет пакеты. |
| Фильтры поиска | Компонент выбора пакетов не меняет выбранные пакеты в фильтре `Поиск в пакете`. |

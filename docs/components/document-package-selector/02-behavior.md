# Выбор пакетов документов: поведение

## 1. Основной пользовательский путь

1. Пользователь выбирает `Добавить в пакет` на плавающей панели массовых действий документов.
2. Интерфейс открывает модальное окно `Добавить в пакет`.
3. Пользователь выбирает один или несколько пакетов в дереве.
4. Кнопка `Применить` становится доступной.
5. Пользователь нажимает `Применить`.
6. Модальное окно закрывается; выбранные документы получают выбранные пакеты; toast показывает подтверждение.

## 2. Таблица основного пути

| Шаг | Действие пользователя | Исходное состояние | Результат в интерфейсе |
|---:|---|---|---|
| 1 | Клик по `Добавить в пакет` | В таблице документов выбран минимум один документ | Модальное окно `Добавить в пакет` открыто; дерево пакетов видимо; кнопка `Применить` недоступна. |
| 2 | Клик по строке пакета вне иконки папки | Модальное окно открыто; пакет не выбран | Строка пакета получает выбранное состояние; кнопка `Применить` доступна. |
| 3 | Повторный клик по выбранной строке пакета вне иконки папки | Пакет выбран | Строка пакета получает невыбранное состояние; если других выбранных пакетов нет, кнопка `Применить` недоступна. |
| 4 | Клик по иконке папки у пакета с дочерними узлами | Ветка закрыта | Под родительской строкой показаны дочерние строки пакетов. |
| 5 | Клик по иконке папки у раскрытой ветки | Дочерние строки видимы | Дочерние строки скрыты; выбранное состояние пакетов внутри ветки сохраняется. |
| 6 | Клик по `Применить` | Выбран минимум один пакет | Модальное окно закрыто; родительское массовое действие применяет выбранные пакеты к выбранным документам. |
| 7 | Клик по `Отмена` или кнопке закрытия модального окна | Модальное окно открыто | Модальное окно закрыто; выбранный набор документов в таблице сохраняется. |

## 3. Короткие внешние результаты

| Действие в текущем компоненте | Компонент-получатель | Видимый результат |
|---|---|---|
| Выбор первого пакета | `document-bulk-actions` | Кнопка `Применить` в футере модального окна становится доступной. |
| Снятие выбора с последнего пакета | `document-bulk-actions` | Кнопка `Применить` в футере модального окна становится недоступной. |
| `Применить` при выбранном пакете | `documents-list` | Выбранные документы сохраняют выбранное состояние и получают выбранные пакеты. |
| `Применить` при выбранном пакете | Toast | Toast показывает количество обработанных документов и названия выбранных пакетов. |

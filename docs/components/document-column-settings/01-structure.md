# Настройки колонок документов: структура

## 1. Расположение

| Условие | Область интерфейса | Видимый результат |
|---|---|---|
| Активен раздел `Поиск` | Правая часть рабочей области поиска документов, поверх таблицы документов | Правая панель `Настройки` открывается после выбора кнопки `Настройки таблицы` в заголовке результатов поиска. |
| Активен раздел `Задачи` | Рабочая область задач S-Tracker | Настройки колонок документов скрыты вместе с рабочей областью поиска. |

## 2. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Правая панель `Настройки` | Главный UI компонента | Показывает черновик колонок документов, библиотеку дополнительных атрибутов, пресеты вида, действия `По умолчанию` и `Применить`. |
| Хедер панели | Часть компонента | Показывает заголовок `Настройки` и кнопку закрытия. |
| Область `Общие атрибуты` | Часть компонента | Показывает селект текущего вида, кнопку `Сохранить` и список колонок черновика. |
| Область `Библиотека атрибутов` | Часть компонента | Показывает поиск по библиотеке и список дополнительных атрибутов документов. |
| Футер панели | Часть компонента | Показывает кнопку раскрытия библиотеки, `По умолчанию`, `Применить`. |
| Модальное окно `Сохранение шаблона` | Часть компонента | Открывается из кнопки `Сохранить` и создает пользовательский пресет вида колонок. |
| Кнопка `Настройки таблицы` | Внешняя точка входа | Находится в заголовке результатов поиска; при выборе открывает панель `Настройки`. |
| Таблица документов | Внешний получатель результата | После `Применить` получает состав, порядок и закрепление колонок. |
| Фильтры поиска документов | Внешнее условие | Задают набор документов; настройки колонок документов не меняют значения фильтров. |
| Шаблоны поиска документов | Соседний компонент без общего состояния | Не являются пресетами вида колонок и не меняют черновик колонок. |

## 4. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Слой интерфейса | Состав | Что не входит |
|---|---|---|---|---|---|---|
| Правая панель `Настройки` | Правая сторона рабочей области поиска документов | Таблица документов остается под затемненным слоем | Пользователь выбирает `Настройки таблицы` | Drawer поверх рабочей области поиска | Хедер, тело панели, футер | Левая панель фильтров, таблица документов, заголовок результатов поиска. |
| Затемненный слой | Между рабочей областью поиска и правой панелью | Правая панель находится выше слоя | Панель `Настройки` открыта | Overlay | Затемнение внешней рабочей области | Состав колонок, фильтры, строки таблицы. |
| Хедер панели | Верхняя строка drawer | Тело панели ниже | Панель `Настройки` открыта | Внутри drawer | Заголовок `Настройки`, кнопка закрытия | Кнопка открытия панели в заголовке результатов поиска. |
| Тело панели | Между хедером и футером | Хедер сверху, футер снизу | Панель `Настройки` открыта | Внутри drawer | `Общие атрибуты`; при раскрытой библиотеке также `Библиотека атрибутов` слева | Таблица документов и пагинация. |
| `Общие атрибуты` | Правая рабочая область тела панели; единственная рабочая область при закрытой библиотеке | `Библиотека атрибутов` слева только в раскрытом состоянии | Панель `Настройки` открыта | Внутри drawer | Заголовок, селект текущего вида, кнопка `Сохранить`, список колонок черновика | Поиск по библиотеке. |
| `Библиотека атрибутов` | Левая рабочая область тела панели | `Общие атрибуты` справа | Пользователь выбирает кнопку библиотеки в футере | Внутри drawer | Заголовок, поле поиска, список дополнительных атрибутов | Селект текущего вида и список колонок черновика. |
| Футер панели | Нижняя строка drawer | Тело панели сверху | Панель `Настройки` открыта | Внутри drawer | Кнопка библиотеки слева; `По умолчанию` и `Применить` справа | Список колонок, список атрибутов, модальное окно сохранения. |
| Модальное окно `Сохранение шаблона` | Центр видимой области поверх рабочей области поиска | Правая панель и таблица остаются под overlay | Пользователь выбирает доступную кнопку `Сохранить` | Modal поверх overlay | Хедер, поле имени шаблона, кнопки `Отмена` и `Сохранить` | Список сохраненных шаблонов поиска документов. |

## 5. Состояния компоновки панели

| Состояние | Видимые зоны | Отсутствующие зоны | Владелец состояния |
|---|---|---|---|
| Панель закрыта | Рабочая область поиска документов | Правая панель `Настройки`, overlay, модальное окно сохранения | Компонент настроек колонок документов. |
| Панель открыта, библиотека закрыта | Правая панель, `Общие атрибуты`, футер | `Библиотека атрибутов`, модальное окно сохранения | Компонент настроек колонок документов. |
| Панель открыта, библиотека открыта | Правая панель, `Библиотека атрибутов`, `Общие атрибуты`, футер | Модальное окно сохранения | Компонент настроек колонок документов. |
| Модальное окно сохранения открыто | Overlay и модальное окно `Сохранение шаблона` | Таблица документов недоступна для прямого действия под модальным слоем | Компонент настроек колонок документов. |

## 6. Состав области `Общие атрибуты`

| Элемент | Расположение | Условие видимости | Видимый состав |
|---|---|---|---|
| Заголовок `Общие атрибуты` | Верх области | Панель открыта | Текстовый заголовок области. |
| Селект текущего вида | Под заголовком, слева в строке пресета | Панель открыта | Значение `Базовое отображение` или название сохраненного вида, иконка раскрытия. |
| Кнопка `Сохранить` | В строке пресета справа от селекта | Панель открыта | Кнопка доступна только после изменения черновика относительно базового набора или выбранного вида. |
| Список колонок | Под строкой пресета | Панель открыта | Строки колонок черновика в текущем порядке. |

## 7. Строка колонки

| Элемент строки | Расположение в строке | Условие видимости | Видимый результат |
|---|---|---|---|
| Индикатор видимости | Левая часть строки | Строка находится в `Общие атрибуты` | Показывает включенную или выключенную колонку черновика. |
| Название колонки | После индикатора видимости | Строка находится в `Общие атрибуты` | Показывает пользовательское название колонки документа. |
| Кнопка возврата в библиотеку | Справа от названия перед закреплением | Колонка добавлена из библиотеки | Возвращает колонку в список `Библиотека атрибутов`. |
| Кнопка закрепления | Правая часть строки перед ручкой порядка | Строка находится в `Общие атрибуты` | Включает или снимает закрепление колонки в таблице после `Применить`. |
| Ручка изменения порядка | Крайняя правая часть строки | Строка находится в `Общие атрибуты` | Позволяет изменить порядок колонки в черновике. |

## 8. Состав области `Библиотека атрибутов`

| Элемент | Расположение | Условие видимости | Видимый состав |
|---|---|---|---|
| Заголовок `Библиотека атрибутов` | Верх левой области | Библиотека открыта | Текстовый заголовок области. |
| Поле поиска | Под заголовком библиотеки | Библиотека открыта | Поле `Введите значение`. |
| Список дополнительных атрибутов | Под полем поиска | Библиотека открыта | Строки атрибутов документов, которые не находятся в `Общие атрибуты`. |
| Кнопка добавления атрибута | Правая часть строки библиотеки | Атрибут находится в библиотеке | Переносит атрибут в `Общие атрибуты`. |

## 9. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `search-workspace` | Родительская рабочая область | Панель открывается поверх правой части поиска документов. | `search-workspace/01-structure.md`, `search-workspace/03-data-states-rules.md`. |
| `documents-list` | Получатель результата | Таблица документов показывает примененный состав, порядок и закрепление колонок. | `documents-list/01-structure.md`, `documents-list/03-data-states-rules.md`. |
| `search-filters` | Соседний компонент | Фильтры меняют набор документов, но не меняют черновик колонок. | `search-filters/03-data-states-rules.md`. |
| `search-filter-templates` | Соседний компонент | Шаблоны поиска не являются пресетами вида колонок. | `search-filter-templates/03-data-states-rules.md`. |

## 10. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Правая панель `Настройки` | Drawer | Кнопка `Настройки таблицы` открывает правую панель черновика колонок документов. | Заполняется после утверждения DS-карты. |
| `Общие атрибуты` | Column list / settings panel | Показывает текущий вид, кнопку сохранения и строки колонок черновика. | Заполняется после утверждения DS-карты. |
| Строка колонки | List item | Показывает видимость, название, возврат в библиотеку при добавленном атрибуте, закрепление и порядок. | Заполняется после утверждения DS-карты. |
| `Библиотека атрибутов` | Attribute library panel | Раскрытое состояние панели показывает поиск и список дополнительных атрибутов документов. | Заполняется после утверждения DS-карты. |
| Футер панели | Button group | Кнопка библиотеки переключает состав тела панели; `По умолчанию` сбрасывает черновик; `Применить` передает конфигурацию в таблицу документов. | Заполняется после утверждения DS-карты. |
| Модальное окно `Сохранение шаблона` | Modal | Доступная кнопка `Сохранить` открывает окно сохранения пользовательского вида колонок. | Заполняется после утверждения DS-карты. |

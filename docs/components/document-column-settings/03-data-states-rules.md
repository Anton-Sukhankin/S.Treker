# Настройки колонок документов: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| Настройки колонок документов | Открытие панели | При открытом состоянии справа виден drawer `Настройки` и overlay; при закрытом состоянии оба слоя скрыты. |
| Настройки колонок документов | Черновик колонок | Панель показывает состав, порядок, видимость и закрепление колонок до применения. |
| Настройки колонок документов | Примененное состояние колонок | Таблица документов показывает только примененный состав, порядок и закрепление колонок. |
| Настройки колонок документов | Состояние библиотеки | При закрытой библиотеке видна только область `Общие атрибуты`; при открытой библиотеке слева видна область `Библиотека атрибутов`. |
| Настройки колонок документов | Список сохраненных видов | Селект текущего вида показывает `Базовое отображение` и созданные пользователем виды текущей страницы. |
| Настройки колонок документов | Модальное окно сохранения вида | Overlay и модальное окно видны после выбора доступной кнопки `Сохранить`. |
| Таблица документов | Итоговый набор колонок | Заголовок и строки таблицы получают примененный набор после `Применить`. |

## 2. Состав базового отображения

| Значение | Состав |
|---|---|
| Базовые колонки документов | `Дата документа`, `Номер`, `Наименование`, `Изменение`, `Тип`. |
| Дополнительные атрибуты библиотеки | `Код ДО`, `Вид документа (справочник)`, `Расторгнут`, `Размер аванса (строка)`, `Основной договор не найден`, `Название файла`, `Номер раздела`, `Название раздела`, `Номер пункта`, `Текст пункта`, `Банк`, `Отслеживаемость`, `Группа ковенантов`, `Код группы ковенантов`, `Ковенант`, `Код ковенанта`, `Код тега`, `Триггер`, `ИНН Банка`, `ИНН Организации`. |
| Постоянные ячейки таблицы | Чекбокс выбора строки и ячейка меню строки не входят в черновик колонок. |

## 3. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Панель закрыта | Пользователь не открывал настройки или закрыл панель | Drawer и overlay скрыты; таблица показывает примененное состояние колонок. | Пользователь выбирает `Настройки таблицы`. |
| Панель открыта | Пользователь выбирает `Настройки таблицы` | Drawer `Настройки` открыт; черновик показывает текущий набор колонок. | Пользователь закрывает панель или выбирает `Применить`. |
| Библиотека открыта | Пользователь выбирает кнопку библиотеки в футере | Слева видна область `Библиотека атрибутов`; справа видна область `Общие атрибуты`. | Пользователь повторно выбирает кнопку библиотеки или закрывает панель. |
| Черновик изменен | Пользователь меняет видимость, порядок, закрепление или добавляет атрибут | Кнопка `Сохранить` в области `Общие атрибуты` становится доступной. | Пользователь сохраняет вид, выбирает другой вид, выбирает `По умолчанию`, закрывает панель или применяет черновик. |
| Модальное окно сохранения открыто | Пользователь выбирает доступную кнопку `Сохранить` | Видно поле имени шаблона и кнопки `Отмена`, `Сохранить`. | Пользователь сохраняет вид, выбирает `Отмена` или закрывает окно. |
| Сохраненный вид выбран | Пользователь выбирает вид в селекте | Черновик получает состав, порядок и закрепление выбранного вида; селект показывает название вида. | Пользователь выбирает другой вид, удаляет активный вид или выбирает `По умолчанию`. |

## 4. Правила одной колонки

| Свойство | Правило |
|---|---|
| Колонка документа | Строка в `Общие атрибуты` показывает название колонки, которую пользователь настраивает для таблицы документов. |
| Видимость | Активная строка попадает в таблицу после `Применить`; неактивная строка не попадает в таблицу после `Применить`. |
| Порядок | Порядок строк в `Общие атрибуты` задает порядок настраиваемых колонок таблицы после `Применить`. |
| Закрепление | Закрепленная строка попадает в закрепленную группу настраиваемых колонок после `Применить`. |
| Принадлежность библиотеке | Атрибут, добавленный из библиотеки, имеет кнопку возврата и может быть возвращен в библиотеку до применения. |

## 5. Правила сохраненного вида

| Значение вида | Источник | Правило сохранения | Правило применения |
|---|---|---|---|
| Название | Поле модального окна `Сохранение шаблона` | Сохраняется непустое уникальное значение. | Показывается в селекте текущего вида. |
| Состав активных колонок | Черновик `Общие атрибуты` | Сохраняются активные строки черновика. | Активные строки выбранного вида становятся черновиком панели. |
| Закрепленные колонки | Кнопки закрепления строк | Сохраняется набор закрепленных колонок. | Закрепление выбранного вида переносится в черновик панели. |
| Порядок колонок | Порядок строк в панели | Сохраняется порядок строк на момент сохранения. | Черновик получает сохраненный порядок строк. |

После перезагрузки страницы селект вида показывает `Базовое отображение`; пользовательские виды текущей страницы больше не видны.

## 6. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в настройках колонок | Результат в связанном компоненте |
|---|---|---|---|---|
| `search-workspace` | Родительская область | Активен раздел `Поиск` | Кнопка `Настройки таблицы` доступна в заголовке результатов поиска. | Рабочая область поиска остается открытой под overlay при раскрытии панели. |
| `documents-list` | Получатель примененного состояния | Пользователь выбирает `Применить` | Черновик становится примененным состоянием; панель закрывается. | Таблица показывает примененный состав, порядок и закрепление колонок. |
| `documents-list` | Источник постоянных ячеек | Таблица документов видна | Настройки не получают чекбокс строки и ячейку меню строки в черновик. | Чекбокс строки и меню строки остаются видимыми независимо от настроек колонок. |
| `search-filters` | Соседний источник набора документов | Пользователь меняет фильтры до или после настройки колонок | Черновик и сохраненные виды не меняются. | Таблица показывает документы по фильтрам и примененному набору колонок. |
| `search-filter-templates` | Соседний компонент | Пользователь сохраняет или применяет шаблон поиска | Список видов колонок не меняется. | Шаблон поиска меняет значения фильтров, но не состав колонок. |

## 7. Ограничения ответственности

| Область | Правило |
|---|---|
| Данные документов | Настройки колонок документов не изменяют значения документов. |
| Фильтры поиска | Настройки колонок документов не меняют значения фильтров, выбранные пакеты, типы документов и атрибутные фильтры. |
| Шаблоны поиска | Сохраненный вид колонок не является шаблоном поиска документов. |
| Выбор документов | Настройки колонок документов не выбирают строки и не снимают выбор строк. |
| Массовые действия | Настройки колонок документов не показывают и не скрывают плавающую панель массовых действий. |
| Связи документов | Настройки колонок документов не открывают дровер связей и не меняют связанные документы. |
| Пагинация | Настройки колонок документов не меняют текущую страницу выдачи. |

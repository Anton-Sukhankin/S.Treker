# Дровер связей документа: структура

## 1. Граница компонента

| Объект интерфейса | Тип связи | Правило для текущей спецификации |
|---|---|---|
| Правый дровер `Связи документа` | Часть компонента | Показывает набор документов, связанных с выбранным документом или выбранным набором документов. |
| Затемненный слой | Часть компонента | Перекрывает рабочую область поиска при открытом дровере. |
| Хедер дровера | Часть компонента | Показывает название, контекст источника связей, иконку состояния или кнопку возврата, кнопку закрытия. |
| Таблица связей | Часть компонента | Показывает связанные документы, чекбоксы строк, сортируемые колонки и меню строки. |
| Меню строки таблицы связей | Часть компонента | Показывает действия над документом в строке связей. |
| Таблица документов | Внешняя точка входа | Меню строки передает один документ для открытия дровера. |
| Плавающая панель массовых действий документов | Внешняя точка входа | Действие `Связи документа` передает выбранный набор документов для открытия дровера. |
| Toast | Внешний получатель результата | Показывает подтверждение после пометки или снятия пометки на удаление. |

## 3. Пространственный контракт

| Зона | Расположение | Соседняя область | Условие видимости | Слой интерфейса | Состав | Что не входит |
|---|---|---|---|---|---|---|
| Затемненный слой | Поверх всей рабочей области поиска | Правый дровер расположен поверх слоя справа | Дровер открыт | Overlay | Полупрозрачное затемнение | Таблица документов, левая панель поиска. |
| Правый дровер | Правая часть окна поверх рабочей области поиска | Слева остается затемненная рабочая область поиска | Пользователь выбирает действие `Связи документа` | Drawer | Хедер, тело с таблицей связей | Плавающая панель массовых действий, таблица документов. |
| Хедер дровера | Верхняя часть дровера | Тело дровера ниже | Дровер открыт | Inline внутри drawer | Иконка состояния или кнопка возврата, заголовок `Связи документа`, подзаголовок источника, кнопка закрытия | Строки таблицы связей. |
| Тело дровера | Между хедером и нижней границей дровера | Хедер выше | Дровер открыт | Inline внутри drawer | Контейнер таблицы связей | Футер отсутствует. |
| Таблица связей | Внутри тела дровера | Не перекрывает хедер | Дровер открыт | Inline внутри drawer | Заголовок таблицы, строки документов, чекбоксы, меню строки | Пагинация документов, фильтры поиска. |
| Меню строки таблицы связей | Поверх таблицы связей рядом с кнопкой меню строки | Строки таблицы остаются под меню | Пользователь открывает меню строки связанного документа | Floating menu | Пункты действий строки, включая `Связи документа` и пометку на удаление | Массовая панель документов. |

## 4. Состав хедера

| Элемент | Положение | Условие показа | Видимый результат |
|---|---|---|---|
| Иконка документа или связей | Левая часть хедера | Дровер открыт на первом уровне | Видна иконка источника связей. |
| Кнопка возврата | Левая часть хедера вместо иконки | Пользователь открыл связи документа из таблицы связей | Видна кнопка возврата к предыдущему набору связей. |
| Заголовок | Центральная часть хедера | Дровер открыт | Текст `Связи документа`. |
| Подзаголовок | Под заголовком | Дровер открыт | Показывает документ-источник или количество выбранных документов и их наименования. |
| Кнопка закрытия | Правая часть хедера | Дровер открыт | Закрывает дровер и overlay. |

## 5. Состав таблицы связей

| Элемент | Положение | Условие показа | Видимый результат |
|---|---|---|---|
| Чекбокс заголовка | Первая ячейка заголовка | Дровер открыт | Выбирает или снимает выбор со строк текущей таблицы связей. |
| Колонки связанного документа | Заголовок и строки таблицы | Дровер открыт | Показывают дату документа, номер, наименование, дату изменения и тип. |
| Сортируемый заголовок | В колонках `Дата`, `Номер`, `Наименование`, `Изменено` | Дровер открыт | Заголовок принимает направление сортировки после выбора. |
| Чекбокс строки | Первая ячейка строки | Строка связанного документа видна | Выбирает строку внутри дровера. |
| Меню строки | Правая ячейка строки | Строка связанного документа видна | Открывает floating-меню действий строки. |
| Пустое состояние | Единственная строка тела таблицы | У выбранного источника нет связанных документов | Видна строка `Связи документа не найдены`. |

## 6. Внешние связи на уровне структуры

| Связанный компонент | Тип связи | Что фиксирует `01` | Где находится полное правило |
|---|---|---|---|
| `documents-list` | Внешняя точка входа | Меню строки открывает дровер для одного документа. | `documents-list/02-behavior.md`, `documents-list/03-data-states-rules.md`. |
| `document-bulk-actions` | Внешняя точка входа | Кнопка `Связи документа` открывает дровер для выбранного набора. | `document-bulk-actions/02-behavior.md`, `document-bulk-actions/03-data-states-rules.md`. |
| `documents-list` | Получатель результата | Пометка на удаление из дровера меняет видимое состояние соответствующего документа в таблице документов. | `documents-list/03-data-states-rules.md`. |
| Toast | Получатель результата | Пометка или снятие пометки показывает подтверждение. | `document-relations-drawer/03-data-states-rules.md`. |

## 7. Точки будущей DS-binding привязки

| Зона спецификации | Тип UI-элемента | Продуктовое правило S-Tracker | Будущее имя DS-компонента |
|---|---|---|---|
| Затемненный слой | Overlay | Открытый дровер виден поверх рабочей области поиска; затемненная область под ним недоступна для прямого действия. | Заполняется после утверждения DS-карты. |
| Правый дровер | Drawer | Действие `Связи документа` открывает правую панель с таблицей связей выбранного источника. | Заполняется после утверждения DS-карты. |
| Хедер дровера | Drawer header | Показывает источник связей; при вложенном переходе вместо иконки показывает кнопку возврата. | Заполняется после утверждения DS-карты. |
| Таблица связей | Table | Показывает документы, связанные с одним документом или выбранным набором документов. | Заполняется после утверждения DS-карты. |
| Меню строки таблицы связей | Floating menu | Открывается из строки связанного документа и содержит действия над этим документом. | Заполняется после утверждения DS-карты. |

# Дровер связей документа: данные, состояния и правила

## 1. Владельцы состояния

| Область | Состояние или значение | Правило видимого результата |
|---|---|---|
| `documents-list` | Документ-источник | Дровер показывает связанные документы выбранной строки таблицы документов. |
| `document-bulk-actions` | Выбранный набор документов | Дровер показывает объединенный набор связанных документов выбранного набора. |
| Дровер связей документа | Текущий источник связей | Хедер показывает документ-источник или выбранный набор; таблица показывает соответствующие связи. |
| Дровер связей документа | История вложенных переходов | Кнопка возврата видна только на вложенном уровне. |
| Дровер связей документа | Сортировка таблицы связей | Таблица показывает текущий набор связей в выбранном порядке. |
| Дровер связей документа | Выбранные строки таблицы связей | Выбранные строки получают выбранное состояние внутри дровера. |
| Документ | Пометка на удаление | Строки документа в таблице документов и таблице связей показывают состояние пометки. |

## 2. Продуктовые состояния

| Состояние | Условие входа | Видимый результат | Условие выхода или сброса |
|---|---|---|---|
| Дровер закрыт | Пользователь не открывал связи или закрыл дровер | Overlay и правый дровер скрыты. | Пользователь выбирает `Связи документа` из меню строки или плавающей панели. |
| Первый уровень связей одного документа | Пользователь выбирает `Связи документа` в меню строки таблицы документов | Хедер показывает выбранный документ; таблица показывает связанные документы этого документа; кнопка возврата скрыта. | Пользователь закрывает дровер или открывает вложенный уровень. |
| Первый уровень связей выбранного набора | Пользователь выбирает `Связи документа` на плавающей панели | Хедер показывает количество выбранных документов и их наименования; таблица показывает объединенный набор связанных документов. | Пользователь закрывает дровер или открывает вложенный уровень. |
| Вложенный уровень связей | Пользователь выбирает `Связи документа` в меню строки таблицы связей | Хедер показывает выбранный связанный документ; таблица показывает его связи; кнопка возврата видна. | Пользователь выбирает кнопку возврата или закрывает дровер. |
| Пустой набор связей | Текущий источник не имеет связанных документов | Тело таблицы показывает строку `Связи документа не найдены`. | Пользователь возвращается, закрывает дровер или открывает источник с непустым набором связей. |
| Документ выбран внутри дровера | Пользователь выбирает чекбокс строки таблицы связей | Строка и чекбокс получают выбранное состояние внутри дровера. | Пользователь снимает выбор, выбирает чекбокс заголовка с противоположным состоянием или открывает другой набор связей. |

## 3. Счетчики, видимость и применимость

| Элемент или значение | Условие | Видимый результат |
|---|---|---|
| Overlay | Дровер открыт | Затемненный слой виден поверх рабочей области поиска. |
| Кнопка возврата | История вложенных переходов содержит предыдущий набор связей | Кнопка видна в левой части хедера. |
| Кнопка возврата | Дровер открыт на первом уровне | Кнопка скрыта; вместо нее видна иконка источника. |
| Подзаголовок хедера | Источник - один документ | Подзаголовок показывает тип, номер и наименование документа. |
| Подзаголовок хедера | Источник - выбранный набор документов | Подзаголовок показывает количество выбранных документов и их наименования. |
| Таблица связей | Набор связей содержит документы | Тело таблицы показывает строки связанных документов. |
| Таблица связей | Набор связей пустой | Тело таблицы показывает пустое состояние. |
| Чекбокс заголовка таблицы связей | Пользователь выбирает или снимает чекбокс | Все чекбоксы строк текущей таблицы связей получают то же состояние. |

## 4. Правила данных

| Данные или значение | Источник для интерфейса | Где используется | Видимый результат |
|---|---|---|---|
| Номер связанного документа | Документ из набора связей | Колонка `Номер` | В строке таблицы связей показан номер документа. |
| Наименование связанного документа | Документ из набора связей | Колонка `Наименование` | В строке таблицы связей показано наименование документа. |
| Дата документа | Документ из набора связей | Колонка `Дата документа` | В строке таблицы связей показана дата документа. |
| Дата изменения | Документ из набора связей | Колонка `Изменено` | В строке таблицы связей показана дата последнего изменения. |
| Тип документа | Документ из набора связей | Колонка `Тип` | В строке таблицы связей показан тип документа. |
| Пакет документа | Документ из набора связей | Индикатор рядом с наименованием | Пользователь видит маршрут пакета через popover индикатора. |
| Связанные документы источника | Текущий источник связей | Тело таблицы связей | Таблица показывает документы, номера которых входят в связи источника. |
| Пометка на удаление | Состояние документа | Меню строки и строка документа | Меню показывает `Снять отметку` для помеченного документа; строка показывает состояние пометки. |

## 5. Контракты взаимодействия

| Связанный компонент | Роль связанного компонента | Условие | Результат в текущем компоненте | Результат в связанном компоненте |
|---|---|---|---|---|
| `documents-list` | Источник одного документа | Пользователь выбирает `Связи документа` в меню строки таблицы документов | Дровер открывается; таблица показывает связи выбранного документа. | Таблица документов сохраняет текущую выдачу и выбранные строки. |
| `document-bulk-actions` | Источник выбранного набора | Пользователь выбирает `Связи документа` на плавающей панели | Дровер открывается; таблица показывает объединенный набор связей выбранных документов. | Плавающая панель остается в состоянии выбранного набора до изменения выбора или закрытия панели. |
| `documents-list` | Получатель состояния пометки | Пользователь выбирает пометку или снятие пометки в меню строки дровера | Строка документа в дровере получает актуальное состояние пометки. | Строка этого документа в таблице документов получает актуальное состояние пометки. |
| Toast | Получатель подтверждения | Пользователь меняет пометку на удаление из меню строки дровера | Дровер сохраняет текущий набор связей. | Toast показывает текст подтверждения действия. |

## 6. Ограничения ответственности

| Область | Правило |
|---|---|
| Таблица документов | Дровер не меняет текущие условия поиска, сортировку, страницу и примененные колонки таблицы документов. |
| Массовые действия | Дровер не создает выбранный набор документов; он получает набор из плавающей панели. |
| Фильтры поиска | Дровер не применяет фильтры и не меняет значения левой панели поиска. |
| Пакеты документов | Дровер не меняет пакет документа; он показывает текущий маршрут пакета в строке. |
| Вложенная навигация | Дровер хранит только историю переходов внутри самого дровера; закрытие дровера очищает эту историю. |
| Пагинация | Дровер не использует пагинацию основной таблицы документов. |

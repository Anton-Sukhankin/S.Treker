# Flow: открытие карточки задачи

## Цель и граница

Пользователь открывает детальную карточку из списка задач и после закрытия возвращается к той же позиции. Flow связывает список задач и `task-card-drawer`; внутренние действия формы описаны в компонентной спецификации drawer.

## Основной сценарий

| Шаг | Действие | Источник | Передаваемое значение | Получатель | Видимый итог |
|---:|---|---|---|---|---|
| 1 | Пользователь нажимает наименование задачи в таблице или карточном виде | `tasks` | `taskId` | `task-card-drawer` | Drawer выезжает от правой границы справа налево и показывает данные выбранной задачи без overlay |
| 2 | Пользователь работает с карточкой или нажимает наименование другой доступной задачи | `task-card-drawer`, `tasks` | Локальный draft и выбранный `taskId` | `task-card-drawer` | Список не заблокирован; при выборе другой задачи содержимое drawer переключается, а draft хранится отдельно по `taskId` |
| 3 | Пользователь закрывает drawer | `task-card-drawer` | Элемент-инициатор | `tasks` | Drawer скрыт, фокус возвращён на наименование задачи |

## Ветви

При несохранённом draft шаг закрытия сначала показывает подтверждение выхода. Переключение на другую задачу не считается закрытием и не требует подтверждения: draft предыдущей задачи остаётся в карте состояний текущей сессии. При переходе в `Поиск` drawer закрывается до показа рабочей области документного поиска.

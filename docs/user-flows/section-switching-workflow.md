# Flow: переключение разделов `Задачи` / `Поиск`

## Зачем нужен сценарий

Пользователь переходит из рабочего списка задач в документный поиск и возвращается обратно. Финальный результат: активный пункт верхней навигации соответствует видимой рабочей области, а состояния задач и поиска не смешиваются.

## Граница flow

| Граница | Значение |
|---|---|
| Начальное состояние | S-Tracker открыт; активен пункт `Задачи`; рабочая область задач видна. |
| Конечный результат | Пользователь может переключить видимость рабочей области задач и рабочей области поиска через верхнюю навигацию. |
| Не входит в flow | Внутренний поиск документов, фильтры документов, таблица документов, внутренние сценарии списка задач и локальные действия компонентов. |

## Участники интерфейса

| Участник | Роль в сценарии | Источник деталей |
|---|---|---|
| Верхняя навигация | Источник активного раздела. | `docs/components/app-header/02-behavior.md`, `docs/components/app-header/03-data-states-rules.md` |
| Рабочая область задач | Получатель активного раздела `Задачи`. | `docs/components/tasks/03-data-states-rules.md` и комплекты компонентов задач. |
| Рабочая область поиска | Получатель активного раздела `Поиск`. | `docs/components/search-workspace/02-behavior.md`, `docs/components/search-workspace/03-data-states-rules.md` |

## Основной сценарий

| Шаг | Действие пользователя или событие | Компонент-источник | Передаваемый результат | Компонент-получатель | Видимый итог |
|---:|---|---|---|---|---|
| 1 | Пользователь открывает S-Tracker. | Верхняя навигация | Активный раздел `Задачи`. | Рабочая область задач | Рабочая область задач видна; рабочая область поиска скрыта. |
| 2 | Пользователь выбирает пункт `Поиск`. | Верхняя навигация | Активный раздел `Поиск`. | Рабочая область поиска | Рабочая область поиска видна под хедером; рабочая область задач скрыта. |
| 3 | Пользователь выбирает пункт `Задачи`. | Верхняя навигация | Активный раздел `Задачи`. | Рабочая область задач | Рабочая область задач видна под хедером; рабочая область поиска скрыта. |

## Изменения состояния

| Состояние | Владелец состояния | Когда меняется | Видимый результат |
|---|---|---|---|
| Активный раздел | Верхняя навигация | Пользователь выбирает `Задачи` или `Поиск`. | Выбранный пункт верхней навигации имеет активную индикацию. |
| Видимость рабочей области задач | Верхняя навигация и рабочая область задач | Активный раздел получает значение `Задачи` или `Поиск`. | Область задач видна только при активном пункте `Задачи`. |
| Видимость рабочей области поиска | Верхняя навигация и рабочая область поиска | Активный раздел получает значение `Поиск` или `Задачи`. | Область поиска видна только при активном пункте `Поиск`. |
| Выбор задач | Компоненты выбора задач | Пользователь выбирает `Поиск` при непустом выбранном наборе задач. | Выбранные задачи теряют выбранное состояние; плавающая панель выбора задач скрыта. |

## Ветки

| Ситуация | Условие | Видимый результат |
|---|---|---|
| Открыт слой задач | В рабочей области задач открыт дровер, модальное окно, выпадающий список или плавающая панель выбора задач; пользователь выбирает `Поиск`. | Открытый слой задач закрыт; рабочая область поиска видна. |
| Изменены состояния документного поиска | Пользователь выбирает `Задачи` после работы с поиском документов. | Рабочая область задач видна; фильтры задач, колонки задач, очереди, пагинация задач и выбранные задачи не получают значения из документного поиска. |

## Когда обновлять документ

- Меняется способ переключения `Задачи` / `Поиск`.
- Меняется видимый результат входа в раздел `Поиск` или возврата в `Задачи`.
- Меняется правило изоляции состояний между рабочей областью задач и рабочей областью поиска.
